## 📖 О проекте

<img width="1727" height="859" alt="v2-03 preview" src="https://github.com/user-attachments/assets/ca9af402-5512-4091-92f6-b801d15d334d" />

**Frontend Interview Playground** — это интерактивная платформа для подготовки к техническим собеседованиям по **React** и **JavaScript** (от уровня **Junior** до **Lead**). Платформа содержит более **250 практических задач с реальных интервью**, разборы антипаттернов в кодe кандидатов, эталонные решения и интерактивные шпаргалки.

Теперь решать задачи можно не только в своей IDE, но также и непосредственно в браузере!

> 🌐 **Быстрый доступ:**
>
> - **[🚀 Открыть интерактивную онлайн-версию](https://evgeniibogdanov.github.io/frontend-practice/)** — *без локальной установки, редактор в браузере*
> - **[📥 Перейти к инструкции по локальной установке](#-пошаговая-установка-и-запуск)** — *для практики в связке с IDE*

## 📥 Пошаговая установка и запуск

Следуйте этой инструкции для локального запуска проекта на вашем компьютере.

### 1️⃣ Клонирование репозитория

Откройте терминал (или командную строку) и выполните команду клонирования:

```bash
git clone https://github.com/EvgeniiBogdanov/frontend-practice.git
```

Перейдите в папку проекта:

```bash
cd frontend-practice
```

### 2️⃣ Установка зависимостей

Установите все необходимые npm-пакеты:

```bash
npm install
```

### 3️⃣ Запуск в режиме разработки

Запустите локальный сервер разработки Vite:

```bash
npm run dev
```

После этого в терминале появится ссылка вида `http://localhost:4000/`. Откройте её в вашем браузере. 🎉

## ⌨️ Горячие клавиши (Hotkeys)

| Сочетание клавиш                                             | Действие                                               |
| :----------------------------------------------------------- | :----------------------------------------------------- |
| <kbd>⌘</kbd> + <kbd>K</kbd> / <kbd>Ctrl</kbd> + <kbd>K</kbd> | Открыть палитру быстрого поиска задач по всем разделам |
| <kbd>Esc</kbd>                                               | Закрыть модальное окно / палитру поиска                |
| <kbd>↓</kbd> / <kbd>↑</kbd>                                  | Переключение между задачами в списке                   |

## 📂 Структура проекта

```text
src/
├── components/
│   ├── common/        # Общие компоненты (Header, Sidebar и др.)
│   ├── dashboard/     # Компонент Главной страницы (HomeDashboard)
│   ├── layout/        # Основная разметка приложения
│   ├── modals/        # Модальные окна (Статистика, Поиск, Шпаргалки)
│   └── task/          # Вкладки задачи (Кандидат, Решение, Разбор, Чек-лист)
├── javascript/
│   └── data/          # Реестр и код задач по JavaScript
├── react/
│   └── data/          # Реестр и код задач по React
├── playground.css     # Стили
├── Playground.jsx     # Главный контейнер платформы
└── main.jsx           # Точка входа приложения
```

## 🤝 Как внести вклад

Вклады всегда приветствуются! Если вы хотите улучшить проект:

1. 🍴 Сделайте форк репозитория
2. 🌿 Создайте новую ветку: `git checkout -b feature/your-feature`
3. 💾 Закоммитьте изменения: `git commit -m 'Add some feature'`
4. 📤 Отправьте ветку: `git push origin feature/your-feature`
5. 🔄 Откройте Pull Request

Пожалуйста, убедитесь, что ваши изменения не ломают существующий функционал и следуют стилю кода проекта.
