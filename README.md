# 🚀 Frontend Interview Playground & Practice `v1.0`

Интерактивная платформа (версия **v1.0**) для подготовки к техническим собеседованиям по **React** и **JavaScript** (от уровня Junior до Lead). Платформа содержит более 250 практических задач с реальных интервью, разборами антипаттернов в кандидатском коде, эталонными решениями и интерактивными шпаргалками.

---

## ⚡ Основные возможности

- **🎯 250+ реальных задач с собеседований**:
  - **JavaScript**: Замыкания, рекурсия, прототипы, `this`, каррирование, полифилы `Promise`, `Debounce`/`Throttle`, `Event Loop` и утилиты объектов.
  - **React**: Хуки (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`), паттерны рефакторинга компонентов, оптимизация перерендеров, Redux Toolkit и интеграция с TypeScript.
  - **Алгоритмы**: Классические алгоритмические паттерны на JS.
- **💻 Песочница кандидата (Candidate Code)**: Запускаемый live-код с багами, недочетами и антипаттернами кандидатов для отработки навыка проведения Code Review.
- **💡 Эталонные решения (Solution Tab)**: Оптимизированные решения с пометками предпочтительности на собеседованиях, разбором сложности $O(N)$ / $O(1)$ и лучшими практиками.
- **📋 Чек-листы и вопросы интервьюера**: Вопросы для самопроверки и список критериев, проверяемых собеседующими.
- **🔍 Поиск по всему приложению (`Cmd+K`)**: Палитра команд для мгновенного поиска любых задач по ключевым словам и темам.
- **🎨 Дизайн в стиле Notion**: Поддержка тёмной и светлой темы с аутентичной типографикой и callout-блоками.

---

## 🛠 Технологический стек

- **Core**: React 18, JavaScript (ES6+) / TypeScript
- **Bundler**: Vite 5
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Notion Design System)

## 📥 Пошаговая установка и запуск

Следуйте этой инструкции для локального запуска проекта на вашем компьютере.

### 1. Предварительные требования

Убедитесь, что на вашем компьютере установлены:
- **Node.js**: версия `18.0.0` или выше ([Скачать Node.js](https://nodejs.org/))
- **Git**: ([Скачать Git](https://git-scm.com/))

Проверить версии в терминале:
```bash
node -v
npm -v
```

---

### 2. Клонирование репозитория

Откройте терминал (или командную строку) и выполните команду клонирования:

```bash
git clone https://github.com/EvgeniiBogdanov/frontend-practice.git
```

Перейдите в папку проекта:

```bash
cd frontend-practice
```

---

### 3. Установка зависимостей

Установите все необходимые npm-пакеты:

```bash
npm install
```

---

### 4. Запуск в режиме разработки

Запустите локальный сервер разработки Vite:

```bash
npm run dev
```

После этого в терминале появится ссылка вида `http://localhost:5173`. Откройте её в вашем браузере.

---

### 5. Сборка проекта для продакшна

Для проверки сборки оптимизированного бандла запустите:

```bash
npm run build
```

Итоговый бандл будет собран в директорию `dist/`.

Для локального предпросмотра готовой продакшн-сборки используйте:

```bash
npm run preview
```

├── components/
