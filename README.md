# 🚀 Frontend Interview Playground & Practice `v2.0.1`

<img width="1728" height="884" alt="version-2" src="https://github.com/user-attachments/assets/5f0cbd73-b99f-4b99-ae8b-dae267900c31" />

Интерактивная платформа для подготовки к техническим собеседованиям по **React** и **JavaScript** (от уровня Junior до Lead). Платформа содержит более 250 практических задач с реальных интервью, разборами антипаттернов в кандидатском коде, эталонными решениями и интерактивными шпаргалками. Теперь решать задачи можно не только в своей IDE, но также и непосредственно в браузере!

---

## ⚡ Основные возможности

- **🎯 250+ реальных задач с собеседований**:
  - **JavaScript**: Замыкания, рекурсия, прототипы, `this`, каррирование, полифилы `Promise`, `Debounce`/`Throttle`, `Event Loop` и утилиты объектов.
  - **React**: Хуки (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`), паттерны рефакторинга компонентов, оптимизация перерендеров, Redux Toolkit и интеграция с TypeScript.
  - **Алгоритмы**: Классические алгоритмические паттерны на JS.
- **💻 Встроенный редактор кода в браузере**: Решать задачи и многофайловые модули можно непосредственно в браузере без запуска сторонней IDE. Поддержка редактирования JavaScript, TypeScript и React-разметки (JSX / TSX). Но вы также можете решать задачи в IDE и комбинировать эти подходы.
- **⚡ Интерактивная консоль JavaScript**: Мгновенный запуск кода в браузере (<kbd>Ctrl</kbd> + <kbd>Enter</kbd>) с отслеживанием времени выполнения в миллисекундах (`⚡ 6.4ms`) и разбором вывода.
- **💻 Песочница кандидата (Candidate Code)**: Запускаемый live-код с багами, недочетами и антипаттернами кандидатов для отработки навыка проведения Code Review.
- **💡 Эталонные решения (Solution Tab)**: Оптимизированные решения с пометками предпочтительности на собеседованиях, разбором сложности $O(N)$ / $O(1)$ и лучшими практиками.
- **📋 Чек-листы и вопросы интервьюера**: Вопросы для самопроверки и список критериев, проверяемых собеседующими.
- **🔍 Поиск по всему приложению (`Cmd+K`)**: Палитра команд для мгновенного поиска любых задач по ключевым словам и темам.
- **🎨 Современный минималистичный дизайн**: Поддержка тёмной и светлой темы с удобной типографикой и информационными блоками.

## 📥 Пошаговая установка и запуск

Следуйте этой инструкции для локального запуска проекта на вашем компьютере.

### 1. Клонирование репозитория

Откройте терминал (или командную строку) и выполните команду клонирования:

```bash
git clone https://github.com/EvgeniiBogdanov/frontend-practice.git
```

Перейдите в папку проекта:

```bash
cd frontend-practice
```

---

### 2. Установка зависимостей

Установите все необходимые npm-пакеты:

```bash
npm install
```

---

### 3. Запуск в режиме разработки

Запустите локальный сервер разработки Vite:

```bash
npm run dev
```

После этого в терминале появится ссылка вида `http://localhost:4000/`. Откройте её в вашем браузере.

## ⌨️ Горячие клавиши (Hotkeys)

| Сочетание клавиш                                             | Действие                                               |
| :----------------------------------------------------------- | :----------------------------------------------------- |
| <kbd>⌘</kbd> + <kbd>K</kbd> / <kbd>Ctrl</kbd> + <kbd>K</kbd> | Открыть палитру быстрого поиска задач по всем разделам |
| <kbd>Esc</kbd>                                               | Закрыть модальное окно / палитру поиска                |
| <kbd>↓</kbd> / <kbd>↑</kbd>                                  | Переключение между задачами в списке                   |

## 📂 Структура проекта

```text
src/
├── components/
│   ├── common/        # Общие компоненты (Header, Sidebar и др.)
│   ├── dashboard/     # Компонент Главной страницы (HomeDashboard)
│   ├── layout/        # Основная разметка приложения
│   ├── modals/        # Модальные окна (Статистика, Поиск, Шпаргалки)

│   └── data/          # Реестр и код задач по JavaScript
├── react/
│   └── data/          # Реестр и код задач по React
├── playground.css     # Стили
├── Playground.jsx     # Главный контейнер платформы
└── main.jsx           # Точка входа приложения
```
