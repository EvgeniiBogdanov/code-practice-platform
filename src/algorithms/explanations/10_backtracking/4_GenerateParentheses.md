# Generate Parentheses — разбор задачи

Источник: https://leetcode.com/problems/generate-parentheses/ (задача №22, сложность Medium)

## Какой алгоритм используется

**Backtracking (поиск с возвратом / бэктрекинг)**.

Мы строим строку из скобок символ за символом. На каждом шаге у нас есть выбор:
добавить открывающую скобку `(` или закрывающую `)`. Но выбор не любой — он ограничен
правилами, чтобы в итоге получилась ПРАВИЛЬНАЯ последовательность. Если строка достроена
до нужной длины — сохраняем её как готовый ответ. Дерево всех возможных строк перебирается
полностью, но заведомо "неправильные" ветки просто не создаются (это и есть отличие от
грубого перебора всех строк подряд).

## В чём суть задачи

Дано число `n` — количество пар скобок. Нужно вернуть массив всех строк длины `2 * n`,
составленных из круглых скобок `(` и `)`, которые образуют правильную скобочную
последовательность.

Правильная последовательность — это когда:
- у каждой открывающей скобки `(` есть своя закрывающая `)`;
- при чтении строки слева направо в любой момент закрывающих скобок не может быть
  больше, чем открывающих (нельзя закрыть то, что ещё не открыто).

Например при `n = 1` подходит только `"()"`. А `")("` — не подходит, потому что скобка
закрывается раньше, чем открылась.

## Идея решения

Заводим два счётчика:
- `open` — сколько открывающих скобок мы уже поставили;
- `close` — сколько закрывающих скобок мы уже поставили.

На каждом шаге строим строку `current` и решаем, что можно добавить дальше:

1. **Добавить `(`** — можно, только если ещё не исчерпан лимit открывающих скобок,
   то есть `open < n`.
2. **Добавить `)`** — можно, только если закрывающих скобок пока меньше, чем открывающих,
   то есть `close < open` (иначе получится "лишняя" закрывающая скобка без пары).

Когда длина строки `current` достигла `2 * n` — значит все скобки расставлены и
последовательность гарантированно правильная (за счёт условий выше). Сохраняем строку
в результат.

Поскольку строки в JS неизменяемые, никакого "отката" (`pop`) как в задаче Combination
Sum делать не нужно — при каждом рекурсивном вызове мы просто передаём новую строку
`current + "("` или `current + ")"`, а старая версия `current` в текущем вызове остаётся
нетронутой.

## Пошаговый разбор кода

```js
const generateParenthesis = (n) => {
  const result = []; // сюда складываем все готовые правильные комбинации

  const backtrack = (current, open, close) => {
    // current — строка, которую мы собираем прямо сейчас
    // open  — сколько открывающих скобок уже поставлено
    // close — сколько закрывающих скобок уже поставлено

    if (current.length === n * 2) {
      // строка нужной длины и по построению она гарантированно правильная —
      // сохраняем результат и на этом ветка рекурсии заканчивается
      result.push(current);
      return;
    }

    if (open < n) {
      // ещё остались "неиспользованные" открывающие скобки — пробуем поставить одну
      backtrack(current + "(", open + 1, close);
    }

    if (close < open) {
      // закрывающих скобок меньше, чем открывающих — можно закрыть одну из них
      backtrack(current + ")", open, close + 1);
    }
  };

  backtrack("", 0, 0);
  return result;
};
```

### Разбор на примере `n = 2`

1. Старт: `current = ""`, `open = 0`, `close = 0`.
2. `open < n` (0 < 2) → добавляем `(` → `current = "("`, `open = 1`.
3. Снова `open < n` (1 < 2) → добавляем `(` → `current = "(("`, `open = 2`.
4. Теперь `open === n`, добавить `(` уже нельзя. Но `close < open` (0 < 2) →
   добавляем `)` → `current = "(()"`.
5. `close < open` (1 < 2) → добавляем `)` → `current = "(())"`, длина строки 4 = `2*n`
   → сохраняем `"(())"`.
6. Возвращаемся назад по дереву и пробуем другие ветки — так постепенно находим
   и `"()()"`.
7. Итоговый результат для `n = 2`: `["(())", "()()"]`.

## Сложность алгоритма

Количество правильных скобочных последовательностей для `n` пар скобок равно
`n`-ому числу Каталана, поэтому итоговая сложность по времени и памяти —
`O(4^n / sqrt(n))`, то есть экспоненциальная. Для ограничения задачи (`n <= 8`)
это работает быстро.
