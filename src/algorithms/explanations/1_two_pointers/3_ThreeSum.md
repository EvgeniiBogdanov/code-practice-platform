## Алгоритм
**Sorting + Two Pointers (сортировка + два указателя)**

Это усложнённая версия классической задачи Two Sum: вместо пары чисел
нужно найти тройку. Задача решается через сортировку массива и
последующий перебор с фиксацией одного элемента + Two Pointers по
оставшейся части.

## Суть задачи
Дан массив целых чисел `nums`. Нужно найти **все уникальные тройки**
чисел из этого массива, сумма которых равна 0. В ответе должны быть
сами значения чисел (а не их индексы), и итоговый набор троек не должен
содержать дубликатов — то есть тройка `[-1, 0, 1]` должна встретиться
в ответе только один раз, даже если в исходном массиве есть несколько
способов её составить из разных индексов.

Например, для `nums = [-1, 0, 1, 2, -1, -4]` подходящие тройки —
`[-1, -1, 2]` и `[-1, 0, 1]`. Другие комбинации либо повторяют уже
найденные тройки, либо не дают в сумме 0.

## Разбор решения

Ключевая идея: **свести 3Sum к Two Sum**. Если зафиксировать один
элемент массива `nums[i]`, то задача "найти два других числа, которые
вместе с `nums[i]` дают 0" — это ровно задача Two Sum с целью
`-nums[i]`. А Two Sum на отсортированном массиве решается двумя
указателями за O(n).

Шаги алгоритма:

1. **Сортируем массив** по возрастанию. Это необходимо по двум причинам:
   - позволяет применить Two Pointers (сумма растёт/убывает предсказуемо
     при сдвиге указателей);
   - позволяет легко пропускать соседние одинаковые числа, чтобы не
     плодить дубликаты троек в ответе.

2. **Перебираем индекс `i`** от начала массива до `length - 2`
   (нужно оставить место минимум для двух чисел справа). Это первое,
   "зафиксированное" число тройки.

3. **Пропускаем повторы для `i`.** Если текущее число `nums[i]` равно
   предыдущему `nums[i - 1]`, пропускаем итерацию — иначе получим
   тройки-дубликаты с одинаковым первым числом.

4. Для каждого `i` запускаем **Two Pointers** по оставшейся части
   массива (`left = i + 1`, `right = nums.length - 1`), ищем пару чисел,
   которая в сумме с `nums[i]` даёт 0, то есть `nums[left] + nums[right]
   === -nums[i]`.

5. Если сумма трёх чисел равна 0 — сохраняем тройку в ответ. После
   этого **пропускаем повторяющиеся значения** и слева, и справа
   (соседние одинаковые числа), чтобы не добавить в ответ дубликат
   той же тройки, затем сдвигаем оба указателя навстречу друг другу.

6. Если сумма меньше 0 — сдвигаем `left` вправо (увеличиваем сумму).
   Если больше 0 — сдвигаем `right` влево (уменьшаем сумму).

7. Повторяем для всех `i`, пока не переберём весь массив.

## Пошаговый разбор кода

```js
const threeSum = (nums) => {
  const result = [];
  // Сортируем массив — без этого Two Pointers и пропуск дубликатов
  // не сработают
  const sorted = [...nums].sort((a, b) => a - b);

  // Перебираем первое число тройки. Останавливаемся за 2 элемента
  // до конца, так как справа нужно ещё минимум два числа
  for (let i = 0; i < sorted.length - 2; i++) {
    // Пропускаем повтор первого числа, чтобы не плодить дубликаты троек
    if (i > 0 && sorted[i] === sorted[i - 1]) {
      continue;
    }

    // Два указателя по оставшейся (правой) части массива
    let left = i + 1;
    let right = sorted.length - 1;

    while (left < right) {
      const sum = sorted[i] + sorted[left] + sorted[right];

      if (sum === 0) {
        // Нашли тройку — сохраняем её
        result.push([sorted[i], sorted[left], sorted[right]]);

        // Пропускаем повторяющиеся значения слева,
        // чтобы не добавить в ответ такую же тройку ещё раз
        while (left < right && sorted[left] === sorted[left + 1]) {
          left++;
        }
        // То же самое справа
        while (left < right && sorted[right] === sorted[right - 1]) {
          right--;
        }

        // Сдвигаем оба указателя навстречу друг другу
        left++;
        right--;
      } else if (sum < 0) {
        // Сумма меньше нуля — нужно число побольше слева
        left++;
      } else {
        // Сумма больше нуля — нужно число поменьше справа
        right--;
      }
    }
  }

  return result;
};
```

### Пример пошагового выполнения

`nums = [-1, 0, 1, 2, -1, -4]` → после сортировки:
`sorted = [-4, -1, -1, 0, 1, 2]`

**i = 0, sorted[i] = -4** (цель для пары: 4)

| left | right | sorted[left] | sorted[right] | sum | Действие |
|------|-------|----------------|------------------|-----|----------|
| 1 | 5 | -1 | 2 | -4 + (-1) + 2 = -3 | -3 < 0 → left++ |
| 2 | 5 | -1 | 2 | -4 + (-1) + 2 = -3 | -3 < 0 → left++ |
| 3 | 5 | 0  | 2 | -4 + 0 + 2 = -2    | -2 < 0 → left++ |
| 4 | 5 | 1  | 2 | -4 + 1 + 2 = -1    | -1 < 0 → left++ |

`left` и `right` встретились — троек с `-4` в сумме 0 не найдено.

**i = 1, sorted[i] = -1** (цель для пары: 1)

| left | right | sorted[left] | sorted[right] | sum | Действие |
|------|-------|----------------|------------------|-----|----------|
| 2 | 5 | -1 | 2 | -1 + (-1) + 2 = 0 | sum === 0 → тройка [-1, -1, 2], сдвигаем оба указателя |
| 3 | 4 | 0  | 1 | -1 + 0 + 1 = 0    | sum === 0 → тройка [-1, 0, 1] |

`left` и `right` встретились — переходим к `i = 2`.

**i = 2, sorted[i] = -1** — но `sorted[2] === sorted[1]` (оба `-1`),
поэтому по правилу пропуска дубликатов эта итерация **пропускается**
(`continue`), чтобы не искать те же тройки повторно.

**i = 3, sorted[i] = 0** (цель для пары: 0)

| left | right | sorted[left] | sorted[right] | sum | Действие |
|------|-------|----------------|------------------|-----|----------|
| 4 | 5 | 1 | 2 | 0 + 1 + 2 = 3 | 3 > 0 → right-- |

`left` и `right` встретились — троек с `0` не найдено.

Итог: `[[-1, -1, 2], [-1, 0, 1]]` — совпадает с ожидаемым ответом.

## Почему нужен именно этот подход

- **Наивный перебор** всех троек через три вложенных цикла даёт
  сложность **O(n³)** — для массива из 3000 элементов это до 27 млрд
  операций, что слишком медленно.
- **Сортировка + Two Pointers** снижает сложность до **O(n²)**:
  сортировка занимает O(n log n), внешний цикл по `i` — O(n), а Two
  Pointers внутри цикла для каждого `i` — O(n), итого O(n) × O(n) =
  O(n²), что для 3000 элементов — уже вполне выполнимо.
- Память — O(1) дополнительной (не считая массива под результат и
  копии `sorted`), так как Two Pointers не требует хеш-таблиц.
