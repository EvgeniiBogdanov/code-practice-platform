# Same Tree (LeetCode 100) — разбор задачи

## Какой алгоритм используется
**Рекурсивный обход дерева в глубину (DFS)** — параллельно по двум
деревьям сразу. На каждом шаге сравниваем текущую пару узлов, а затем
рекурсивно спускаемся в пары "левый-левый" и "правый-правый".

## Суть задачи
Даны два бинарных дерева `p` и `q`. Нужно проверить, одинаковые ли
они. Деревья считаются одинаковыми, если у них:
1. одинаковая **форма** (структура) — каждому узлу одного дерева
   соответствует узел на "том же месте" другого дерева;
2. одинаковые **значения** в соответствующих узлах.

Пример, когда форма разная (значит деревья точно не равны):

```
p:        q:
  1         1
 /           \
2             2
```

Пример, когда форма одинаковая, но значения перепутаны местами
(тоже не равны):

```
p:          q:
   1           1
  / \         / \
 2   1       1   2
```

## Почему это рекурсия
Два дерева равны тогда и только тогда, когда:
- их корни имеют одинаковое значение, **и**
- их **левые** поддеревья равны между собой, **и**
- их **правые** поддеревья равны между собой.

Получается та же большая задача ("равны ли деревья"), только для
поддеревьев меньшего размера — классическая рекурсия.

Базовых случаев (когда рекурсия останавливается и сразу даёт ответ)
два:
- если оба узла — `null`, поддеревья пустые и, значит, равны (`true`);
- если только один из узлов — `null` (а другой нет), формы уже разные
  (`false`).

## Пошаговый разбор кода

```js
const isSameTree = (p, q) => {
  if (p === null && q === null) {
    return true;
  }
  // Базовый случай №1: оба поддерева закончились одновременно —
  // значит, здесь всё совпадает.

  if (p === null || q === null) {
    return false;
  }
  // Базовый случай №2: только одно из поддеревьев закончилось —
  // формы уже не совпадают, дальше сравнивать нечего.

  if (p.val !== q.val) {
    return false;
  }
  // Если оба узла существуют, но значения разные — деревья точно не равны.

  return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
  // Если дошли сюда — значения текущих узлов совпали.
  // Осталось рекурсивно проверить, что равны и левые, и правые поддеревья.
  // "&&" работает как логическое "И" — если левая часть уже дала false,
  // до правой рекурсии дело не дойдёт (короткое замыкание).
};
```

## Сложность
- **Время:** O(min(n, m)), где n и m — количество узлов в p и q,
  потому что в худшем случае обходим оба дерева целиком, а рекурсия
  останавливается, как только находит первое несовпадение.
- **Память:** O(min(h1, h2)), где h1 и h2 — высоты деревьев, за счёт
  стека рекурсивных вызовов.

## Про вспомогательные функции
`createNode` и `buildTree` — это не часть самой задачи с LeetCode
(там дерево уже собрано системой тестирования), а просто удобный
способ задавать деревья локально через плоский массив, а не собирать
узлы вручную объект за объектом.
