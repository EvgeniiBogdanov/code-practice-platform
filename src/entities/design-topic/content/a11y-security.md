# Доступность и безопасность

Это два направления, которые часто откладывают «на потом». На интервью их замечают сразу: они показывают зрелость инженера.

## Доступность (a11y)

Интерфейс должен работать с клавиатурой, скринридером и при плохом зрении. Начните с главного: **семантическая разметка**. `button`, `a`, `label`, `ul` уже умеют фокус, роли и клавиатуру. ARIA нужна, только когда нативного элемента нет.

Правила:

- Любое действие доступно с клавиатуры, фокус виден и идёт в логичном порядке.
- У каждого поля есть метка (`label`), у иконки-кнопки есть доступное имя (`aria-label`).
- Информация не передаётся только цветом.
- Контраст текста достаточный (не меньше 4,5:1 для обычного текста).
- Динамические изменения объявляются: `aria-live` для статусов и ошибок.
- Модальное окно захватывает фокус, закрывается по `Esc` и возвращает фокус на кнопку, которая его открыла.

### Паттерн combobox (автокомплит)

| Элемент    | Роль и атрибуты                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Поле ввода | `role="combobox"`, `aria-expanded`, `aria-controls` (id списка), `aria-autocomplete="list"`, `aria-activedescendant` (id выбранного пункта) |
| Список     | `role="listbox"`                                                                                                                            |
| Пункт      | `role="option"`, `aria-selected`                                                                                                            |

Клавиатура: `↓` / `↑` перемещают выбор, `Enter` подтверждает, `Esc` закрывает список. **Фокус остаётся в поле ввода**, а выбранный пункт обозначается через `aria-activedescendant`. Количество найденных подсказок объявляйте через `aria-live`: скринридер должен знать, что список обновился.

## Безопасность клиента

### XSS (межсайтовый скриптинг)

Злоумышленник внедряет свой скрипт на вашу страницу, и он выполняется с правами пользователя. Защита:

- React экранирует значения в JSX. Опасны `dangerouslySetInnerHTML`, `innerHTML` и ссылки `javascript:`.
- Если нужно вставить HTML от пользователя, пропускайте его через **санитайзер** (например, DOMPurify) с белым списком тегов.
- **Content Security Policy (CSP)** запрещает выполнение чужих и встроенных скриптов: это вторая линия защиты.

### Хранение токенов

| Место                                     | Плюсы                   | Риск                                           |
| ----------------------------------------- | ----------------------- | ---------------------------------------------- |
| `localStorage`                            | Просто                  | Любой XSS читает токен                         |
| Cookie `HttpOnly` + `Secure` + `SameSite` | Скрипты не читают токен | Нужна защита от CSRF (`SameSite`, токен формы) |

Для сессий надёжнее `HttpOnly`-cookie. Токены доступа живут недолго, обновляются через refresh.

### Другое

- **Права проверяются на сервере.** Скрытая в интерфейсе кнопка — не защита.
- **Сторонние скрипты** (аналитика, чат-виджеты) исполняются с вашими правами: ограничивайте CSP, подключайте с `integrity` и не отдавайте им больше, чем нужно.
- **Зависимости.** Следите за уязвимостями (`npm audit`, Dependabot).
- **Утечки данных.** Не пишите чувствительное в логи, URL и аналитику.

## Надёжность интерфейса

- **Границы ошибок** (`ErrorBoundary`) не дают одному компоненту уронить всю страницу.
- **Состояния** загрузки, пустоты и ошибки проектируются заранее, а не «если останется время».
- **Деградация.** Если подсказки не загрузились, поле остаётся рабочим.
- **Мониторинг.** Ошибки и метрики уходят в систему наблюдения; без этого проблему увидят пользователи, а не вы.

## Что сказать на интервью

«Автокомплит делаю по паттерну combobox: фокус остаётся в поле, выбор через `aria-activedescendant`, число результатов объявляю через `aria-live`. Пользовательский HTML в подсказках не вставляю как есть: показываю текст, а подсветку совпадений строю на сервере или через безопасные теги. Токен храню в `HttpOnly`-cookie».
