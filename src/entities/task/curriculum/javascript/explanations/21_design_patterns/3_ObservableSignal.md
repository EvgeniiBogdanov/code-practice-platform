# Реактивная переменная createSignal

## 1. Что такое signal

Signal хранит значение и позволяет другим частям программы подписаться на изменения. В решении возвращаются три функции:

- `get()` читает текущее значение;
- `set(next)` обновляет его;
- `subscribe(listener)` добавляет наблюдателя и возвращает отписку.

Само значение не выставляется наружу напрямую, поэтому изменить его можно только через контролируемый `set`.

## 2. Состояние в замыкании

```js
let value = initialValue;
const subscribers = new Set();
```

`value` и набор подписчиков продолжают жить после завершения `createSignal`, потому что возвращённые функции замкнули эти переменные. `Set` не допускает дублирования одной и той же ссылки на listener.

## 3. Чтение и обновление

`get` просто возвращает актуальный `value`.

```js
value = typeof nextValue === "function"
  ? nextValue(value)
  : nextValue;
```

`set` поддерживает два формата: прямое значение и updater-функцию. Вызов `set((previous) => previous + 1)` безопасно вычисляет новое состояние из текущего.

После записи каждый подписчик получает уже обновлённое значение:

```js
subscribers.forEach((listener) => listener(value));
```

## 4. Подписка и очистка

```js
const subscribe = (listener) => {
  subscribers.add(listener);
  return () => subscribers.delete(listener);
};
```

Возвращаемая функция — удобный cleanup. Она удаляет именно ту ссылку, которая была добавлена. Повторный вызов cleanup безопасен: `Set.delete` просто вернёт `false`.

## 5. Граничные случаи и решения продукта

- Текущая версия уведомляет подписчиков даже при установке того же значения. Можно добавить `Object.is(value, next)` и пропустить лишнее уведомление.
- Новый подписчик не получает текущее значение немедленно; он узнает о нём через `get` или после следующего `set`.
- Ошибка одного listener прервёт обход и не даст вызвать следующие. Иногда ошибки изолируют через `try/catch`.
- Listener может подписаться или отписаться во время уведомления. Для фиксированного снимка используют `[...subscribers]`.
- Забытый cleanup удерживает listener в памяти.

## 6. Сложность

`get` и `subscribe` в среднем работают за `O(1)`. `set` занимает `O(k)`, потому что вызывает `k` подписчиков. Память — `O(k)`.

## 7. Что запомнить

Минимальная реактивность — это значение в замыкании плюс коллекция наблюдателей. `set` меняет источник правды и рассылает уведомление, а `subscribe` обязательно должен давать способ очистки.
