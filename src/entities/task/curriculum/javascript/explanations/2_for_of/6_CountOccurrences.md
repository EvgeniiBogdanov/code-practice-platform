## Что делает решение

```js
const countOccurrences = (arr, word) => {
  let count = 0;
  for (const item of arr) {
    if (item === word) count++;
  }
  return count;
};
```

Функция считает, сколько элементов массива строго равны `word`. Аккумулятор увеличивается только на совпадениях, поэтому отсутствующее слово естественно даёт ноль.

## Пошаговый разбор

Для `['кофе', 'сок', 'кофе']` и цели `'кофе'` счётчик меняется `0 → 1 → 1 → 2`. Инвариант: перед каждой итерацией `count` равен числу совпадений в уже просмотренной части массива.

Альтернативный `reduce` возвращает `count + 1` на совпадении и прежний `count` иначе. Оба варианта проходят весь массив: ранний выход невозможен, потому что для точного количества нужно увидеть все элементы.

## Граничные случаи и ошибки

- Сравнение чувствительно к регистру: `'Кофе'` и `'кофе'` различны. Нормализацию нужно добавлять явно.
- `===` не приводит типы: `1` не совпадает с `"1"`.
- `NaN` не совпадает сам с собой. Если его нужно учитывать, используйте `Object.is(item, word)` или SameValueZero-проверку.
- Объекты считаются совпавшими только при одинаковой ссылке, не по содержимому.
- Пустой массив возвращает `0`.
- Для множества запросов по одному большому массиву повторный линейный подсчёт неэффективен; один раз постройте частотную `Map`.
- Регистр, пробелы и Unicode-нормализация являются частью контракта «слова», а не автоматически исправляются циклом.

## Сложность

Один запрос требует `O(n)` времени и `O(1)` памяти. Частотная карта строится за `O(n)` времени и `O(k)` памяти, после чего каждый запрос в среднем близок к `O(1)`.

## Что запомнить

Подсчёт вхождений — аккумулятор с условным обновлением. Выберите нужную семантику равенства и нормализацию до написания цикла; для одного запроса достаточно обхода, для многих выгоден предварительный индекс.
