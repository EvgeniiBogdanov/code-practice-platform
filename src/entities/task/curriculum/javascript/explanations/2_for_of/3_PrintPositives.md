## Что делает решение

```js
const printPositives = (arr) => {
  for (const num of arr) {
    if (num > 0) console.log(num);
  }
};
```

Функция просматривает все значения и выводит только те, которые строго больше нуля. Для `[-43, 32, -33, 6]` в консоль попадут `32` и `6` в исходном порядке.

## Как устроена фильтрация

Цикл отвечает за обход, `if` — за решение по одному элементу. Отрицательное значение и ноль просто не выполняют тело условия; `continue` здесь не нужен. Порядок элементов сохраняется, поскольку `for...of` идёт слева направо.

Функция производит побочный эффект и возвращает `undefined`. Если отфильтрованные числа нужны дальше, лучше вернуть `arr.filter((num) => num > 0)`. Тогда вывод можно сделать на уровне вызывающего кода.

## Граничные случаи и ошибки

- Ноль не считается положительным, потому что используется `> 0`, а не `>= 0`.
- `NaN > 0`, `undefined > 0` и `null > 0` дают ложь, но это не означает, что вход корректен.
- Числовые строки сравниваются с приведением типов: `"5" > 0` истинно. Для строгого контракта проверяют `typeof num === "number"` и `Number.isFinite(num)`.
- `Infinity` считается положительным числом и будет выведена.
- Пустой массив ничего не выводит.
- `null` вместо массива вызовет `TypeError`, потому что значение не итерируемо.
- Консольный вывод трудно использовать как результат и неудобно тестировать без перехвата `console.log`.

## Сложность

Даже если положительных значений мало, проверяется каждый элемент: `O(n)` времени и `O(1)` дополнительной памяти. Возвращаемый массив потребовал бы до `O(n)` памяти.

## Что запомнить

Разделяйте обход, предикат и действие. Здесь предикат — `num > 0`, действие — вывод. Перед реализацией уточните, входит ли ноль, разрешено ли приведение типов и нужен ли побочный эффект или возвращаемая коллекция.
