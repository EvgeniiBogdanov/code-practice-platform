### Что делает решение
Функция `memoize(fn)` оборачивает переданную функцию `fn` и кэширует результаты её вызовов с учетом порядка аргументов:
1. В лексической области видимости `memoize` создается кэш `cache = new Map()`.
2. Возвращается функция-обертка `function (...args)`, которая сериализует аргументы в строковый ключ `const key = JSON.stringify(args)`.
3. Порядок аргументов важен: `[1, 2]` превращается в `"[1,2]"`, а `[2, 1]` — в `"[2,1]"`, что гарантирует раздельное кэширование вызовов с разным порядком параметров.
4. Если результат для данного ключа уже сохранен (`cache.has(key)`), возвращается значение из кэша `cache.get(key)` без повторного вызова `fn`.
5. При первом вызове функция `fn` запускается с сохранением контекста `this` через `fn.apply(this, args)`, результат записывается в `Map` (`cache.set(key, result)`) и возвращается.

```js
function memoize(fn) {
  const cache = new Map();
  return function (...args) {
    const key = JSON.stringify(args);
    if (cache.has(key)) {
      return cache.get(key);
    }
    const result = fn.apply(this, args);
    cache.set(key, result);
    return result;
  };
}
```

### Граничные случаи и ошибки
- **Сохранение контекста `this`**: возврат обычной функции `function (...args)` и вызов `fn.apply(this, args)` необходим для корректной работы мемоизированных методов объектов. Стрелочная функция потеряла бы динамический `this`.
- **Проверка через `has`, а не `get`**: если функция вернула `0`, `false`, `null`, пустую строку или `undefined`, простая проверка `if (cache.get(key))` посчитала бы значение отсутствующим и вызвала `fn` заново. Метод `cache.has(key)` проверяет именно наличие записи.
- **Любое количество аргументов**: rest-параметры `...args` поддерживают вызовы с нулем, одним или произвольным числом аргументов.
- **Ограничения `JSON.stringify`**: подходит для примитивов (числа, строки, булевы значения), однако `undefined` в массиве превращается в `null`, а циклические структуры и `BigInt` вызовут исключение.

### Сложность
- **По времени**: `O(1)` в среднем на проверку и извлечение из `Map`, плюс `O(A)` на сериализацию аргументов `JSON.stringify(args)` (где `A` — суммарная длина аргументов). При промахе кэша сложность равна времени выполнения `fn`.
- **По памяти**: `O(N)` по памяти, где `N` — количество уникальных комбинаций аргументов, для которых сохранены результаты.

### Что запомнить для собеседования
- `Map` сохраняет любые ключи и гарантирует быстрый доступ за `O(1)`.
- Использование `fn.apply(this, args)` сохраняет контекст вызова, позволяя использовать `memoize` для методов классов и объектов.
- Метод `cache.has(key)` критичен для корректной обработки falsy-значений (`false`, `0`, `""`, `null`, `undefined`).
