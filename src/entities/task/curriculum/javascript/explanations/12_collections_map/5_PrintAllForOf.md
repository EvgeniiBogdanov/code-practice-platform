## Что делает решение

Функция обходит все записи `Map` и выводит каждую пару в формате `ключ: значение`:

```js
const printAll = (map) => {
  for (const [key, value] of map) {
    console.log(`${key}: ${value}`);
  }
};
```

Для коллекции `new Map([["fruit", "apple"], ["veg", "carrot"]])` будут выведены строки `fruit: apple` и `veg: carrot`.

## Почему работает деструктуризация

`Map` является итерируемой коллекцией. Её итератор по умолчанию выдаёт записи в виде двухэлементных массивов:

```js
["fruit", "apple"]
["veg", "carrot"]
```

Запись `[key, value]` в заголовке цикла сразу деструктурирует очередную пару: первый элемент попадает в `key`, второй — в `value`. Без деструктуризации код выглядел бы длиннее:

```js
for (const entry of map) {
  const key = entry[0];
  const value = entry[1];
  console.log(`${key}: ${value}`);
}
```

Цикл `for...of map` эквивалентен `for...of map.entries()`. Метод `entries()` можно написать явно, но в этой ситуации он не добавляет новой информации.

## Порядок обхода

`Map` сохраняет порядок вставки ключей. Если сначала добавлен `fruit`, а затем `veg`, цикл обойдёт их именно так. Обновление существующего ключа через `set` не переносит его в конец. Если удалить ключ и добавить заново, он станет последним.

## Почему здесь удобен for...of

В отличие от `forEach`, цикл поддерживает `break`, `continue`, `return` из окружающей функции и `await` внутри `async`-функции. Это важно, когда обход нужно остановить досрочно или выполнить последовательные асинхронные действия.

```js
for (const [key, value] of map) {
  if (value === "carrot") break;
  console.log(key);
}
```

## Граничные случаи и ошибки

- Пустая `Map` не выполнит тело цикла ни разу.
- Шаблонная строка вызывает строковое преобразование ключа и значения. Объекты будут выведены как `[object Object]`, если не форматировать их отдельно.
- Если во время обхода удалить ещё не посещённый ключ, он не будет выдан. Добавленные в процессе записи могут попасть в этот же обход.
- `for...in` использовать нельзя: он перебирает перечисляемые свойства объекта, а не записи `Map`.
- Функция только печатает данные и возвращает `undefined`; она не создаёт массив строк.

## Сложность

Полный обход занимает `O(n)` времени и `O(1)` дополнительной памяти. Консоль и строковое представление сложных значений могут добавлять собственные расходы.

## Что запомнить

Итератор `Map` по умолчанию выдаёт `[key, value]`, поэтому `for (const [key, value] of map)` — основной читаемый способ обхода. Он сохраняет порядок вставки и позволяет управлять циклом через `break` и `continue`.
