## Что делает решение

`Map` можно наполнить не только последовательными вызовами `set`, но и сразу при создании. Конструктор принимает итерируемую коллекцию пар `[key, value]`:

```js
const map = new Map([
  ["name", "Иван"],
  ["age", 30],
  ["city", "Москва"],
]);
```

Внешний массив содержит записи, а каждый внутренний массив описывает одну пару. Конструктор последовательно добавляет их так, словно для каждой пары был вызван `map.set(key, value)`.

## Как читать полученную Map

```js
console.log(map.get("name")); // "Иван"
console.log(map.get("age"));  // 30
console.log(map.size);        // 3
```

Доступ `map.name` или `map["name"]` не читает запись коллекции. Такие выражения обращаются к обычным свойствам самого объекта `Map`. Для содержимого используются `get`, `set`, `has` и `delete`.

## Почему конструктор принимает именно пары

Форма `[key, value]` позволяет передать ключ и значение одним элементом iterable. Подходит не только массив массивов:

```js
const source = { theme: "dark", language: "ru" };
const settings = new Map(Object.entries(source));
```

`Object.entries(source)` уже возвращает массив пар, поэтому его можно передать напрямую. Обратное преобразование выполняется через `Object.fromEntries(settings)`, если ключи можно безопасно представить как свойства объекта.

## Что произойдёт с повторными ключами

```js
const map = new Map([
  ["role", "user"],
  ["role", "admin"],
]);
```

В результате останется одна запись `"role" → "admin"`: более поздняя пара перезапишет значение. Размер будет равен `1`. Позиция ключа соответствует его первому добавлению.

## Граничные случаи и ошибки

- `new Map()` и `new Map([])` создают пустую коллекцию.
- Каждый элемент входного iterable должен предоставлять пару. Некорректный элемент может привести к `TypeError`.
- Значение `undefined` допустимо. `get` не отличает его от отсутствующего ключа, поэтому используйте `map.has(key)`.
- Ключом может быть объект, но получить запись получится только по той же ссылке.
- При передаче `Object.entries` числовые имена свойств уже представлены строками.
- Конструктор потребляет iterable один раз. Если передать генератор, после создания `Map` генератор окажется исчерпан.

## Сложность

Создание коллекции из `n` пар занимает в среднем `O(n)` времени и `O(n)` памяти. Последующие операции `get`, `set` и `has` в типичных реализациях близки к `O(1)` в среднем.

## Что запомнить

Конструктор `Map` ожидает последовательность двухэлементных записей `[key, value]`. Это делает `Map` естественно совместимой с `Object.entries`, генераторами пар и результатами других преобразований данных.
