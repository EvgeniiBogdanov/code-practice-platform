## Что делает решение

Функция удаляет запись по ключу и сообщает, произошло ли удаление:

```js
const removeIfExists = (map, key) => {
  return map.delete(key);
};
```

`Map.prototype.delete` уже возвращает подходящее булево значение:

- `true`, если ключ существовал и запись была удалена;
- `false`, если такого ключа не было.

Поэтому отдельная проверка `map.has(key)` не нужна.

## Пошаговый пример

```js
const map = new Map([
  ["a", 1],
  ["b", 2],
]);

removeIfExists(map, "a"); // true
```

До вызова `map.size === 2`. Метод находит ключ `"a"`, удаляет связанную пару и возвращает `true`. После вызова остаётся только `"b" → 2`, а `map.size === 1`.

```js
removeIfExists(map, "z"); // false
```

Ключа `"z"` нет, поэтому состояние коллекции не меняется и возвращается `false`.

## Почему вариант с `has` избыточен

Можно написать:

```js
if (map.has(key)) {
  map.delete(key);
  return true;
}

return false;
```

Результат будет тем же, но коллекция ищет ключ дважды: сначала в `has`, затем в `delete`. Встроенный контракт `delete` уже объединяет проверку и удаление, поэтому прямой возврат короче и точнее выражает намерение.

## Важное свойство: функция мутирует Map

`delete` изменяет переданную коллекцию на месте. Функция возвращает не новую `Map`, а только статус операции:

```js
const sameMap = map;
removeIfExists(map, "b");

sameMap.has("b"); // false
```

Обе переменные ссылаются на одну коллекцию и видят изменение.

## Граничные случаи и ошибки

- Удаление из пустой `Map` безопасно и возвращает `false`.
- Значение записи не влияет на результат: ключ со значением `undefined` всё равно существует и будет удалён с результатом `true`.
- Объектный ключ сравнивается по ссылке. `delete({ id: 1 })` не удалит запись, созданную с другим объектом `{ id: 1 }`.
- После удаления и повторного `set` ключ окажется в конце порядка обхода.
- Если мутация входных данных запрещена контрактом, нужно заранее создать копию: `const copy = new Map(map)`.

## Сложность

Удаление в типичных реализациях близко к `O(1)` в среднем и использует `O(1)` дополнительной памяти. Создание защитной копии всей коллекции потребовало бы `O(n)` времени и памяти.

## Что запомнить

Не дублируйте возможности стандартного API: `map.delete(key)` уже проверяет наличие, удаляет запись и возвращает статус. При этом операция изменяет исходную коллекцию, что должно быть частью контракта функции.
