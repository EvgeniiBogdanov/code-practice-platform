## Что делает решение

`groupBy(items, key)` объединяет объекты по значению выбранного свойства. Ключами результата становятся значения группирующего поля, а значениями — массивы исходных объектов.

```js
const groupBy = (items, key) => {
  const map = new Map();

  for (const item of items) {
    const groupKey = item[key];

    if (!map.has(groupKey)) {
      map.set(groupKey, []);
    }

    map.get(groupKey).push(item);
  }

  return map;
};
```

Если `key === "city"`, люди из Москвы попадут в одну запись `"Москва" → [...]`, а люди из Петербурга — в другую.

## Пошаговая логика

Для каждого объекта выполняются три действия:

1. `item[key]` динамически читает значение свойства. Запись `item.key` искала бы буквальное поле `key`.
2. Если группа встречается впервые, в `Map` создаётся пустой массив.
3. Текущий объект добавляется в массив найденной группы.

Для данных Аня/Москва, Петя/Питер, Оля/Москва состояние меняется так:

| Элемент | Результат после шага |
| --- | --- |
| Аня | `Москва → [Аня]` |
| Петя | `Москва → [Аня], Питер → [Петя]` |
| Оля | `Москва → [Аня, Оля], Питер → [Петя]` |

Проверка `has` нужна до `push`: у новой группы ещё нет массива, и вызов `undefined.push(...)` завершился бы ошибкой.

## Преимущество Map для группировки

Значением свойства может быть число, объект, функция или `undefined`, и `Map` сохранит тип ключа. В обычном объекте ключи приводятся к строкам. Особенно заметна разница при группировке по объектному свойству: две записи объединятся только тогда, когда содержат одну и ту же ссылку.

В современных окружениях существует `Map.groupBy(items, callback)`, но ручное решение полезно для понимания алгоритма и контроля совместимости.

## Граничные случаи и ошибки

- Пустой массив возвращает пустую `Map`.
- Если свойства `key` нет, элемент попадёт в группу с ключом `undefined`.
- В группы сохраняются ссылки на исходные объекты. Их последующая мутация видна в обоих местах.
- Порядок групп соответствует первому появлению ключа, порядок элементов внутри группы — исходному порядку массива.
- Значения `NaN` образуют одну группу, а разные объектные ссылки — разные группы.

## Сложность

Среднее время — `O(n)`: каждый элемент обрабатывается один раз. Память — `O(n + k)`, где `k` — число групп; асимптотически `O(n)`.

## Что запомнить

Группировка состоит из двух обязательных операций: лениво создать контейнер группы и добавить в него элемент. `Map` сохраняет тип группирующего ключа и порядок первого появления групп.
