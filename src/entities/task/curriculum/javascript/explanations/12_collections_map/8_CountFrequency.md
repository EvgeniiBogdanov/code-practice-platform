## Что делает решение

Функция строит частотную таблицу: каждому уникальному элементу массива сопоставляет число его появлений.

```js
const countFrequency = (arr) => {
  const map = new Map();

  for (const item of arr) {
    map.set(item, (map.get(item) || 0) + 1);
  }

  return map;
};
```

Для `['a', 'b', 'a', 'c', 'b', 'a']` результатом будет `Map` с записями `a → 3`, `b → 2`, `c → 1`.

## Пошаговая трассировка

Выражение `(map.get(item) || 0) + 1` сначала читает прежний счётчик. Для нового ключа `get` возвращает `undefined`, поэтому `|| 0` подставляет стартовый ноль. Затем счётчик увеличивается и сохраняется через `set`.

| Текущий элемент | Состояние после шага |
| --- | --- |
| `a` | `a → 1` |
| `b` | `a → 1, b → 1` |
| `a` | `a → 2, b → 1` |
| `c` | `a → 2, b → 1, c → 1` |
| `b` | `a → 2, b → 2, c → 1` |
| `a` | `a → 3, b → 2, c → 1` |

Вместо `|| 0` можно использовать более точный nullish fallback:

```js
map.set(item, (map.get(item) ?? 0) + 1);
```

Для положительных счётчиков оба варианта эквивалентны, но `??` подставляет ноль только для `null` и `undefined`, а не для любого falsy-значения.

## Почему Map удобнее объекта

Обычный объект приводит ключи к строкам: число `1` и строка `"1"` сольются в одну запись. `Map` сохраняет тип ключа. Она также умеет считать объекты, функции и символы.

```js
const first = { id: 1 };
const second = { id: 1 };

countFrequency([first, second, first]);
// first → 2, second → 1
```

Объекты сравниваются по ссылке, поэтому одинаковое содержимое не делает их одним ключом.

## Граничные случаи и ошибки

- Пустой массив возвращает пустую `Map`.
- Значения `NaN` считаются одним ключом `NaN`.
- `0` и `-0` считаются одним ключом.
- Два отдельных объектных литерала являются разными ключами.
- Решение не меняет исходный массив, но сохраняет ссылки на его объектные элементы.
- Результат нельзя прочитать через `result[item]`; используйте `get`.

## Сложность

Массив обходится один раз: время — `O(n)` в среднем. Память — `O(k)`, где `k` — число уникальных ключей.

## Что запомнить

Частотная таблица строится паттерном «прочитать старое значение → подставить ноль → увеличить → сохранить». `Map` особенно полезна, когда тип ключа важен или элементы не ограничены строками.
