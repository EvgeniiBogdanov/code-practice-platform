## Что делает фактическое решение

Задача похожа на предыдущую группировку, но результатом должен быть обычный объект. Текущее решение строит его напрямую через `reduce`:

```js
const groupBy = (items, key) => {
  return items.reduce((acc, item) => {
    const groupKey = item[key];
    acc[groupKey] = acc[groupKey] || [];
    acc[groupKey].push(item);
    return acc;
  }, {});
};
```

Важно: в этом коде сначала не создаётся `Map`, и `Object.fromEntries` не вызывается. Старое краткое описание утверждало обратное и не соответствовало показанному решению.

## Пошаговый разбор

Аккумулятор `acc` начинается с пустого объекта. На каждой итерации:

1. `item[key]` получает динамический ключ группы.
2. `acc[groupKey] || []` оставляет существующий массив либо создаёт новый.
3. `push(item)` добавляет текущий объект.
4. `return acc` передаёт тот же аккумулятор следующей итерации.

Для городов результат принимает форму:

```js
{
  "Москва": [
    { name: "Аня", city: "Москва" },
    { name: "Оля", city: "Москва" },
  ],
  "Питер": [{ name: "Петя", city: "Питер" }],
}
```

## Чем результат отличается от Map

Ключи объекта могут быть только строками или символами. Число `1` станет строкой `"1"`; разные объекты превратятся в одинаковую строку `"[object Object]"`. Поэтому объект удобен для сериализуемых строковых категорий, а `Map` — для ключей любых типов.

Альтернативный двухэтапный вариант действительно возможен:

```js
const groupedMap = groupByToMap(items, key);
const groupedObject = Object.fromEntries(groupedMap);
```

Но для этой конкретной функции промежуточная `Map` не нужна: она добавляет ещё один контейнер и дополнительный проход.

## Граничные случаи и ошибки

- Пустой массив возвращает `{}`.
- Отсутствующее свойство создаёт группу `"undefined"`.
- Ключи вроде `"constructor"` и `"__proto__"` конфликтуют с прототипом обычного объекта и могут сломать инициализацию. Для внешних ключей безопаснее `Object.create(null)` или `Map`.
- В группы попадают ссылки на исходные объекты, а не копии.
- Если забыть `return acc`, следующая итерация получит `undefined`.
- Порядок строковых ключей обычно следует вставке, но целочисленные ключи объекта перечисляются по специальным правилам.

## Сложность

Время — `O(n)` в среднем, память результата — `O(n)`. Вариант с промежуточной `Map` тоже остаётся линейным, но требует больше временной памяти.

## Что запомнить

Выбирайте форму результата по контракту: объект удобен для JSON и строковых категорий, `Map` — для ключей любых типов. Разбор всегда должен описывать фактически показанный код, а не похожий альтернативный вариант.
