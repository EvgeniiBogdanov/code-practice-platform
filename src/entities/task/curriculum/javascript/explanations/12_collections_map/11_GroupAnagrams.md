## Что такое анаграммы

Анаграммы состоят из одинаковых символов в одинаковом количестве, но могут иметь разный порядок. Например, `eat`, `tea` и `ate` принадлежат одной группе. Слова `tan` и `nat` образуют другую.

Главная задача — придумать общий ключ, который будет одинаковым у всех анаграмм.

## Пошаговый разбор решения

```js
const groupAnagrams = (arr) => {
  const map = new Map();

  for (const str of arr) {
    const key = str.split("").sort().join("");

    if (!map.has(key)) {
      map.set(key, []);
    }

    map.get(key).push(str);
  }

  return [...map.values()];
};
```

Канонический ключ строится в три этапа:

1. `split("")` превращает строку в массив символов.
2. `sort()` упорядочивает символы.
3. `join("")` снова собирает строку.

У `eat`, `tea` и `ate` ключом будет `aet`. У `tan` и `nat` — `ant`. Поэтому `Map` естественно объединяет их.

| Слово | Канонический ключ | Группа после добавления |
| --- | --- | --- |
| `eat` | `aet` | `[eat]` |
| `tea` | `aet` | `[eat, tea]` |
| `tan` | `ant` | `[tan]` |
| `ate` | `aet` | `[eat, tea, ate]` |

В конце вспомогательные ключи не нужны, поэтому берутся только значения `Map`: `[...map.values()]`.

## Почему нельзя использовать Set букв

`Set` потерял бы количество повторений. Слова `abb` и `ab` дали бы один набор `{a, b}`, хотя анаграммами не являются. Сортированная строка сохраняет и состав, и число повторений.

## Граничные случаи и ошибки

- Текущее решение чувствительно к регистру: `Eat` и `tea` попадут в разные группы.
- Пробелы и знаки препинания тоже считаются символами. Нормализация зависит от требований задачи.
- Пустые строки имеют одинаковый пустой ключ и группируются вместе.
- `split("")` работает с кодовыми единицами UTF-16; сложные Unicode-символы и эмодзи могут потребовать `[...str]` и Unicode-нормализацию.
- Порядок групп соответствует первому появлению ключа, а порядок слов внутри группы — исходному массиву.

## Сложность

Пусть `n` — число слов, а `k` — средняя длина слова. Сортировка каждого слова занимает `O(k log k)`, поэтому общее время — `O(n · k log k)`. Память для ключей и групп — `O(n · k)`.

Для фиксированного небольшого алфавита ключ можно строить по частотам символов за `O(k)`, но такое решение сложнее и зависит от набора допустимых символов.

## Что запомнить

Для группировки сложных объектов сначала найдите каноническое представление. У анаграмм это отсортированные символы. Ключ обязан учитывать не только наличие символов, но и количество каждого из них.
