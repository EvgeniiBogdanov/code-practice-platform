## Что делает решение

Задача знакомит с базовой моделью `Map`: это коллекция пар «ключ → значение». В отличие от обычного объекта, записи добавляются не через `object[key] = value`, а методом `set`.

```js
const map = new Map();

map.set("a", 1);
map.set("b", 2);
map.set("c", 3);
```

После выполнения в коллекции находятся три записи: `"a" → 1`, `"b" → 2` и `"c" → 3`. Свойство `map.size` будет равно `3`.

## Разбор по шагам

`new Map()` создаёт отдельную пустую коллекцию. Каждый вызов `set(key, value)` выполняет одно из двух действий:

1. Если ключ встречается впервые, добавляет новую запись.
2. Если ключ уже существует, заменяет его значение, не увеличивая `size`.

```js
map.set("a", 10);

console.log(map.get("a")); // 10
console.log(map.size);     // 3, а не 4
```

`set` возвращает сам объект `Map`, поэтому вызовы можно объединять в цепочку:

```js
const map = new Map()
  .set("a", 1)
  .set("b", 2)
  .set("c", 3);
```

Оба варианта создают одинаковую коллекцию. Для учебной задачи отдельные строки нагляднее показывают изменение состояния, а цепочка удобна для компактной инициализации.

## Почему здесь может понадобиться Map, а не Object

Ключом `Map` может быть не только строка или символ, но и число, объект, функция и даже `NaN`:

```js
const user = { id: 1 };
const cache = new Map();

cache.set(user, "данные пользователя");
cache.get(user); // "данные пользователя"
```

Объектные ключи сравниваются по ссылке. Новый литерал `{ id: 1 }` — другая ссылка, поэтому `cache.get({ id: 1 })` вернёт `undefined`. Число `1` и строка `"1"` тоже будут разными ключами, тогда как в обычном объекте оба превращаются в строковое имя свойства.

## Граничные случаи и ошибки

- `map.set("a", undefined)` создаёт существующий ключ со значением `undefined`; наличие проверяется через `has`.
- Повторный `set` перезаписывает значение, но не создаёт дополнительную запись.
- `Map` изменяется на месте. Все переменные, содержащие ссылку на эту коллекцию, увидят добавленные записи.
- Запись `map["a"] = 1` создаёт обычное свойство объекта и не добавляет запись в коллекцию. Методы `get`, `has` и `size` такую запись не увидят.
- `const` запрещает переназначить переменную `map`, но не запрещает менять содержимое самой коллекции.

## Сложность

В типичных реализациях `set`, `get`, `has` и `delete` работают в среднем за время, близкое к `O(1)`. Память для `n` записей — `O(n)`.

## Что запомнить

`Map` — отдельная коллекция со своим API. Создавайте её через `new Map()`, добавляйте данные через `set`, читайте через `get`, а количество записей получайте из `size`. Главная практическая особенность — ключи не ограничены строками.
