### Что делает решение
Код показывает главное отличие `Map` от обычного объекта — **какими могут быть ключи**.

У обычного объекта ключ — это всегда строка или `Symbol`. Любое другое значение перед записью приводится к строке:
- объект `{ id: 1 }` превращается в `"[object Object]"` через `toString()`;
- число `1` превращается в `"1"`.

У `Map` ключом может быть **любое значение**, и оно хранится как есть. Сравнение ключей идёт по алгоритму SameValueZero: примитивы сравниваются по значению, объекты — по ссылке.

### Пошаговый разбор
1. `obj[key1] = "first"` записывает свойство `"[object Object]"`.
2. `obj[key2] = "second"` записывает **то же самое** свойство `"[object Object]"` и перезаписывает значение. Поэтому `obj[key1]` возвращает `"second"`, а в `Object.keys(obj)` один ключ.
3. В `Map` ключи `key1` и `key2` — две разные ссылки, поэтому записей две и `map.get(key1)` возвращает `"first"`.
4. `obj[1]` и `obj["1"]` — один и тот же ключ `"1"`, последнее присваивание побеждает: `"string"`.
5. В `Map` число `1` и строка `"1"` — разные ключи, значения не конфликтуют.

### Когда выбирать Map
| | `Object` | `Map` |
|---|---|---|
| Типы ключей | строки и символы | любые значения |
| Размер | `Object.keys(obj).length` (`O(n)`) | `map.size` (`O(1)`) |
| Порядок | сначала целочисленные ключи по возрастанию, затем строки в порядке вставки | всегда порядок вставки |
| Прототип | есть унаследованные ключи (`toString`, `constructor`) | нет «лишних» ключей |
| Частые добавления и удаления | медленнее | оптимизирован |
| Сериализация в JSON | из коробки | нужно `Object.fromEntries(map)` |

### Граничные случаи и ошибки
- `map.get({ id: 1 })` вернёт `undefined`, даже если ключ с таким содержимым был: это **другой** объект. Нужно хранить и передавать ту же ссылку.
- Объекты-ключи в `Map` не освобождаются сборщиком мусора, пока запись существует. Для метаданных DOM-узлов и других объектов используют `WeakMap`.
- `map[key] = value` — ошибка: так создаётся свойство объекта `map`, а не запись коллекции. Нужно использовать `set` и `get`.
- `JSON.stringify(map)` вернёт `"{}"`.

### Сложность
`set`, `get`, `has`, `delete` у `Map` работают за `O(1)` в среднем. Задача на понимание, данные не масштабируются.

### Что запомнить для собеседования
- Ключи объекта приводятся к строке, ключи `Map` — нет.
- Объекты-ключи в `Map` сравниваются по ссылке.
- `Map` выбирают для произвольных ключей, частых изменений и гарантированного порядка вставки.
