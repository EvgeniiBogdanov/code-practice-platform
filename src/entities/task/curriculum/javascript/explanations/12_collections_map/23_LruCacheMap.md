### Что делает решение
Функция `memoize(fn, ms)` реализует паттерн мемоизации с ограничением по времени жизни кэша (Time-To-Live, TTL) на базе структуры `Map`:
1. В замыкании создается экземпляр `cache = new Map()`, в котором ключом выступает строка сериализованных аргументов `JSON.stringify(args)`.
2. В качестве значения в `Map` сохраняется объект `{ value, expiry }`, где `value` — результат вызова исходной функции, а `expiry = now + ms` — временная метка истечения актуальности кэша.
3. При каждом вызове обертки вычисляется текущее время `now = Date.now()`. Если ключ уже есть в кэше и `now < expiry`, возвращается сохраненное значение `value` без повторного вызова `fn`.
4. Если запись отсутствует или срок действия истек (`now >= expiry`), функция `fn(...args)` вызывается заново, новый результат кэшируется с обновленным `expiry`, после чего возвращается пользователю.

```js
const memoize = (fn, ms) => {
  const cache = new Map();
  return (...args) => {
    const key = JSON.stringify(args);
    const now = Date.now();
    if (cache.has(key)) {
      const { value, expiry } = cache.get(key);
      if (now < expiry) {
        return value;
      }
    }
    const result = fn(...args);
    cache.set(key, {
      value: result,
      expiry: now + ms,
    });
    return result;
  };
};
```

### Граничные случаи и ошибки
- **Протухание кэша (TTL expiration)**: запись считается актуальной только при строгом неравенстве `now < expiry`. Ровно в момент `expiry` и позже кэш считается устаревшим и вычисляется заново.
- **Ограничения `JSON.stringify`**: ключи аргументов сериализуются через JSON. Примитивы (числа, строки, булевы значения) сериализуются стабильно, однако `undefined`, `NaN` и `Infinity` требуют осторожности при сериализации в сложных структурах.
- **Очистка устаревших записей**: в данной реализации старые записи обновляются «лениво» при повторном обращении с теми же аргументами. Невостребованные ключи остаются в `Map`, поэтому в высоконагруженных системах дополнительно применяют периодическую очистку или стратегию вытеснения LRU.
- **Сохранение контекста**: для чистых функций со стрелочной оберткой передача `this` не критична, но для методов объектов следует учитывать контекст.

### Сложность
- **По времени**: `O(1)` в среднем на поиск и чтение из `Map` плюс `O(A)` на сериализацию аргументов `JSON.stringify`, где `A` — размер аргументов. При промахе кэша сложность определяется временем выполнения исходной функции `fn`.
- **По памяти**: `O(K)` по памяти, где `K` — количество уникальных наборов аргументов, сохраненных в `Map`.

### Что запомнить для собеседования
- Мемоизация с TTL позволяет эффективно защищать сервер и клиент от избыточных вычислений и повторных запросов на заданный интервал времени `ms`.
- Сохранение объекта `{ value, expiry }` в `Map` дает возможность проверять актуальность записи за константное время `O(1)`.
- Разделение ответственности: проверка наличия через `cache.has(key)` и проверка валидности времени `now < expiry`.
