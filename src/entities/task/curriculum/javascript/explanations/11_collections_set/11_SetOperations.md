### Что делает решение
Все четыре операции строятся из двух идей:
1. `new Set(arr)` убирает дубликаты.
2. `set.has(x)` проверяет принадлежность за `O(1)` в среднем, поэтому фильтрация одного массива по множеству другого стоит `O(n + m)`, а не `O(n * m)`.

| Операция | Формула | Реализация |
|---|---|---|
| Объединение A ∪ B | есть хотя бы в одном | `new Set([...a, ...b])` |
| Пересечение A ∩ B | есть в обоих | `a.filter((x) => setB.has(x))` |
| Разность A \ B | есть в A, нет в B | `a.filter((x) => !setB.has(x))` |
| Симметрическая разность A △ B | ровно в одном | `(A \ B) ∪ (B \ A)` |

`new Set(a)` перед фильтрацией нужен, чтобы дубликаты в `a` не попали в результат: `intersection([1, 2, 2, 3], ...)` должен вернуть `[2, 3]`, а не `[2, 2, 3]`.

### Встроенные методы ES2025
С 2024–2025 годов у `Set` есть методы `union`, `intersection`, `difference`, `symmetricDifference`, а также проверки `isSubsetOf`, `isSupersetOf`, `isDisjointFrom`. Они поддерживаются во всех современных браузерах и в Node.js 22+. На собеседовании полезно их знать, но реализацию через `filter` + `has` попросят написать в любом случае.

### Граничные случаи и ошибки
- **Квадратичная ловушка:** `a.filter((x) => b.includes(x))` даёт правильный ответ, но `includes` — линейный поиск, итого `O(n * m)`. Это самая частая ошибка, на которую обращают внимание.
- Объекты сравниваются по ссылке: два разных объекта `{ id: 1 }` — разные элементы множества. Для пересечения по ключу стройте `Set` из идентификаторов: `new Set(b.map((x) => x.id))`.
- `NaN` в Set равен `NaN` (сравнение SameValueZero), поэтому пересечение `[NaN]` и `[NaN]` — `[NaN]`.
- Порядок результата — порядок первого появления в первом массиве.

### Сложность
- По времени: `O(n + m)` для каждой операции.
- По памяти: `O(n + m)` на множества и результат.

### Что запомнить для собеседования
- Пересечение и разность: `Set` из второго массива + `filter` по первому.
- `filter` + `includes` — `O(n * m)`, это нужно уметь объяснить и исправить.
- В ES2025 у `Set` есть встроенные `union`, `intersection`, `difference`, `symmetricDifference`.
