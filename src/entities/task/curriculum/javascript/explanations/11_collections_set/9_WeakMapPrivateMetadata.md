### Что делает решение
Решение использует коллекцию `WeakMap` для реализации отслеживания приватных метаданных (счетчика посещений пользователя через `trackVisit(user)` и `getVisitCount(user)`). Метаданные связываются с объектом-ключом без мутации самого объекта и без риска утечек памяти (Memory Leaks).

### Пошаговый разбор механизма JS Engine

1. **Слабые ссылки (Weak References)**:
   - В обычном `Map` объект-ключ удерживается сильной ссылкой (strong reference). Пока `Map` жив, объект не будет удален сборщиком мусора, даже если в остальном приложении на него не осталось ссылок.
   - В `WeakMap` ссылки на объекты-ключи являются «слабыми». Когда объект `user` выходит из области видимости или удаляется (`user = null`), сборщик мусора V8 беспрепятственно освобождает память этого объекта, а ассоциированная с ним запись в `WeakMap` автоматически уничтожается.

2. **Работа функций `trackVisit` и `getVisitCount`**:
   - `trackVisit(user)` считывает текущее значение через `visitCounts.get(user) || 0` и сохраняет инкрементированное значение через `visitCounts.set(user, count + 1)`.
   - `getVisitCount(user)` возвращает накопленное число посещений либо `0`, если пользователь еще не посещал страницу.

3. **Ограничения `WeakMap`**:
   - Ключами могут быть **только объекты** (и незарегистрированные символы в ES2023+). Попытка передать примитив (`string`, `number`) в качестве ключа вызывает `TypeError`.
   - `WeakMap` **не итерируем**: у него отсутствуют методы `.keys()`, `.values()`, `.entries()`, свойство `.size` и цикл `for...of`, поскольку работа сборщика мусора недетерминирована во времени.

### Граничные случаи и ошибки
- **Пользователь без посещений**: если `trackVisit` еще не вызывался для пользователя, `getVisitCount(user)` безопасно возвращает `0` благодаря fallback `visitCounts.get(user) || 0`.
- **Попытка передать примитив**: `trackVisit("Alice")` вызовет ошибку `TypeError: Invalid value used as weak map key`, так как ключом может быть только объект.
- **Инкапсуляция**: объект `user` не загрязняется сторонними свойствами (`user.visitCount = 2`), что сохраняет его форму (Hidden Class в V8) и чистоту API.

### Сложность
- **По времени**: `O(1)` в среднем для операций `visitCounts.get()` и `visitCounts.set()`.
- **По памяти**: `O(1)` дополнительной памяти на каждый отслеживаемый объект с автоматической очисткой при сборке мусора.

### Что запомнить для собеседования
- `WeakMap` предотвращает утечки памяти при связывании дополнительных данных с объектами или DOM-элементами.
- Ключи — строго объекты, ссылки слабые, размер коллекции и итерация недоступны.
- Идеальный паттерн для кэширования, подсчета метаданных и скрытых данных без мутации исходных сущностей.
