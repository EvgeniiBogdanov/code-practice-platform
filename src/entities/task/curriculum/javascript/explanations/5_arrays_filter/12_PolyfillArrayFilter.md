### Что делает решение
Решение реализует точный полифил метода `Array.prototype.filter` (`customFilter` / `myFilter`):
1. Валидирует входные аргументы: выбрасывает `TypeError`, если массив не передан или `callback` не является функцией.
2. Итерирует по массиву фиксированной длины, пропуская отсутствующие индексы в разреженных массивах через проверку `i in obj`.
3. Оборачивает результат вызова `callback` в `Boolean(...)` для надежной фильтрации по truthy/falsy значениям.
4. Возвращает новый массив, наполненный прошедшими предикат элементами.

### Пошаговый разбор механизма JS Engine

1. **Разреженные массивы и оператор `in`**:
   - В `[1, , 3]` элемент с индексом `1` — это "дыра" в памяти (`hole`). Оператор `1 in obj` возвращает `false`.
   - Это гарантирует, что функция предиката не вызовется для несуществующих элементов.

2. **Приведение предиката к булеву типу**:
   - Если callback возвращает не-булево значение (например, `1`, `"ok"`, `null`), оно явно трактуется в булевом контексте (`Boolean(val)`).

3. **Иммутабельность**:
   - Исходный массив не подвергается никаким мутациям, создается новый компактный массив с помощью `result.push()`.

### Граничные случаи и ошибки
- **Пустой массив**: возвращает `[]` без вызова callback.
- **Ни один элемент не подошел**: возвращает новый пустой массив `[]`.
- **callback мутирует массив**: новые добавленные элементы не обрабатываются из-за фиксированной границы `len`.

### Сложность
- **По времени**: `O(n)` — один проход по массиву длины `n`.
- **По памяти**: `O(k)` — где `k <= n` — количество элементов, прошедших фильтрацию.

### Что запомнить для собеседования
- `filter` возвращает новый массив только с теми элементами, для которых callback вернул truthy.
- `filter` никогда не изменяет исходный массив.
- Разреженные элементы (`empty slots`) пропускаются без вызова предиката.
