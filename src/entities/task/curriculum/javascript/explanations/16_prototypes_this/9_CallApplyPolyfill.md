### Что делает решение
Полифил опирается на правило неявной привязки: при вызове `obj.fn()` внутри `fn` значение `this` равно `obj`. Значит, чтобы вызвать функцию с нужным `this`, её достаточно **временно положить в объект-контекст и вызвать через точку**:
1. Внутри `myCall` значение `this` — сама функция (`introduce.myCall(...)` — неявная привязка к `introduce`).
2. Контекст нормализуется: `null` и `undefined` заменяются на `globalThis`, а примитивы оборачиваются через `Object(context)`, иначе к ним нельзя добавить свойство.
3. Функция записывается в контекст под **уникальным ключом `Symbol`** — так невозможно перезаписать существующее свойство объекта, даже если у него есть поле `fn`.
4. Функция вызывается как метод, результат возвращается.
5. В `finally` временное свойство удаляется, даже если функция бросила исключение.

`myApply` отличается только форматом аргументов: массив разворачивается в `myCall`. Значение по умолчанию `args = []` позволяет вызвать `myApply` без второго аргумента.

### Граничные случаи и ошибки
- **Строковый ключ `"fn"`** вместо `Symbol` — классическая ошибка: он перезапишет свойство объекта с таким именем и после `delete` удалит оригинал.
- **Без `finally`** исключение внутри функции оставит в объекте «мусорное» свойство.
- **Примитивы.** Встроенный `call` в строгом режиме передаёт примитив как есть (`typeof this === "number"`), а полифил вынужден обернуть его в объект (`"object"`). Это известное ограничение подхода через свойство.
- **Замороженные объекты.** `Object.freeze(ctx)` не даст добавить свойство, и полифил упадёт. Встроенный `call` работает с любыми объектами.
- Прямой вызов `fn(...args)` без привязки потеряет `this` — весь смысл задачи в правиле «вызов через точку».

### Сложность
- По времени: `O(n)` на передачу `n` аргументов.
- По памяти: `O(n)` на массив аргументов.

### Что запомнить для собеседования
- Идея полифила: временно сделать функцию методом контекста и вызвать через точку.
- Ключ — `Symbol`, очистка — в `finally`.
- `call(ctx, a, b)` и `apply(ctx, [a, b])` отличаются только способом передачи аргументов. Современный `fn.call(ctx, ...arr)` почти полностью заменил `apply`.
