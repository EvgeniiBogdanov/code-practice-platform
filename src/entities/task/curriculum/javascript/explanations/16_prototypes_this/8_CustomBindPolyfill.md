### Что делает решение
Решение реализует полифил метода `Function.prototype.bind` (`myBind` / `customBind`). Функция жестко привязывает контекст `this` к переданному объекту `context` и поддерживает частичное применение (partial application / currying) аргументов.

### Пошаговый разбор механизма JS Engine

1. **Разница между `call`, `apply` и `bind`**:
   - `fn.call(context, arg1, arg2)`: немедленно вызывает функцию с указанным `this` и списком аргументов через запятую.
   - `fn.apply(context, [args])`: немедленно вызывает функцию с указанным `this` и массивом аргументов.
   - `fn.bind(context, ...boundArgs)`: **не вызывает** функцию сразу, а возвращает новую функцию с навсегда привязанным `this` и предварительно зафиксированными аргументами.

2. **Объединение аргументов**:
   - При создании обертки захватываются аргументы `...boundArgs`.
   - При последующем вызове обертки поступают аргументы `...callArgs`.
   - Результирующий массив `[...boundArgs, ...callArgs]` передается в `fn.apply(context, ...)`.

3. **Неизменяемость привязанного контекста**:
   - Повторный вызов `.bind()` поверх уже привязанной функции не меняет исходный `this`, так как самая первая внутренняя обертка всегда вызывает оригинальную функцию с первоначальным `context`.

### Граничные случаи и ошибки
- **Передача не-функции**: если первый аргумент не является функцией, выбрасывается `TypeError`.
- **Передача `null` или `undefined` в качестве контекста**: в non-strict mode контекстом станет глобальный объект (`globalThis`), в strict mode сохранится `null`/`undefined`.

### Сложность
- **По времени**: `O(k + m)` — где `k` — число связанных аргументов, `m` — число аргументов при вызове (склеивание массивов).
- **По памяти**: `O(k)` — замыкание хранит массив связанных аргументов.

### Что запомнить для собеседования
- `bind` возвращает функцию с жестко привязанным `this` и частичным применением аргументов.
- Повторный `bind` не может переопределить контекст первого `bind`.
- Стрелочные функции не имеют собственного `this`, поэтому к ним `bind/call/apply` неприменимы.
