### Что делает решение
Класс использует все современные возможности инкапсуляции:

| Синтаксис | Что это | Где хранится |
|---|---|---|
| `this.owner = owner` | публичное поле | в экземпляре |
| `#balance = 0` | приватное поле (ES2022) | в экземпляре, недоступно снаружи |
| `#validate(amount)` | приватный метод | доступен только внутри класса |
| `get balance()` | геттер | в прототипе, вызывается при чтении `account.balance` |
| `static count = 0` | статическое поле | в самом классе `BankAccount` |
| `static isAccount()` | статический метод | вызывается как `BankAccount.isAccount(...)` |

### Как это работает
- `#balance` — настоящая приватность на уровне языка. Обращение `account.#balance` снаружи класса — `SyntaxError` ещё на этапе разбора кода. Поле не видно в `Object.keys`, `for...in`, `JSON.stringify` и даже через `Reflect.ownKeys`.
- Изменить баланс можно только через `deposit` и `withdraw`, которые проверяют инварианты (`#validate`, проверка остатка). В этом смысл инкапсуляции: объект не может оказаться в некорректном состоянии.
- Геттер без сеттера делает свойство доступным только для чтения. В строгом режиме (тело класса всегда строгое) присваивание бросает `TypeError`, в нестрогом коде оно было бы молча проигнорировано.
- `static count` — общий счётчик для всех экземпляров. В конструкторе к нему обращаются через имя класса.

### Граничные случаи и ошибки
- **Соглашение `_balance`** — не приватность: свойство доступно и изменяемо снаружи. Это была договорённость до появления `#`.
- **Приватность через замыкание** (переменная в конструкторе + методы, объявленные внутри него) работает, но методы создаются заново для каждого экземпляра.
- Приватные поля **не наследуются** в смысле доступа: подкласс не видит `#balance` родителя и должен использовать публичные методы или геттеры.
- `#balance in value` — проверка наличия приватного поля (ES2022). Это более надёжная альтернатива `instanceof` для `isAccount`: её нельзя обмануть через `Object.setPrototypeOf`.
- Обращение к `this.#balance` у объекта, созданного не этим классом, бросает `TypeError`.

### Сложность
Все методы работают за `O(1)`.

### Что запомнить для собеседования
- `#field` — настоящая приватность, `_field` — только соглашение.
- Геттер без сеттера даёт свойство только для чтения; запись в строгом режиме бросает `TypeError`.
- `static` принадлежит классу, а не экземплярам.
- Инкапсуляция нужна, чтобы объект нельзя было перевести в некорректное состояние в обход проверок.
