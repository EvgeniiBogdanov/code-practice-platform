### Что делает решение
Код проверяет, как `extends` и `super` устроены на уровне прототипов.

**`extends` строит две цепочки прототипов одновременно:**
1. `Dog.prototype → Animal.prototype` — экземпляры собак получают методы и геттеры животных (`speak`, `description`).
2. `Dog → Animal` — сам класс-конструктор наследует **статические** члены, поэтому `Dog.kingdom === "Животные"`.

**`super` используется в двух ролях:**
- `super(name)` в конструкторе вызывает конструктор родителя. В производном классе объект `this` создаёт именно родительский конструктор, поэтому до вызова `super()` обращение к `this` бросает `ReferenceError`.
- `super.speak()` в методе вызывает метод родителя с текущим `this`. Так переопределённый метод может расширить поведение родителя, а не заменить его полностью.

### Пошаговый разбор
1. `new Dog("Шарик")` выводит `"Animal constructor: Шарик"`, затем `"Dog constructor"`: тело конструктора `Dog` продолжается после `super`.
2. `dog.speak()` — метод `Dog` вызывает `super.speak()` и дописывает `": гав!"`.
3. `dog.description` — геттер найден в `Animal.prototype`.
4. `typeof Dog === "function"`: класс — это особая функция-конструктор.
5. В `Cat` присваивание `this.name` до `super` бросает `ReferenceError`, ошибка перехвачена, затем `super` создаёт объект.
6. `Object.hasOwn(dog, "speak")` — `false`: собственные свойства экземпляра — только поля (`name`), методы лежат в прототипе. Оператор `in` ищет по всей цепочке и возвращает `true`.

### Граничные случаи и ошибки
- Если в производном классе объявлен конструктор, он **обязан** вызвать `super()` до обращения к `this` и до выхода из конструктора. Иначе — `ReferenceError` при создании объекта.
- Если конструктор в подклассе не объявлен, создаётся неявный: `constructor(...args) { super(...args); }`.
- Стрелочные функции в полях класса (`handleClick = () => {}`) создаются для каждого экземпляра и не попадают в прототип. Поэтому их нельзя переопределить через `super.handleClick()`.
- Классы не поднимаются (TDZ) и всегда работают в строгом режиме. Вызов без `new` бросает `TypeError`.

### Сложность
Задача на понимание: `O(1)`. Поиск метода по цепочке прототипов — `O(d)` по глубине иерархии.

### Что запомнить для собеседования
- `extends` связывает и прототипы экземпляров, и сами классы (отсюда наследование `static`).
- `super()` создаёт `this` в производном классе — до него `this` недоступен.
- `super.method()` вызывает метод родителя с текущим `this`.
- Методы живут в прототипе, поля — в экземпляре.
