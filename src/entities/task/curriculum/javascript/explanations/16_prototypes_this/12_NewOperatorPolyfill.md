### Что делает решение
Оператор `new Constructor(...args)` выполняет четыре шага, и `myNew` повторяет каждый из них:
1. **Создаёт пустой объект.**
2. **Связывает его с прототипом:** `[[Prototype]]` нового объекта становится `Constructor.prototype`. `Object.create(Constructor.prototype)` делает оба шага сразу. Благодаря этому экземпляру доступны методы прототипа (`sayHi`), и `instanceof` возвращает `true`.
3. **Вызывает конструктор** с `this`, указывающим на новый объект: `Constructor.apply(instance, args)`.
4. **Выбирает результат:** если конструктор явно вернул объект или функцию, `new` вернёт его, а созданный объект будет выброшен. Если вернул примитив или ничего, результатом будет созданный объект.

### Пошаговый разбор особых случаев
- `WithObjectReturn` возвращает `{ b: 2 }`. Этот объект подменяет экземпляр, поэтому свойства `a` в результате нет. Так иногда реализуют синглтоны и фабрики «в обёртке» конструктора.
- `WithPrimitiveReturn` возвращает `42`, примитив игнорируется, результат — объект с `a: 1`.

### Граничные случаи и ошибки
- Проверка `typeof result === "object"` без `result !== null` ошибочна: `typeof null === "object"`, и `return null` в конструкторе вернул бы `null` вместо экземпляра.
- Функцию тоже нужно учитывать: если конструктор вернул функцию, `new` вернёт её.
- Старый способ `const obj = {}; obj.__proto__ = Constructor.prototype` работает, но `__proto__` устарел. `Object.create` и `Object.setPrototypeOf` — стандартные способы.
- Классы `class` так не создать: вызов класса без `new` (в том числе через `apply`) бросает `TypeError`. Для полноценной поддержки классов используют `Reflect.construct(Constructor, args)`.
- Стрелочные функции не имеют `prototype` и не могут быть конструкторами.

### Сложность
`O(1)` плюс время работы самого конструктора.

### Что запомнить для собеседования
- `new`: создать объект → связать с `Constructor.prototype` → вызвать конструктор с этим `this` → вернуть объект (если конструктор не вернул свой объект).
- Возвращённый из конструктора объект подменяет экземпляр, примитив игнорируется.
- `Reflect.construct` — встроенный способ вызвать конструктор «как через new».
