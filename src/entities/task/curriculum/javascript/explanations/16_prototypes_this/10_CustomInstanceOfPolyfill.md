### Что делает решение
Решение реализует точный алгоритм работы оператора `instanceof` согласно спецификации ECMAScript, выполняя поиск целевого объекта `Constructor.prototype` в цепочке прототипов проверяемого инстанса.

### Пошаговый разбор механизма JS Engine

1. **Проверка на примитивы**:
   - Любые примитивы (`"string"`, `123`, `true`, `Symbol()`, `null`, `undefined`) при проверке через `instanceof` всегда возвращают `false`, так как примитивы не имеют прототипной цепочки в памяти.
   - Обернутые объекты (`new String("abc")`, `new Number(123)`) являются объектами, поэтому для них проверка возвращает `true`.

2. **Метод `Symbol.hasInstance`**:
   - В ES6+ классы и функции могут переопределять поведение `instanceof` через статический метод `[Symbol.hasInstance](instance)`. Если он определен, движок вызывает его в первую очередь.

3. **Итеративный обход цепочки `[[Prototype]]`**:
   - `Object.getPrototypeOf(obj)` считывает внутреннее скрытое свойство `[[Prototype]]` (то же, что `__proto__`).
   - На каждом шаге цикла `currentProto` сравнивается по ссылке (`===`) с `Constructor.prototype`.
   - Если ссылка совпала — возвращается `true`. Если достигнут конец цепочки (`null` — вершина `Object.prototype`) — возвращается `false`.

### Граничные случаи и ошибки
- **Объекты из разных фреймов (iframes / realms)**: `instanceof` сравнивает ссылки на объекты `.prototype`. Если массив создан в одном `window`, а конструктор `Array` передан из другого, ссылки на `.prototype` не совпадут (`arr instanceof Array === false`). Для надежной проверки массивов в JS введен `Array.isArray()`.
- **`Constructor.prototype` не является объектом**: если конструктор был изменен так, что его `prototype` стал примитивом, движок выбрасывает `TypeError`.

### Сложность
- **По времени**: `O(d)` — где `d` — глубина цепочки прототипов (обычно от 1 до 5 уровней, поэтому фактически `O(1)`).
- **По памяти**: `O(1)` — обход по указателям без выделения памяти.

### Что запомнить для собеседования
- `instanceof` проверяет наличие `Constructor.prototype` в цепочке `[[Prototype]]`.
- Примитивы всегда возвращают `false`.
- `Symbol.hasInstance` позволяет кастомизировать поведение проверки.
- Для проверки массивов между iframes нужно использовать `Array.isArray()`, а не `instanceof`.
