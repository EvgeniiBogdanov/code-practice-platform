### Что делает решение
Решение демонстрирует современную объектную модель ES2022+ в JavaScript:
1. **Приватные поля (`#field`)**: инкапсуляция состояния на уровне движка JavaScript (hard privacy).
2. **Наследование (`extends` + `super`)**: вызов конструктора родительского класса `super()` и доступ к родительским методам через `super.method()`.
3. **Статические методы и свойства (`static`)**: объявление методов на самом классе и их автоматическое прототипное наследование в дочерних классах.

### Пошаговый разбор механизма JS Engine

1. **Приватные поля `#field` vs `_field`**:
   - Префикс `_field` — это лишь стилистическая конвенция, поле остается публичным и доступным в `Object.keys()` и при обращении `obj._field`.
   - Синтаксис `#field` реализует жесткую инкапсуляцию: попытка доступа снаружи (`counter.#count`) приводит к `SyntaxError: Private field '#count' must be declared in an enclosing class`. Поле невидимо для `Object.keys()`, `JSON.stringify()` и `Reflect.ownKeys()`.

2. **Правила вызова `super()`**:
   - В конструкторе класса-наследника обращение к `this` до вызова `super(...)` выбрасывает `ReferenceError: Must call super constructor in derived class before accessing 'this'`.

3. **Прототипное наследование статических методов**:
   - В JavaScript `extends` связывает не только прототипы экземпляров (`AdvancedCounter.prototype.__proto__ === BaseCounter.prototype`), но и сами функции-конструкторы (`AdvancedCounter.__proto__ === BaseCounter`).
   - Благодаря этому статические методы родителя (`BaseCounter.getDefaultStep()`) автоматически доступны на дочернем классе (`AdvancedCounter.getDefaultStep()`).

### Граничные случаи и ошибки
- **Попытка деструктурировать приватное поле**: `{ #count } = this` запрещено синтаксисом языка.
- **Проверка наличия приватного поля**: в ES2022 доступен оператор `#field in obj`.

### Сложность
- **По времени**: `O(1)` для всех операций чтения и инкремента.
- **По памяти**: `O(1)`.

### Что запомнить для собеседования
- Приватные поля `#` полностью изолированы на уровне движка (не видны в `Object.keys` и `Reflect.ownKeys`).
- В конструкторе наследника `super()` обязан вызываться ДО `this`.
- Статические методы наследуются дочерними классами через `ChildClass.__proto__ === ParentClass`.
