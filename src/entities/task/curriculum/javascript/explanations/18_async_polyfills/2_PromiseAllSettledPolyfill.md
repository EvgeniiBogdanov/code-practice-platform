# Полифил Promise.allSettled

## 1. Что делает allSettled

`Promise.allSettled` ждёт завершения всех входных операций независимо от результата каждой. Общий промис не должен отклоняться из-за отдельной ошибки. Вместо этого для каждого элемента возвращается объект одного из двух видов:

```js
{ status: "fulfilled", value: результат }
{ status: "rejected", reason: ошибка }
```

Это удобно, когда нужно показать пользователю полный отчёт: какие запросы сработали, а какие нет.

## 2. Главная идея решения

Обычный `Promise.all` уже умеет ждать массив промисов и сохранять порядок. Проблема только в том, что он останавливается на первом `reject`. Значит, нужно преобразовать каждый входной промис в новый промис, который **всегда завершается успешно**, но упаковывает исходный успех или ошибку в объект.

## 3. Разбор кода

```js
promises.map((promise) =>
  Promise.resolve(promise).then(
    (value) => ({ status: "fulfilled", value }),
    (reason) => ({ status: "rejected", reason })
  )
)
```

`Promise.resolve` позволяет принимать и промисы, и обычные значения. У `then` переданы два обработчика:

1. обработчик успеха возвращает объект со статусом `fulfilled`;
2. обработчик ошибки **тоже возвращает обычный объект**, а не бросает ошибку.

Возврат обычного объекта означает, что созданный цепочкой промис становится выполненным. Поэтому после `map` получается массив безопасных промисов, среди которых уже нет отклонённых.

```js
return Promise.all(wrappedPromises);
```

Теперь `Promise.all` спокойно ждёт все обёртки и возвращает массив отчётов в исходном порядке.

## 4. Почему нельзя написать только catch

Вариант `.catch(() => undefined)` скроет сам факт ошибки и потеряет её причину. Формат `{ status, value/reason }` сохраняет всю информацию и позволяет вызывающему коду явно обработать каждый результат.

## 5. Граничные случаи

- Пустой массив корректно даёт `[]`, потому что это уже умеет `Promise.all([])`.
- Обычное значение становится `{ status: 'fulfilled', value }`.
- Ошибка может быть не объектом `Error`, а строкой или любым другим значением; её нужно сохранить в `reason` без изменений.
- Все операции запускаются сразу. `allSettled` не ограничивает параллелизм.

## 6. Сложность

Преобразование и сбор результата требуют `O(n)` времени и `O(n)` памяти. Фактическое ожидание заканчивается после самой долгой операции, успешной или неуспешной.

## 7. Что запомнить

`allSettled` строится из двух идей: превратить любой исход в успешный объект-отчёт, затем применить обычный `Promise.all`.
