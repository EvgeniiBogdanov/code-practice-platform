# Полифилы Promise.race и Promise.any

## 1. В чём различие

Обе функции запускают все переданные операции сразу, но выбирают победителя по разным правилам:

- `Promise.race` берёт **первый завершившийся** промис — неважно, успешно или с ошибкой;
- `Promise.any` берёт **первый успешный** промис и игнорирует ошибки, пока остаётся шанс на успех.

## 2. Как работает promiseRace

```js
return new Promise((resolve, reject) => {
  promises.forEach((promise) => {
    Promise.resolve(promise).then(resolve, reject);
  });
});
```

Каждый элемент подключён к одним и тем же `resolve` и `reject` общего промиса. Какой обработчик вызовется первым, тот и зафиксирует состояние. Остальные операции продолжат выполняться, но изменить уже завершённый промис не смогут.

`Promise.resolve` снова нужен для обычных значений. Такое значение становится уже выполненным промисом и, скорее всего, выиграет гонку на ближайшем проходе очереди микрозадач.

Пустой `race([])` остаётся `pending` навсегда: нет ни одного участника, который мог бы вызвать `resolve` или `reject`. Это соответствует поведению нативного метода.

## 3. Как работает promiseAny

```js
const errors = [];
let rejectedCount = 0;
```

Успешный результат можно сразу передать в `resolve`. Ошибки приходится накапливать: общий промис должен отклониться только тогда, когда отклонились **все** участники.

```js
Promise.resolve(promise)
  .then(resolve)
  .catch((error) => {
    errors[index] = error;
    rejectedCount += 1;
    if (rejectedCount === total) {
      reject(new AggregateError(errors, "All promises were rejected"));
    }
  });
```

Ошибки записываются по исходному индексу, поэтому массив `AggregateError.errors` не зависит от порядка завершения. Счётчик отличает промежуточную ошибку от ситуации «успеха уже не будет».

## 4. Особый случай пустого массива

`Promise.any([])` сразу отклоняется с `AggregateError`: среди нуля участников невозможно найти успешный. Это противоположно `Promise.all([])`, который сразу успешно возвращает пустой массив.

## 5. Частые ошибки

- Реализовать `any` как `race` и отклониться при первой ошибке.
- Потерять порядок ошибок, используя `errors.push(error)`.
- Забыть про `AggregateError` и пустой массив.
- Считать, что проигравшие операции отменяются. Агрегаторы Promise сами ничего не отменяют; для отмены нужен отдельный механизм, например `AbortController`.

## 6. Сложность

Подписка на участников занимает `O(n)`. `race` использует `O(1)` дополнительной памяти, а `any` — `O(n)` для возможных ошибок.

## 7. Что запомнить

`race` отвечает на вопрос «кто завершился первым?», а `any` — «кто первым завершился успешно?».
