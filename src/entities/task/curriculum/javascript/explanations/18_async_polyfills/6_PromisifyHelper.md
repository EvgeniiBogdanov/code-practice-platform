# Преобразование callback API в Promise

## 1. Что такое promisify

Старые Node.js API часто принимают callback последним аргументом:

```js
readFile(path, (error, data) => { ... });
```

`promisify(fn)` создаёт новую функцию с теми же входными аргументами, но вместо callback возвращает промис. После этого её можно использовать через `await` и обычный `try/catch`.

## 2. Контракт error-first callback

Решение опирается на соглашение `(error, result) => ...`:

- если `error` содержит значение, операция считается неуспешной;
- если ошибки нет, полезный результат находится во втором аргументе.

Без такого контракта универсальный `promisify` не сможет понять, какой аргумент означает ошибку.

## 3. Пошаговый разбор

```js
const promisify = (fn) => {
  return (...args) => {
    return new Promise((resolve, reject) => {
      fn(...args, (error, result) => {
        if (error) return reject(error);
        resolve(result);
      });
    });
  };
};
```

Внешняя функция получает исходную `fn` и возвращает новую функцию. `...args` собирает все пользовательские аргументы, а затем решение добавляет к ним собственный callback.

При ошибке вызывается `reject(error)`. `return` завершает callback и не позволяет коду дойти до `resolve`. При успехе вызывается `resolve(result)`.

Если `fn` синхронно бросит исключение внутри конструктора `new Promise`, конструктор автоматически превратит его в отклонение промиса.

## 4. Пример использования

```js
const readFileAsync = promisify(readFile);

try {
  const text = await readFileAsync("notes.txt", "utf8");
  console.log(text);
} catch (error) {
  console.error(error);
}
```

Поток управления становится линейным: результат читается как обычное возвращаемое значение, а ошибка обрабатывается в одном месте.

## 5. Ограничения и ловушки

- Некоторые API передают несколько успешных результатов. Базовая версия сохраняет только первый `result`.
- Метод объекта может зависеть от `this`. Вызов `fn(...args)` потеряет контекст; тогда нужно применять `fn.call(this, ...args, callback)` и вернуть обычную функцию, а не стрелку.
- Не всякий callback использует error-first формат.
- Promisify не отменяет исходную операцию автоматически.

## 6. Сложность

Обёртка добавляет `O(1)` работы и памяти на вызов; основная стоимость определяется исходной асинхронной операцией.

## 7. Что запомнить

Promisify — это адаптер между двумя стилями API. Он не меняет саму операцию, а переводит сигнал callback в `resolve` или `reject`.
