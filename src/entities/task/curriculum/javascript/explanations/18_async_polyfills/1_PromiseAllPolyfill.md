# Полифил Promise.all

## 1. Что требуется от функции

`promiseAll` получает массив промисов или обычных значений и возвращает один промис. Он должен:

- дождаться успешного завершения всех элементов;
- вернуть результаты в том же порядке, в котором элементы были переданы;
- немедленно отклониться с первой полученной ошибкой;
- вернуть `[]`, если входной массив пуст.

Важно разделять порядок завершения и порядок результата. Второй промис может завершиться раньше первого, но его значение всё равно должно остаться на позиции `1`.

## 2. Ментальная модель

Представьте таблицу с одной ячейкой для каждого входного элемента. Каждый завершившийся промис записывает значение именно в свою ячейку. Отдельный счётчик показывает, сколько ячеек уже заполнено. Когда счётчик становится равен длине входного массива, можно завершить общий промис.

## 3. Пошаговый разбор решения

```js
const results = [];
let completed = 0;
const total = promises.length;
```

`results` хранит значения, `completed` — количество успешно завершённых операций, `total` — сколько результатов ожидается.

```js
if (total === 0) return resolve([]);
```

Без этой ветки пустой массив никогда не запустил бы `forEach`, счётчик не изменился бы, а возвращённый промис навсегда остался бы в состоянии `pending`.

```js
promises.forEach((promise, index) => {
  Promise.resolve(promise).then((value) => {
    results[index] = value;
    completed += 1;
    if (completed === total) resolve(results);
  }).catch(reject);
});
```

`Promise.resolve` нормализует вход: с настоящим промисом он работает как с промисом, а обычное значение превращает в уже выполненный промис. Запись по `index`, а не через `push`, сохраняет исходный порядок. Передача `reject` в `catch` реализует fail-fast: первая ошибка отклоняет общий промис. Последующие завершения уже не изменят его состояние — промис меняет состояние только один раз.

## 4. Пример порядка

Если задачи завершаются как `B` через 10 мс и `A` через 50 мс, но переданы как `[promiseA, promiseB]`, результат будет `['A', 'B']`, а не `['B', 'A']`.

## 5. Частые ошибки

- Использовать `results.push(value)` и тем самым возвращать порядок завершения.
- Не обработать пустой массив.
- Не оборачивать обычные значения через `Promise.resolve`.
- Ждать остальные операции после ошибки. `Promise.all` отклоняется сразу, хотя уже запущенные операции физически не отменяются.

## 6. Сложность

Время после запуска определяется самой медленной успешной операцией; обработка результатов занимает `O(n)`. Дополнительная память — `O(n)` для массива результатов.

## 7. Что запомнить

`Promise.all` — это «все успешно или первая ошибка». Индекс отвечает за порядок, счётчик — за момент общего успеха, а `Promise.resolve` — за единообразную работу с промисами и обычными значениями.
