# Хелпер условных CSS-классов

## 1. Зачем нужен classNames

Функция принимает значения разных форм и собирает из них одну строку CSS-классов:

```js
classNames("button", { active: true, disabled: false });
// "button active"
```

Это позволяет декларативно описывать условия без ручной конкатенации строк.

## 2. Общий алгоритм

Создаётся массив `classes`. Каждый аргумент проверяется по типу, допустимые классы добавляются, а в конце соединяются одним пробелом.

```js
if (!arg) continue;
```

Falsy-значения пропускаются: `null`, `undefined`, `false`, пустая строка, `0` и `NaN`. Поэтому число `0` не станет классом, а число `1` станет.

## 3. Строки, числа и массивы

Строки и числа добавляются напрямую. Массивы обрабатываются рекурсивно:

```js
const inner = classNames(...arg);
if (inner) classes.push(inner);
```

Рекурсия поддерживает любую глубину: `['a', ['b', { c: true }]]`. Внутренняя строка добавляется одним элементом, а итоговый `join` всё равно создаёт корректные пробелы.

## 4. Объекты условий

Для обычного объекта перебираются собственные перечислимые ключи. Ключ попадает в результат только при truthy-значении:

```js
{ active: true, hidden: 0 } // -> "active"
```

Проверка `hasOwnProperty.call` не позволяет случайно добавить унаследованные ключи.

Отдельная ветка поддерживает объекты с пользовательским `toString`: результат этого метода считается готовым именем класса. Это поведение повторяет совместимость популярных библиотек, но делает контракт сложнее.

## 5. Граничные случаи

- Дубликаты не удаляются: `classNames('a', 'a')` вернёт `'a a'`. Обычно это безвредно.
- Значение объекта проверяется на truthy, а не строго на `true`.
- Symbol и функции игнорируются.
- Циклический массив вызовет бесконечную рекурсию.
- Вызов пользовательского `toString` может иметь побочные эффекты или бросить ошибку.
- Результат не валидирует синтаксис CSS-класса — ответственность остаётся у вызывающего кода.

## 6. Сложность

Каждый элемент и ключ посещается один раз: `O(n)` времени. Массив классов и строка результата занимают `O(n)` памяти; глубина рекурсии зависит от вложенности массивов.

## 7. Что запомнить

Полезная утилита нормализует несколько входных форм: примитив становится классом, массив рекурсивно раскрывается, объект фильтрует ключи по значению, falsy-аргументы исчезают.
