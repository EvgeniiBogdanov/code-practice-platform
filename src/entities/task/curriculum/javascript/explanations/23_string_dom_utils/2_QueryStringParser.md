# Парсер и сериализатор Query String

## 1. Два направления преобразования

`parseQueryString` превращает URL или строку запроса в объект. `stringifyQuery` делает обратное преобразование.

```js
parseQueryString("?q=hello&tags=js&tags=web&debug");
// { q: "hello", tags: ["js", "web"], debug: true }
```

## 2. Извлечение query-части

Функция ищет `?`. Если он есть, берётся всё после него; иначе вход считается сырой query-строкой. Затем часть после `#` отбрасывается, потому что fragment не относится к query parameters.

Пустая строка возвращает `{}`. Дополнительные проверки не позволяют ошибочно разобрать обычный URL без `?` как набор параметров.

## 3. Разбор одной пары

Строка делится по `&`. Для каждого непустого фрагмента ищется **первый** `=` через `indexOf`. Это важно: значение может само содержать закодированный знак равенства.

- Фрагмент без `=` становится флагом со значением `true`.
- Фрагмент с `=` делится на key и value.
- Обе части проходят через `decodeURIComponent`.

Если ключ встречается повторно, первое значение превращается в массив, а следующие добавляются в него. Проверка выполняется через безопасный `Object.prototype.hasOwnProperty.call`, поэтому ключи прототипа не путаются с уже записанными данными.

## 4. Сериализация

`Object.entries` обходит пары объекта. `null` и `undefined` пропускаются. Ключи и значения кодируются через `encodeURIComponent`, чтобы пробелы, кириллица, `&` и `=` не ломали формат.

Массив превращается в повторяющийся ключ:

```text
tags=js&tags=web
```

Обычное значение создаёт одну пару. В конце части соединяются через `&`.

## 5. Важные договорённости

- Текущий parser не превращает `+` в пробел. В HTML-формах `hello+world` часто означает `hello world`, поэтому перед decode может понадобиться замена `+` на пробел.
- Некорректная percent-encoding последовательность заставит `decodeURIComponent` бросить `URIError`; production-версия должна решить, пропускать пару или возвращать ошибку.
- Флаг `debug` после обратной сериализации станет `debug=true`. Полная строка не обязана совпасть посимвольно, хотя смысл данных сохранится.
- Вложенные объекты не имеют стандартного единственного формата; текущая версия сериализует их как строку `[object Object]`.
- Порядок ключей и повторов сохраняется в рамках правил обхода объекта.

## 6. Сложность

Обе функции линейны относительно длины входной строки или числа сериализуемых значений: `O(n)` времени и `O(n)` памяти на результат.

## 7. Что запомнить

Нельзя делить query «как попало»: нужно отделить `?` и `#`, кодировать спецсимволы, поддержать повторные ключи и заранее определить формат флагов, массивов и пустых значений.
