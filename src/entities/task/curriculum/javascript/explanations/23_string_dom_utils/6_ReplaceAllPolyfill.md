### Что делает решение
Решение реализует точный полифил метода `String.prototype.replaceAll` в полном соответствии со спецификацией ECMAScript (ES2021):
1. Выполняет строгую проверку типа аргумента `searchValue`: если передан экземпляр `RegExp` без обязательного глобального флага `g`, выбрасывается `TypeError: String.prototype.replaceAll called with a non-global RegExp argument`.
2. Для строкового шаблона поиска `searchValue` выполняет последовательную замену абсолютно всех вхождений подстроки без привлечения регулярных выражений, что гарантирует безопасность при наличии спецсимволов (`+`, `*`, `?`, `[`, `]`, `(`, `)`).
3. Поддерживает как строковое значение замены, так и динамическую функцию обратного вызова `replaceValue(match, offset, string)`.

### Почему не стоит использовать `new RegExp(searchValue, 'g')`

1. **Проблема неэкранированных спецсимволов RegExp**:
   - Если искомая подстрока содержит метасимволы регулярных выражений (например, `customReplaceAll("2 + 2 = 4", "+", "plus")`), попытка создания `new RegExp("+", "g")` немедленно выбросит фатальную ошибку `SyntaxError: Invalid regular expression`.
   - Подход на базе `indexOf` и итеративного среза строки (либо `split/join` для статических строк) полностью изолирован от синтаксиса регулярных выражений и работает значительно быстрее.

2. **Защита от логических ошибок с не-глобальными регулярками**:
   - Авторы спецификации JS намеренно ввели требование выбрасывать `TypeError` при вызове `replaceAll(/pattern/, replacement)` без флага `g`, чтобы предотвратить скрытые баги в коде разработчиков, ожидавших глобальную замену.

### Граничные случаи и ошибки
- **Пустая искомая строка `""`**: нативный `replaceAll` разбивает строку на отдельные символы и помещает значение замены между каждым символом и по краям строки.
- **`RegExp` без флага `g`**: обязательный выброс исключения `TypeError`.
- **Строка без совпадений**: возвращает точную копию исходной строки без лишних аллокаций.

### Сложность
- **По времени**: `O(N + M)` — где $N$ — длина исходной строки, $M$ — суммарная длина всех замененных фрагментов.
- **По памяти**: `O(N + M)` — выделение памяти под новую результирующую строку.

### Что запомнить для собеседования
- `String.prototype.replaceAll` с не-глобальным `RegExp` всегда выбрасывает `TypeError`.
- Поиск по строке заменяет все вхождения, в отличие от устаревшего `replace(str, replacement)`, который меняет только первое вхождение.
