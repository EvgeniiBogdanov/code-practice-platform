### Что делает решение
Решение безопасно разворачивает строки, содержащие любые символы Unicode (эмодзи, суррогатные пары, модификаторы):
1. Использует современный стандарт `Intl.Segmenter(..., { granularity: "grapheme" })` для выделения неделимых графемных кластеров (`grapheme clusters`).
2. Предоставляет fallback через `Array.from(str)` (или `[...str]`), который итерирует строку по кодовым точкам (`code points`), сохраняя целостность 32-битных суррогатных пар.
3. Разворачивает массив графем и склеивает его обратно.

### Почему `split('')` ломает эмодзи

1. **Кодировка UTF-16 в JavaScript**:
   - Строки в JS индексируются по 16-битным кодовым единицам (`code units`).
   - Символы за пределами базовой многоязыковой плоскости (BMP), включая все современные эмодзи, представляются парой 16-битных чисел (`high surrogate` + `low surrogate`).
   - Вызов `"".split('')` дает `['\uD83D', '\uDC4B']`. Реверс меняет их местами на `['\uDC4B', '\uD83D']`, что является невалидной последовательностью UTF-16.

2. **Графемные кластеры**:
   - Некоторые символы состоят из нескольких кодовых точек (например, эмодзи с тоном кожи `` или флаги стран). `Intl.Segmenter` сохраняет их как единое целое.

### Граничные случаи и ошибки
- **Пустая строка `""`**: возвращает `""`.
- **Не-строка**: возвращает `""`.
- **Строка из одних суррогатных пар**: сохраняет все пары валидными.

### Сложность
- **По времени**: `O(n)` — линейный разбор графем и реверс массива.
- **По памяти**: `O(n)` — массив сегментов.

### Что запомнить для собеседования
- Никогда не используйте `str.split('')` для строк с неизвестным содержимым (эмодзи, спецсимволы).
- `[...str]` или `Array.from(str)` разбивают строку по кодовым точкам (code points).
- `Intl.Segmenter` разбивает строку по графемам (grapheme clusters).
