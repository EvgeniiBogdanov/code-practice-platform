### Что делает решение
Решение реализует полифил метода `Array.prototype.map` (`customMap` / `myMap`) в строгом соответствии со спецификацией ECMAScript:
1. Выполняет предварительную валидацию: если объект вызова `null`/`undefined` или `callback` не функция — выбрасывается `TypeError`.
2. Фиксирует длину массива через `length >>> 0` (ToLength алгоритм).
3. Создает результирующий массив `new Array(len)` и обходит только существующие индексы с помощью оператора `i in obj`, корректно сохраняя пустые слоты (empty slots) в разреженных массивах (`sparse arrays`).
4. Передает контекст `thisArg` в callback через `callback.call(thisArg, element, index, array)`.

### Пошаговый разбор механизма JS Engine

1. **Разреженные массивы (Sparse Arrays)**:
   - В массиве `[1, , 3]` индекс `1` не существует (`1 in arr === false`).
   - Нативный `map` не вызывает callback для отсутствующих индексов, сохраняя слот пустым (`<empty>`), в отличие от случая, когда в слоте явно записано значение `undefined`.
   - Проверка `i in obj` гарантирует сохранение структуры разреженного массива.

2. **Нормализация длины `>>> 0`**:
   - Беззнаковый бинарный сдвиг вправо `>>> 0` преобразует любое значение в 32-битное целое положительное число (стандартный паттерн polyfills для `ToLength`).

3. **Контекст `thisArg`**:
   - Третий аргумент `thisArg` позволяет безопасно привязать контекст к обычной функции без необходимости создавать лишнее замыкание или использовать стрелочную функцию.

### Граничные случаи и ошибки
- **Мутация массива во время обхода**: элементы, добавленные в исходный массив после начала вызова `customMap`, не обрабатываются, так как `len` фиксируется заранее.
- **Удаление элементов во время обхода**: если элемент был удален до того, как итератор дошел до его индекса, `i in obj` вернет `false` и callback вызван не будет.
- **`thisArg` со стрелочной функцией**: у стрелочной функции собственный `this` отсутствует, поэтому `thisArg` для нее не переопределит контекст.

### Сложность
- **По времени**: `O(n)` — один линейный проход по элементам массива.
- **По памяти**: `O(n)` — выделение нового массива размера `n` для результатов трансформации.

### Что запомнить для собеседования
- `map` всегда возвращает **новый** массив той же длины, не мутируя оригинал.
- `callback` принимает 3 аргумента: `(element, index, array)`.
- Для разреженных массивов проверка `i in array` обязательна.
- Если callback не функция — обязателен выброс `TypeError`.
