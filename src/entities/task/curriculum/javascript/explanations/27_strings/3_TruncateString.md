### Что делает решение
1. Если строка помещается в лимит (`str.length <= maxLength`), возвращаем её без изменений.
2. Иначе берём первые `maxLength - 1` символов через `slice(0, maxLength - 1)` и добавляем многоточие `"…"`.

Почему `maxLength - 1`: символ `"…"` (U+2026) — **один** символ, а итоговая длина должна быть ровно `maxLength`. Если использовать три точки `"..."`, нужно оставлять `maxLength - 3` символа.

### Где это встречается
Обрезка заголовков карточек, превью сообщений, названий файлов. На собеседовании задачу часто развивают дальше:
- не резать слово посередине (обрезать по последнему пробелу перед лимитом);
- поддержать параметр-суффикс (`truncate(str, 20, "...")`);
- учесть эмодзи и составные символы.

### Граничные случаи и ошибки
- Условие `>`, а не `>=`: строка длиной ровно `maxLength` не должна обрезаться (`truncate("abc", 3)` → `"abc"`).
- `slice` с отрицательным концом считает с конца строки. Если `maxLength = 0`, то `slice(0, -1)` вернёт почти всю строку — для некорректного лимита нужна отдельная проверка.
- `length` считает UTF-16 code units: эмодзи займёт 2, и `slice` может разрезать его пополам. Для пользовательского текста с эмодзи используйте `Intl.Segmenter` или хотя бы `[...str]`.
- В интерфейсе визуальное усечение часто делают CSS-ом: `text-overflow: ellipsis` вместе с `overflow: hidden` и `white-space: nowrap`. Обрезка в JS нужна, когда строка уходит в данные (уведомления, мета-теги).

### Сложность
- По времени: `O(maxLength)` на копирование части строки.
- По памяти: `O(maxLength)`.

### Что запомнить для собеседования
- `"…"` — один символ, поэтому `slice(0, maxLength - 1)`.
- Проверяйте границу: строка ровно на лимите не обрезается.
- Знайте CSS-альтернативу `text-overflow: ellipsis`.
