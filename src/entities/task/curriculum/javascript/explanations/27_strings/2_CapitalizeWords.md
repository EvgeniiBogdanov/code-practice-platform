### Что делает решение
`capitalize` склеивает две части строки:
- `str.charAt(0).toUpperCase()` — первый символ в верхнем регистре;
- `str.slice(1)` — вся строка начиная со второго символа, без изменений.

`capitalizeWords` разбивает предложение на слова, применяет `capitalize` к каждому через `map` и собирает обратно. Повторное использование маленькой функции — именно то, что интервьюер хочет увидеть вместо дублирования логики.

### Почему `charAt(0)`, а не `str[0]`
Для пустой строки `""[0]` — это `undefined`, и вызов `undefined.toUpperCase()` бросит `TypeError`. `"".charAt(0)` возвращает пустую строку, поэтому функция корректно работает на `""` без дополнительной проверки. Альтернатива — явная проверка `if (!str) return str;` в начале.

### Граничные случаи и ошибки
- Задача — сделать заглавной **только первую** букву. Если вызвать `toLowerCase()` для остальной части, `"javaScript"` превратится в `"Javascript"` и `"FUN"` — в `"Fun"`. Это другая задача (title case), уточняйте требования.
- `split(" ")` при двойных пробелах даст пустые строки. `capitalize("")` их не ломает, и исходные пробелы сохраняются.
- `toUpperCase` корректно работает с кириллицей и большинством алфавитов. Для языков со специальными правилами регистра (например, турецкая `i`) есть `toLocaleUpperCase("tr")`.
- Для чисто визуального эффекта в интерфейсе можно использовать CSS `text-transform: capitalize`, не меняя данные.

### Сложность
- `capitalize`: `O(n)` — `slice` копирует строку.
- `capitalizeWords`: `O(n)` по времени и памяти.

### Что запомнить для собеседования
- `charAt(0)` безопасен для пустой строки, `str[0]` — нет.
- `slice(1)` возвращает «хвост» строки.
- Сложную обработку строк удобно собирать из `split` → `map` → `join`.
