### Что делает решение
Строки в JavaScript **неизменяемы**: метода `reverse` у них нет, а присваивание `str[0] = "x"` молча ничего не делает (в строгом режиме бросает `TypeError`). Поэтому разворот делается через массив:
1. `[...str]` — разбиваем строку на массив символов;
2. `.reverse()` — разворачиваем массив (мутация нового массива безопасна);
3. `.join("")` — склеиваем обратно в строку.

Для слов то же самое, только единица разбиения — слово: `split(/\s+/)` делит по одному или нескольким пробельным символам, а `trim()` заранее убирает пробелы по краям. Без `trim` в начале массива окажется пустая строка `""`.

### Почему `[...str]`, а не `str.split("")`
`split("")` делит строку на UTF-16 code units, а spread — на кодовые точки Unicode. Для обычного текста результат одинаковый, но эмодзи (`"😀"`) занимают два code unit. `split("")` разорвёт такой символ пополам и сломает его. Полностью корректный разворот с эмодзи-последовательностями и составными символами разбирается в задаче «Разворот строки с поддержкой Unicode».

### Вариант с циклом
Интервьюер может запретить встроенные методы. Тогда проходим строку с конца и накапливаем результат. Конкатенация строк в цикле в современных движках оптимизирована (rope-строки), поэтому на практике работает быстро.

### Граничные случаи и ошибки
- Пустая строка должна вернуть `""`.
- `"  много   пробелов  ".split(" ")` даёт много пустых строк — нужна регулярка `/\s+/` или фильтрация.
- Палиндромы проверяют сравнением `str === reverseString(str)`, но для длинных строк выгоднее метод двух указателей без создания копии.

### Сложность
- По времени: `O(n)`.
- По памяти: `O(n)` на массив символов и новую строку.

### Что запомнить для собеседования
- Строки неизменяемы, любые «изменения» создают новую строку.
- `[...str].reverse().join("")` — стандартный ответ; spread корректнее `split("")` для эмодзи.
- Для слов: `trim()` + `split(/\s+/)`.
