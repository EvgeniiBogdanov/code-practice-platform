## Что делает решение

Функция проходит по односвязному списку от головы до конца и суммирует значения узлов:

```js
const sumLinkedList = (head) => {
  let sum = 0;
  let current = head;

  while (current !== null) {
    sum += current.value;
    current = current.next;
  }

  return sum;
};
```

Узел списка содержит значение и ссылку на следующий узел:

```js
{ value: 10, next: { value: 20, next: null } }
```

`null` — специальный маркер конца цепочки. В отличие от массива, у списка нет индекса и длины, поэтому цикл движется по ссылкам `next`.

## Пошаговый разбор

`current` — указатель на узел, который обрабатывается сейчас. Сначала он указывает на `head`. Для списка `10 → 20 → 30 → null`:

| `current.value` | `sum` после сложения | следующий `current` |
|---:|---:|---|
| `10` | `10` | узел `20` |
| `20` | `30` | узел `30` |
| `30` | `60` | `null` |

После перехода к `null` условие становится ложным, и возвращается `60`.

Порядок двух строк в теле важен. Сначала нужно прочитать `current.value`, затем передвинуть указатель. Если сначала выполнить `current = current.next`, значение головы будет пропущено, а в конце может произойти обращение к свойству `null`.

Функция не изменяет список: она переназначает только локальный указатель. Объекты узлов и их поля `next` остаются прежними. Полезный инвариант: перед каждой итерацией `sum` содержит сумму всех уже пройденных узлов, а `current` указывает на первый ещё не обработанный узел.

## Почему while здесь естественнее счётного for

Количество узлов заранее может быть неизвестно. Условие продолжения определяется не числовым индексом, а существованием следующего узла. Запись `while (current !== null)` прямо выражает структуру данных: «продолжать, пока текущий узел существует».

Рекурсивная версия короче, но каждый узел добавляет кадр в стек вызовов. Итеративный вариант обрабатывает длинные списки без риска переполнить стек.

## Граничные случаи и ошибки

- Пустой список представлен `head === null`; цикл не запускается и возвращает нейтральную сумму `0`.
- Если вместо `null` конец обозначен `undefined`, строгая проверка пропустит завершение и затем попытается прочитать `current.value`. Структура и функция должны согласовать единый контракт.
- Циклический список, где `next` ссылается на уже посещённый узел, приведёт к бесконечному циклу. Для недоверенных данных цикл обнаруживают через `Set` посещённых узлов или алгоритм двух указателей.
- Строковое `value` вызовет конкатенацию после первого сложения со строкой. Для строгой функции значения следует валидировать как числа.
- Отсутствующее поле `next` и повреждённый узел вызовут ошибку на следующей итерации.

## Сложность

Для списка из `n` узлов каждый узел посещается один раз: время `O(n)`, дополнительная память `O(1)`. Рекурсивная версия также требует `O(n)` времени, но использует `O(n)` памяти стека.

## Что запомнить

При обходе связного списка храните отдельный указатель `current`: обработайте текущий узел, затем обязательно сдвиньте указатель на `current.next`. Нейтральное начальное значение позволяет естественно обработать пустой список, а явный маркер конца защищает логику от неоднозначности.
