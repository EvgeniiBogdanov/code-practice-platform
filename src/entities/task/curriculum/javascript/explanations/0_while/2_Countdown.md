## Что делает решение

Функция выводит числа от переданного `n` до `1` включительно:

```js
const countdown = (n) => {
  while (n > 0) {
    console.log(n);
    n--;
  }
};
```

Параметр `n` одновременно играет две роли: это текущее выводимое значение и состояние, от которого зависит продолжение цикла. Пока `n > 0`, число печатается, после чего уменьшается на единицу.

## Пошаговый разбор

Для вызова `countdown(3)` состояние меняется так:

| Проверка | Вывод | `n` после `n--` |
|---|---:|---:|
| `3 > 0` → `true` | `3` | `2` |
| `2 > 0` → `true` | `2` | `1` |
| `1 > 0` → `true` | `1` | `0` |
| `0 > 0` → `false` | — | `0` |

Сначала выполняется `console.log(n)`, а затем `n--`. Именно такой порядок сохраняет единицу в выводе и не выводит ноль. Условие `n >= 0` дало бы лишний `0`, а декремент перед `console.log` пропустил бы исходное значение.

Изменение параметра внутри функции не меняет внешнюю числовую переменную:

```js
let start = 3;
countdown(start);
console.log(start); // 3
```

Число — примитив. В параметр попадает его значение, а локальная переменная `n` уменьшается только внутри вызова.

## Компактный вариант

В альтернативном решении написано:

```js
while (n) console.log(n--);
```

Важно точно прочитать этот код: проверяется текущее `n`, а постфиксный декремент находится в аргументе `console.log`. Сначала `n--` возвращает старое значение для печати, затем уменьшает локальную переменную. Это не то же самое, что `while (n--)`: в последнем варианте декремент выполнялся бы прямо при проверке, включая финальную проверку нуля.

Короткая форма работает для положительных целых чисел, но скрывает условие остановки и объединяет вывод с изменением состояния. Для junior-разбора рекомендуемый многострочный вариант безопаснее и легче отлаживается.

## Граничные случаи и ошибки

- При `n = 0` или отрицательном `n` рекомендуемый цикл не выполнится ни разу.
- Дробное `n`, например `2.5`, выведет `2.5`, `1.5`, `0.5`. Если нужны только целые значения, вход следует проверить через `Number.isInteger(n)`.
- `Infinity` никогда не уменьшится до нуля: `Infinity - 1` всё ещё `Infinity`, поэтому цикл станет бесконечным.
- В компактном `while (n)` отрицательные числа истинны. Они будут уменьшаться дальше и также не приведут цикл к завершению.
- Функция выводит данные как побочный эффект и возвращает `undefined`. Если результат нужен для дальнейшей обработки или тестов, удобнее накапливать числа в массиве и возвращать его.

## Сложность

Для положительного целого `n` выполняется ровно `n` итераций: время `O(n)`, дополнительная память `O(1)`. Консоль может сама хранить историю сообщений, но это поведение среды, а не память алгоритма.

## Что запомнить

У счётного `while` должны быть явные начальное значение, условие и шаг. Проверка `n > 0` документирует допустимое направление отсчёта лучше, чем неявное `while (n)`. Следите за порядком вывода и декремента: от него напрямую зависят границы последовательности.
