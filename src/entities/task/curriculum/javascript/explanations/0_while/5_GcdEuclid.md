## Что делает решение

Функция находит наибольший общий делитель двух чисел с помощью алгоритма Евклида:

```js
const gcd = (a, b) => {
  let x = Math.abs(a);
  let y = Math.abs(b);

  while (y !== 0) {
    const temp = y;
    y = x % y;
    x = temp;
  }

  return x;
};
```

Наибольший общий делитель, или НОД, — самое большое положительное целое число, на которое оба исходных числа делятся без остатка. Например, для `48` и `18` ответ равен `6`.

## Идея алгоритма

Алгоритм основан на равенстве:

```text
gcd(x, y) = gcd(y, x % y)
```

Если число делит и `x`, и `y`, то оно делит остаток `x % y`. И наоборот, общий делитель `y` и остатка делит исходное `x`. Поэтому пару можно заменить меньшей парой, не изменив ответ.

Трассировка для `gcd(48, 18)`:

| `x` | `y` | `x % y` | следующая пара |
|---:|---:|---:|---|
| `48` | `18` | `12` | `(18, 12)` |
| `18` | `12` | `6` | `(12, 6)` |
| `12` | `6` | `0` | `(6, 0)` |

Когда второй элемент пары становится нулём, первый содержит НОД — `6`.

## Зачем нужна временная переменная

Оба значения должны обновиться на основе старой пары. После вычисления остатка старое `y` должно стать новым `x`:

```js
const temp = y;
y = x % y;
x = temp;
```

Если сначала написать `x = y`, а затем `y = x % y`, вторая строка использует уже изменённый `x` и всегда получит `0`. Эквивалентная компактная запись через деструктуризацию — `[x, y] = [y, x % y]`: правая часть вычисляется до присваиваний.

`Math.abs` делает знак входных чисел несущественным. Это расширяет фактическое поведение решения по сравнению с условием о положительных числах.

## Граничные случаи и ошибки

- `gcd(a, 0)` возвращает `|a|`, потому что цикл не запускается.
- `gcd(0, b)` после одной итерации возвращает `|b|`.
- Реализация возвращает `0` для `(0, 0)`, хотя в математике НОД этой пары обычно считают неопределённым. Контракт приложения должен решить, допустимо ли это.
- Алгоритм предназначен для целых чисел. Остатки дробных IEEE 754-чисел подвержены погрешности и не выражают обычный целочисленный НОД.
- `NaN` и `Infinity` могут привести к некорректному результату или незавершающемуся циклу. Для строгого API стоит проверять `Number.isSafeInteger`.
- Для `BigInt` нужна отдельная версия без `Math.abs`, использующая `0n` и операции только над `BigInt`.

## Сложность

Время работы — `O(log(min(|a|, |b|)))`; худшие последовательности шагов связаны с соседними числами Фибоначчи. Дополнительная память — `O(1)`, потому что хранятся только два рабочих значения и остаток.

## Что запомнить

Главный инвариант алгоритма: замена `(x, y)` на `(y, x % y)` не меняет НОД, но уменьшает второй элемент, пока он не станет нулём. В реализации особенно важны целочисленный контракт и корректный порядок одновременного обновления переменных.
