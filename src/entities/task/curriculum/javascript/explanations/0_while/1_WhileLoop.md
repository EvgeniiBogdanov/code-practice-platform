## Что делает решение

`while` повторяет блок кода, пока условие в круглых скобках приводится к `true`.

```js
while (true) {
  // Бесконечный цикл
}
```

Здесь условие — литерал `true`. Он никогда не меняется, поэтому после каждой итерации JavaScript снова входит в тело цикла. Сам по себе этот фрагмент **никогда не завершится**. Это демонстрация синтаксиса, а не код, который следует запускать без механизма выхода.

Общая форма цикла выглядит так:

```js
while (условие) {
  // действия одной итерации
}
```

## Как выполняется while

Перед каждой итерацией движок действует в одном порядке:

1. Вычисляет выражение `условие`.
2. Приводит результат к логическому значению.
3. Если получилось `false`, переходит к коду после цикла.
4. Если получилось `true`, выполняет тело и возвращается к первому шагу.

Поэтому обычный конечный цикл должен содержать состояние, которое приближает условие к `false`:

```js
let count = 3;

while (count > 0) {
  console.log(count);
  count--;
}
```

Здесь есть три части: начальное состояние `count = 3`, условие продолжения `count > 0` и шаг `count--`. Если забыть шаг, условие навсегда останется истинным.

Бесконечный `while (true)` иногда используется намеренно, когда выход удобнее описать внутри тела:

```js
let count = 3;

while (true) {
  if (count === 0) break;
  console.log(count);
  count--;
}
```

`break` немедленно завершает ближайший цикл. Такой стиль оправдан, когда условие выхода вычисляется в середине итерации, но для простого счётчика `while (count > 0)` читается лучше.

## Граничные случаи и ошибки

- Не запускайте показанное эталонное решение без `break`: в браузере оно заблокирует основной поток, интерфейс перестанет отвечать, а таймеры и обработчики событий не получат управление.
- `while` проверяет условие **до** тела, поэтому `while (false)` не выполнится ни разу. `do...while` сначала выполняет тело и только затем проверяет условие.
- Условие не обязано быть типом `boolean`: `1`, непустая строка и объект считаются истинными, а `0`, `""`, `null`, `undefined` и `NaN` — ложными. Явное сравнение обычно понятнее неявного приведения.
- `continue` пропускает остаток текущей итерации. Если шаг изменения состояния расположен после `continue`, можно случайно получить бесконечный цикл.
- `break` завершает только ближайший вложенный цикл, а не все циклы сразу.

## Сложность

Одна итерация пустого тела занимает `O(1)`, но у `while (true)` нет конечного числа итераций. Поэтому для показанного фрагмента нельзя указать обычное конечное время выполнения. Дополнительная память — `O(1)`.

Для конечного цикла из `k` итераций время обычно записывают как `O(k)`, если тело выполняет постоянный объём работы.

## Что запомнить

`while` подходит, когда заранее неизвестно точное число повторений, но известно условие продолжения. Перед написанием цикла ответьте на три вопроса: какое состояние проверяется, что меняется на каждой итерации и почему условие когда-нибудь станет ложным. `while (true)` безопасен только вместе с достижимым выходом — обычно `break`, `return` или выбрасыванием ошибки.
