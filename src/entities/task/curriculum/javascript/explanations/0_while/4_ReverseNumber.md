## Что делает решение

Функция переносит цифры исходного числа справа налево в новый числовой аккумулятор:

```js
const reverseNumber = (num) => {
  let reversed = 0;
  let n = num;

  while (n > 0) {
    const lastDigit = n % 10;
    reversed = reversed * 10 + lastDigit;
    n = Math.floor(n / 10);
  }

  return reversed;
};
```

`n` хранит ещё не обработанную часть исходного числа, а `reversed` — уже построенный результат.

## Пошаговый разбор

Развернём `1234`:

| `n` | `lastDigit` | новый `reversed` | новое `n` |
|---:|---:|---:|---:|
| `1234` | `4` | `0 * 10 + 4 = 4` | `123` |
| `123` | `3` | `4 * 10 + 3 = 43` | `12` |
| `12` | `2` | `43 * 10 + 2 = 432` | `1` |
| `1` | `1` | `432 * 10 + 1 = 4321` | `0` |

Умножение `reversed` на `10` сдвигает все уже собранные цифры на один десятичный разряд влево. После этого `lastDigit` занимает освободившийся разряд единиц. Затем `Math.floor(n / 10)` удаляет из `n` только что обработанную последнюю цифру.

Полезный инвариант цикла: перед каждой итерацией `reversed` содержит точный разворот уже извлечённого суффикса, а `n` содержит необработанный префикс. Когда `n` становится нулём, необработанных цифр не остаётся.

## Почему reverseNumber(980) возвращает 89

Первая извлечённая цифра равна нулю, поэтому аккумулятор остаётся `0`. Затем добавляются `8` и `9`. Число не хранит информацию о ведущих нулях: значение `089` численно равно `89`. Если по требованиям нужно сохранить фиксированную длину и получить строку `"089"`, результат должен быть строкой, а не числом.

## Граничные случаи и ошибки

- Текущая реализация рассчитана на неотрицательные целые числа. Для отрицательного `num` условие `n > 0` сразу ложно, поэтому функция вернёт `0`.
- Для сохранения знака можно отдельно вычислить `sign = Math.sign(num)`, работать с `Math.abs(num)`, а в конце вернуть `sign * reversed`.
- Дробные числа не входят в контракт: `% 10` вернёт дробный остаток, и итог не будет корректным разворотом текстовой записи.
- `Infinity` не уменьшается после `Math.floor(n / 10)`, поэтому цикл станет бесконечным; `NaN` вернёт `0` без явной ошибки.
- Числа больше `Number.MAX_SAFE_INTEGER` могут быть представлены неточно ещё до вызова функции.
- Если поменять порядок и сначала уменьшить `n`, последняя цифра будет потеряна.
- Строковый способ проще поддерживает знак и фиксированный формат, но выделяет `O(k)` дополнительной памяти.

## Сложность

Для числа из `k` цифр выполняется `k` итераций: время `O(k)`, то есть `O(log10 n)`, дополнительная память `O(1)`. Числовой результат сам не считается дополнительной структурой размером `k` в модели этой задачи.

## Что запомнить

Чтобы дописать цифру справа к числу, используйте формулу `result = result * 10 + digit`. Последнюю цифру берите через `% 10`, а исходное число сокращайте через `Math.floor(n / 10)`. Отдельно зафиксируйте контракт для нуля, отрицательных чисел, дробей и ведущих нулей: арифметический разворот не сохраняет формат исходной записи.
