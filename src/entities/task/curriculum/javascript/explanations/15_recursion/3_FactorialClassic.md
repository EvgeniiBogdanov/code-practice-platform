## Что делает решение

```js
const factorial = (n) => {
  if (n === 0 || n === 1) return 1;
  return n * factorial(n - 1);
};
```

Факториал неотрицательного целого `n` — произведение `1 · 2 · ... · n`. Рекурсивное равенство `n! = n · (n - 1)!` уменьшает задачу на единицу.

## Пошаговый разбор

`factorial(4)` раскрывается как `4 * factorial(3)`, затем `4 * 3 * factorial(2)`, затем `4 * 3 * 2 * factorial(1)`. База возвращает `1`, после чего умножения выполняются при разворачивании стека и дают `24`.

Случай `0! = 1` — математическое определение, а не обходной трюк. Проверки `0` и `1` можно объединить как `n <= 1`, но только после валидации отрицательных входов.

## Граничные случаи и ошибки

- Отрицательное целое никогда не достигнет точных баз `0` или `1`: аргумент будет уменьшаться дальше до переполнения стека.
- Дробные числа также могут не попасть в базу. Контракт должен требовать `Number.isInteger(n) && n >= 0`.
- `factorial(171)` становится `Infinity` из-за диапазона `Number`; точные большие результаты требуют `BigInt`.
- Даже до числового переполнения очень большой вход может переполнить стек.
- Рекурсивная запись наглядна, но итеративное произведение использует `O(1)` памяти.
- `NaN` не совпадёт с базой и породит бесконечную рекурсию.

## Сложность

Время `O(n)`, память стека `O(n)`. Итеративная версия сохраняет время `O(n)`, но снижает дополнительную память до `O(1)`.

## Что запомнить

Рекурсивная формула корректна только вместе с доменом входа и базой. Для факториала сначала валидируйте неотрицательное целое, затем уменьшайте аргумент ровно к `0` или `1`.
