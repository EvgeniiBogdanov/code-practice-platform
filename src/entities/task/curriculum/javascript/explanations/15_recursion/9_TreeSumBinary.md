## Что делает решение

```js
const treeSum = (node) => {
  if (node === null) return 0;
  return node.value + treeSum(node.left) + treeSum(node.right);
};
```

Функция суммирует значения бинарного дерева. Каждый непустой узел вносит своё `value` и суммы левого и правого поддеревьев. Пустое поддерево возвращает нейтральный ноль.

## Рекурсивная модель дерева

Бинарное дерево само определено рекурсивно: узел содержит два меньших дерева. Поэтому формула функции повторяет структуру данных. Сначала вычисляются ветви, затем их результаты складываются со значением текущего узла. Порядок вычисления в JavaScript слева направо соответствует обходу в глубину, хотя для одной суммы итог от порядка не зависит.

База `null` позволяет листу не иметь отдельных условий: его `left` и `right` дают по нулю.

## Граничные случаи и ошибки

- Пустое дерево `null` возвращает `0`.
- Код ожидает, что у каждого узла есть `left` и `right`, равные узлу или `null`. `undefined` не проходит строгую базу и вызовет ошибку при чтении `.value`.
- Нечисловое `value` может переключить сложение на конкатенацию или дать `NaN`.
- Если одна и та же ссылка встречается в нескольких ветвях, её значение будет посчитано несколько раз; это уже граф, а не строгое дерево.
- Цикл в ссылках приводит к бесконечной рекурсии.
- Сильно перекошенное дерево глубины `n` может переполнить стек; итеративный DFS использует явный стек.

## Сложность

Для `n` узлов время `O(n)`. Память стека `O(h)`, где `h` — высота: `O(log n)` у сбалансированного дерева и `O(n)` у цепочки.

## Что запомнить

Для дерева определите результат пустой ветви и объедините результаты поддеревьев. Ноль — нейтральная база суммы, но форма узла и отсутствие циклов должны быть частью контракта.
