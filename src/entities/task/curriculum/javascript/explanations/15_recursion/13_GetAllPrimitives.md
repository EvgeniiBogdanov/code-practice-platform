## Что делает решение

```js
const getAllPrimitives = (obj) => {
  const arr = [];
  for (const key in obj) {
    const value = obj[key];
    if (typeof value === "number") arr.push(value);
    else if (typeof value === "object" && value !== null) {
      arr.push(...getAllPrimitives(value));
    }
  }
  return arr;
};
```

Функция обходит вложенную структуру в глубину и возвращает плоский массив найденных чисел в порядке обхода свойств.

## Важное несоответствие названию

Название и формулировка говорят о «всех примитивах», но текущее решение добавляет **только числа**. Строки, boolean, `undefined`, `bigint` и `symbol` тоже являются примитивами JavaScript, однако будут проигнорированы. Точный контракт этой реализации — «собрать все числовые значения».

Рекурсивный вызов возвращает массив поддерева, а spread добавляет его элементы по одному в родительский результат.

## Граничные случаи и ошибки

- `for...in` включает унаследованные перечислимые свойства. Для собственных данных нужен `Object.keys` или `Object.hasOwn`.
- `NaN` и `Infinity` имеют тип `number` и попадут в результат.
- Массивы рекурсивно обходятся по индексам, но разреженные слоты пропускаются `for...in`.
- Циклические ссылки вызывают бесконечную рекурсию.
- Очень большой массив из рекурсивного вызова может превысить лимит аргументов в `arr.push(...values)`.
- Символьные ключи не обходятся.
- Для действительно всех примитивов условие должно быть противоположным объекту/функции с отдельной обработкой `null`.

## Сложность

Обход занимает `O(n)` времени по числу свойств, результат — `O(k)` памяти, стек — `O(h)`. Spread может добавлять накладные копирования.

## Что запомнить

Название функции должно соответствовать предикату. Здесь `typeof value === "number"` собирает числа, а не все примитивы. В рекурсивных коллекторах отдельно проверяйте наследование, циклы и размер промежуточных массивов.
