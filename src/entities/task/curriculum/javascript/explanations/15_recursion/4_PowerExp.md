## Что делает решение

```js
const power = (base, exp) => {
  if (exp === 0) return 1;
  return base * power(base, exp - 1);
};
```

Функция вычисляет `base` в целой неотрицательной степени. Равенство `base^exp = base · base^(exp - 1)` уменьшает показатель, а база `base^0 = 1` завершает процесс.

## Пошаговый разбор

`power(2, 3)` раскрывается в `2 * power(2, 2)`, затем `2 * 2 * power(2, 1)` и `2 * 2 * 2 * power(2, 0)`. База возвращает единицу, результат равен `8`.

В каждом кадре сохраняется одно отложенное умножение. Решение простое, но выполняет столько вызовов, каков показатель. Быстрое возведение в степень делит показатель пополам и достигает `O(log exp)`.

## Граничные случаи и ошибки

- Текущий алгоритм не поддерживает отрицательную степень: `exp - 1` уходит от нуля, вызывая переполнение стека. Математически можно вернуть `1 / power(base, -exp)`.
- Дробный показатель может никогда точно не стать нулём и не входит в этот рекурсивный контракт.
- `0^0` текущая функция определяет как `1`; это распространённая программная договорённость, но её стоит зафиксировать.
- Большой показатель переполняет стек или числовой диапазон `Number`.
- `NaN` и `Infinity` в показателе не достигают базы.
- Для целых `BigInt` нельзя смешивать аргументы с обычными `Number`.

## Сложность

Линейная рекурсия требует `O(exp)` времени и памяти стека. Быстрое возведение в степень работает за `O(log exp)` времени и `O(log exp)` рекурсивного стека.

## Что запомнить

Рекурсивная степень демонстрирует «уменьшить параметр до нуля», но контракт обязан ограничить показатель. Для больших степеней используйте деление показателя пополам или встроенный оператор `**`.
