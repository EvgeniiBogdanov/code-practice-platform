## Что делает решение

```js
const sumTree = (data) => {
  let sum = data.value;
  if (data.children) {
    for (const child of data.children) {
      sum += sumTree(child);
    }
  }
  return sum;
};
```

Функция суммирует `value` текущего узла и результаты всех дочерних поддеревьев. Она работает с деревом произвольной ширины: детей может быть ноль, один или много.

## Как работает агрегация

Каждый вызов начинает с локального значения узла. Рекурсивный результат ребёнка уже содержит всю сумму его ветви, поэтому родителю достаточно прибавить одно число. Лист без `children` сразу возвращает собственное `value` — это неявная база.

Инвариант: после обработки первых `k` детей `sum` равен значению текущего узла плюс суммы этих `k` поддеревьев.

## Граничные случаи и ошибки

- `null` или отсутствующий корень не поддерживается; нужен отдельный контракт, например возвращать `0`.
- `children` лучше проверять через `Array.isArray`, иначе истинное неитерируемое значение сломает цикл.
- Строковый `value` переключит `+` на конкатенацию; `NaN` заразит весь результат.
- Узел без свойства `value` даст `undefined`, после чего сумма станет `NaN`.
- Циклическая ссылка вызывает бесконечную рекурсию; общий узел в нескольких ветвях считается несколько раз.
- Глубокая цепочка может переполнить стек. Итеративный DFS с явным стеком безопаснее.
- Порядок детей не влияет на математическую сумму, но влияет на порядок побочных эффектов, если их добавить.

## Сложность

Каждый из `n` узлов посещается один раз: `O(n)` времени. Рекурсивный стек занимает `O(h)`, где `h` — глубина дерева.

## Что запомнить

Агрегация дерева следует формуле «значение узла + агрегаты детей». Определите нейтральный результат пустого дерева, валидируйте числовые значения и не путайте дерево с графом, где нужны посещённые узлы.
