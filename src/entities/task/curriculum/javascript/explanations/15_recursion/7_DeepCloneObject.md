## Что делает решение

Функция возвращает примитивы как есть, массивы копирует через рекурсивный `map`, а обычные объекты — через новый контейнер и обход свойств. В результате вложенные массивы и объекты получают новые ссылки.

```js
if (value === null || typeof value !== "object") return value;
if (Array.isArray(value)) return value.map(deepClone);
```

Это база и отдельная ветка массива. Проверка `null` обязательна из-за исторического `typeof null === "object"`.

## Как работает копирование

Для каждого объекта сначала создаётся `{}`, затем каждое значение рекурсивно копируется. Изменение глубоко вложенного свойства клона не меняет исходник. Встроенный `structuredClone` из альтернативного решения поддерживает больше типов и циклические ссылки, поэтому в production-коде часто лучше.

## Граничные случаи и ошибки

- Текущая ручная версия не отслеживает посещённые объекты: циклическая ссылка заканчивается `RangeError`. Нужен `WeakMap`.
- `for...in` проходит и унаследованные перечислимые свойства, а копия получает их как собственные. Следует использовать `Object.keys` или `Object.hasOwn`.
- `Date`, `RegExp`, `Map`, `Set`, функции, прототипы, дескрипторы, symbol- и неперечислимые свойства копируются неверно или теряются.
- `structuredClone` тоже не копирует функции и некоторые платформенные объекты, но корректно обрабатывает поддерживаемые встроенные типы и циклы.
- Глубокая структура может переполнить стек ручной рекурсии.
- «Глубокая копия» всегда требует определения поддерживаемых типов; универсального короткого решения для всех JavaScript-объектов нет.

## Сложность

Для ацикличной структуры из `n` значений — `O(n)` времени и `O(n)` памяти на копию, плюс `O(h)` стека. Циклы требуют таблицы посещённых ссылок `O(n)`.

## Что запомнить

База возвращает примитив, каждая контейнерная ветка создаёт новую ссылку. Не заявляйте поддержку циклов и специальных типов, если код их явно не обрабатывает; сначала рассмотрите `structuredClone`.
