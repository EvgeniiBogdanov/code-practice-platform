## Что делает решение

```js
const flatten = (arr) => {
  const result = [];
  for (const el of arr) {
    if (Array.isArray(el)) result.push(...flatten(el));
    else result.push(el);
  }
  return result;
};
```

Функция превращает массив любой глубины в плоский массив. Массивный элемент рекурсивно разглаживается, примитивный добавляется как готовое значение.

## Как собирается результат

Каждый вызов отвечает за один уровень и создаёт локальный `result`. Результат вложенного вызова раскрывается через `...` в родительский массив. Порядок обхода слева направо сохраняется. Для `[1, [2, [3]]]` объединяются `[1]`, `[2]` и `[3]`.

Встроенная альтернатива `arr.flat(Infinity)` короче и обычно предпочтительна. Рекурсивная версия полезна, чтобы понять обход вложенной структуры или добавить собственные правила.

## Граничные случаи и ошибки

- Пустые вложенные массивы ничего не добавляют.
- Циклический массив (`arr.push(arr)`) вызовет бесконечную рекурсию; стандартный `flat` также не предназначен для циклов.
- Очень большая глубина переполняет стек.
- Разреженные массивы различают варианты: `flat` удаляет пустые слоты, а `for...of` выдаёт для них `undefined`, которое попадёт в результат.
- Объекты внутри массива не копируются и не разворачиваются — сохраняются те же ссылки.
- `result.push(...largeArray)` может превысить лимит аргументов на огромном вложенном результате. Безопаснее добавлять элементы циклом.
- Нейтерируемый вход вызовет ошибку.

## Сложность

При `n` атомарных элементах время и память результата — `O(n)`, стек — `O(h)`, где `h` — максимальная глубина. Промежуточные массивы и spread добавляют накладные копирования.

## Что запомнить

Рекурсивный flatten различает контейнер и готовое значение: контейнер раскрывается, значение добавляется. Проверяйте глубину, циклы, разреженные массивы и цену промежуточных копий.
