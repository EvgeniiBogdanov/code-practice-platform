## Что делает решение

Функция проходит произвольно вложенный объект и суммирует свойства с числовыми значениями. Для каждого ключа число добавляется, а ненулевой объект порождает рекурсивный вызов.

```js
if (typeof value === "number") {
  sum += value;
} else if (typeof value === "object" && value !== null) {
  sum += sumNumbers(value);
}
```

## Как работает аккумуляция

У каждого уровня свой локальный `sum`. Вложенный вызов полностью вычисляет сумму подструктуры и возвращает одно число родителю. Массивы тоже обходятся, потому что их индексы являются перечислимыми ключами объекта. Отрицательные числа учитываются с их знаком, поэтому пример даёт `-5`.

Проверка `value !== null` обязательна: `typeof null` исторически равен `"object"`, но обходить `null` нельзя.

## Граничные случаи и ошибки

- В отличие от другого решения `deepSum`, здесь `for...in` не фильтруется через `Object.hasOwn`. Унаследованные перечислимые свойства тоже будут посчитаны — важное ограничение текущего кода.
- Заголовок говорит об объектах, но массивы фактически поддерживаются.
- `NaN` превращает итог в `NaN`; `Infinity` даёт бесконечный результат.
- `Date`, `Map` и `Set` не раскрывают содержимое обычными перечислимыми ключами.
- Циклическая ссылка вызывает бесконечную рекурсию; нужна коллекция посещённых ссылок.
- Глубокий вход может переполнить стек.
- Числовые строки игнорируются, а не приводятся к числам.

## Сложность

Для ацикличной структуры с `n` перечислимыми свойствами время `O(n)`, стек `O(h)`. Защита от циклов потребует до `O(n)` памяти.

## Что запомнить

Рекурсивная сумма объединяет локальный аккумулятор с результатами детей. Для надёжной объектной утилиты добавьте проверку собственных свойств и явно определите поддержку массивов, специальных объектов и циклов.
