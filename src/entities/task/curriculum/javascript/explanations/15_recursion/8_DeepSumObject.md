## Что делает решение

```js
const deepSum = (obj) => {
  let sum = 0;
  for (const key in obj) {
    if (!Object.hasOwn(obj, key)) continue;
    const value = obj[key];
    if (typeof value === "number") sum += value;
    if (typeof value === "object" && value !== null) sum += deepSum(value);
  }
  return sum;
};
```

Функция рекурсивно обходит объект, включая вложенные объекты и массивы, и складывает все числовые значения.

## Как работает обход

Каждый вызов создаёт локальную сумму своего контейнера. Число добавляется сразу; вложенный ненулевой объект отдаётся рекурсивному вызову, чей результат прибавляется. Массивы тоже являются объектами, а их индексы перечислимы, поэтому `[4, 5]` даёт вклад `9`.

`Object.hasOwn` защищает от унаследованных перечислимых свойств. Альтернатива через `Object.values(...).reduce(...)` избегает `for...in` и тем же образом рекурсивно классифицирует каждое значение.

## Граничные случаи и ошибки

- `null` нужно исключать отдельно, иначе попытка рекурсивного обхода сломается.
- `NaN` имеет тип `number` и сделает весь итог `NaN`; `Infinity` даст бесконечность.
- Числа внутри `Map` и `Set` не будут найдены через обычные перечислимые ключи.
- Циклическая ссылка вызывает бесконечную рекурсию. Для недоверенных графов нужен `WeakSet` посещённых объектов.
- Символьные и неперечислимые свойства `for...in` не обходит.
- Большая глубина может переполнить стек.
- Строковые числа не складываются, что соответствует строгому числовому контракту.

## Сложность

Каждое перечислимое значение посещается один раз: `O(n)` времени и `O(h)` стека. Защита от циклов добавит до `O(n)` памяти.

## Что запомнить

Рекурсивная агрегация сначала классифицирует значение: число даёт вклад, контейнер порождает подзадачу, остальное игнорируется. Обязательно решите, как поступать с `NaN`, циклами и специальными коллекциями.
