## Что делает решение

```js
const countDown = (n) => {
  if (n <= 0) return;
  console.log(n);
  countDown(n - 1);
};
```

Функция выводит числа от `n` до `1`. Каждый вызов решает один маленький шаг и передаёт уменьшенную задачу следующему вызову.

## Как работает рекурсия

Для `countDown(3)` стек растёт как `countDown(3) → countDown(2) → countDown(1) → countDown(0)`. Последний вызов попадает в базовый случай и ничего больше не вызывает. Затем предыдущие вызовы завершаются в обратном порядке, но после рекурсивной строки у них уже нет действий.

База `n <= 0` обязательна: она доказывает, что цепочка остановится для положительного целого входа. Шаг `n - 1` на каждом уровне приближает аргумент к базе.

## Граничные случаи и ошибки

- При `0` и отрицательном числе вывода нет.
- Если удалить базовый случай или вызывать `countDown(n)` без уменьшения, стек переполнится с `RangeError`.
- Дробное положительное число будет выводиться с шагом один, пока не станет неположительным; это не целочисленный отсчёт.
- `Infinity - 1` остаётся `Infinity`, поэтому рекурсия не завершится.
- Большое `n` переполнит стек раньше завершения. JavaScript обычно не гарантирует оптимизацию хвостовой рекурсии в используемых средах.
- Функция возвращает `undefined`; её результат — консольный побочный эффект.

## Сложность

Выполняется `n` вызовов: `O(n)` времени и `O(n)` памяти стека. Итеративный цикл решил бы задачу за `O(1)` дополнительной памяти.

## Что запомнить

У рекурсии должны быть достижимая база и шаг, уменьшающий размер задачи. Порядок `console.log` до рекурсивного вызова даёт вывод при углублении — от большого числа к маленькому.
