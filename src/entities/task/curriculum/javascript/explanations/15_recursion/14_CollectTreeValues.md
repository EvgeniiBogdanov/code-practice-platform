## Что делает решение

```js
const recursionTree = (data) => {
  const arr = [data.value];
  if (data.children) {
    for (const child of data.children) {
      arr.push(...recursionTree(child));
    }
  }
  return arr;
};
```

Функция собирает значения всех узлов дерева произвольной ширины. Текущий узел добавляется первым, затем по очереди полностью обходятся поддеревья детей. Это depth-first pre-order обход.

## Как сохраняется порядок

Каждый вызов начинает массив со своего `value`. Результат первого ребёнка раскрывается перед переходом ко второму, поэтому пример возвращает `[0, 1, 2, 3, 4, 5]`. Отсутствие `children` служит неявной базой: цикл просто не выполняется, и лист возвращает массив из одного значения.

## Граничные случаи и ошибки

- `null` вместо корня не обрабатывается и вызовет ошибку при чтении `data.value`.
- Проверка только истинности `children` недостаточна для повреждённых данных: неитерируемое значение вызовет `TypeError`. Надёжнее `Array.isArray`.
- Пустой `children: []` работает корректно.
- Циклическая ссылка на предка приводит к бесконечной рекурсии; для графа нужен `WeakSet`.
- Общий дочерний узел в двух ветвях будет добавлен дважды.
- Глубокая цепочка может переполнить стек.
- `push(...largeSubtree)` способен превысить лимит аргументов; итеративное добавление безопаснее для огромных деревьев.

## Сложность

Все `n` узлов посещаются: базово `O(n)` времени и `O(n)` памяти результата, стек `O(h)`. Промежуточные массивы и spread могут добавить копирования, особенно в глубокой цепочке.

## Что запомнить

Pre-order означает «текущий узел, затем дети». Неявная база допустима для листа, но production-версия должна валидировать корень, форму `children` и решить, допускаются ли циклы или общие ссылки.
