## Что делает решение

```js
for (let i = 0; i < arr.length; i++) {
  // действия с arr[i]
}
```

Это базовый индексный обход массива слева направо. Заголовок `for` состоит из трёх выражений: инициализация `let i = 0`, условие продолжения `i < arr.length` и шаг `i++`. Инициализация выполняется один раз, условие — перед каждой итерацией, шаг — после тела.

## Как работает цикл

При массиве из трёх элементов `i` последовательно равен `0`, `1`, `2`. Значение `3` уже не проходит проверку `3 < 3`. Благодаря строгому `<` индекс никогда не выходит за правую границу. `let` нужен потому, что счётчик меняется; область видимости `i` ограничена циклом.

Все три части необязательны: `for (;;) {}` синтаксически корректен, но без `break` это бесконечный цикл. `continue` пропускает остаток тела, затем всё равно выполняется шаг `i++`; `break` сразу завершает цикл.

## Граничные случаи и ошибки

- В эталонном фрагменте `arr` должен быть объявлен снаружи. Сам по себе шаблон выдаст `ReferenceError`.
- Пустой массив даёт ноль итераций.
- Условие `i <= arr.length` ошибочно: последняя итерация прочитает `arr[arr.length]`, то есть `undefined`.
- Если удалить `i++`, цикл не завершится. Если увеличивать `i` и в заголовке, и в теле, элементы будут пропускаться.
- Изменение длины `arr` во время обхода меняет условие на лету. Добавление элементов может продлить цикл, а удаление — пропустить данные.
- Для простого чтения значений часто понятнее `for...of`; индексный `for` нужен, когда важны позиция, направление или нестандартный шаг.

## Сложность

Для массива длины `n` выполняется `n` итераций: `O(n)` времени и `O(1)` дополнительной памяти, если тело постоянно по стоимости.

## Что запомнить

Читайте `for` как последовательность «начать → проверить → выполнить → сделать шаг». До запуска убедитесь, что счётчик движется к ложному условию и что правая граница не выходит за допустимые индексы.
