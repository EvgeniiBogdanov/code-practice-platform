## Что делает решение

```js
const printNumbers = (n) => {
  for (let i = 1; i <= n; i++) {
    console.log(i);
  }
};
```

Функция выводит целые числа от `1` до `n` включительно. Счётчик начинается с первого требуемого значения, условие `i <= n` включает верхнюю границу, а `i++` приближает цикл к завершению.

## Пошаговый разбор

Для `printNumbers(3)` сначала создаётся `i = 1`. Проверка истинна — выводится `1`, затем `i` становится `2`. Аналогично выводятся `2` и `3`. После шага до `4` выражение `4 <= 3` ложно, и управление переходит за цикл.

Здесь важно различать результат функции и побочный эффект. `console.log` показывает значения, но функция ничего явно не возвращает, поэтому её результат — `undefined`. Если числа нужны другому коду, лучше собрать и вернуть массив.

## Граничные случаи и ошибки

- При `n <= 0` цикл не выполнится ни разу — это естественное поведение текущего контракта.
- Дробное `n`, например `3.7`, выведет `1`, `2`, `3`. Это похоже на округление вниз, но не выражено явно. Для строгого API проверяют `Number.isInteger(n)`.
- `Infinity` создаст бесконечный цикл, потому что конечный `i` никогда не станет больше бесконечности.
- `NaN` не пройдёт первую проверку и ничего не выведет, скрыв ошибочный вход.
- Замена `<=` на `<` потеряет число `n`; старт с `0` добавит лишний ноль. Это классические ошибки на единицу.
- Большой объём `console.log` значительно медленнее самого цикла и может перегрузить консоль.

## Сложность

Для положительного целого `n` выполняется `n` итераций: время `O(n)`, дополнительная память `O(1)`. Если возвращать массив, память станет `O(n)`.

## Что запомнить

Границы цикла должны буквально повторять условие задачи. Формулировка «от 1 до N включительно» превращается в `i = 1` и `i <= n`. Отдельно решите, должна функция печатать данные или возвращать их — это разные контракты.
