## Что делает решение

Функция приводит строку к нижнему регистру, строит её развёрнутую копию и сравнивает две строки:

```js
const isPalindrome = (str) => {
  const lowerStr = str.toLowerCase();
  let reverseString = "";

  for (let i = str.length - 1; i >= 0; i--) {
    reverseString += lowerStr[i];
  }

  return reverseString === lowerStr;
};
```

Для `"Madam"` рабочая строка равна `"madam"`, обратный обход собирает ту же последовательность, поэтому возвращается `true`.

## Как работает цикл

Последний допустимый индекс строки — `length - 1`. Счётчик уменьшается до нуля включительно. На каждой итерации очередной символ дописывается справа к `reverseString`. После цикла строгое сравнение возвращает готовый boolean.

Более экономная альтернатива — два указателя: сравнивать символы с начала и конца и сразу вернуть `false` при несовпадении. Она не создаёт полную обратную строку и может завершиться раньше.

## Граничные случаи и ошибки

- Пустая строка и строка из одного символа считаются палиндромами.
- Решение игнорирует регистр, но не игнорирует пробелы, знаки препинания и диакритику: `"А роза..."` потребует предварительной нормализации по отдельному контракту.
- Индексация строк работает по UTF-16-кодовым единицам. Составные emoji и некоторые символы могут разворачиваться некорректно. Вариант `[...str]` лучше работает с Unicode code points, но не со всеми графемными кластерами.
- Цикл использует длину исходной `str`, а читает `lowerStr`. Для редких Unicode-символов преобразование регистра может менять длину, поэтому надёжнее брать `lowerStr.length`.
- Повторная конкатенация строк может потребовать до `O(n²)` копирований в наивной модели, хотя движки часто оптимизируют её.
- Нестрочный вход вызовет ошибку у `toLowerCase`.

## Сложность

Обход и сравнение требуют `O(n)` времени, обратная строка — `O(n)` памяти. Метод двух указателей использует `O(1)` дополнительной памяти в простой модели кодовых единиц.

## Что запомнить

Сначала определите, что именно означает палиндром: учитывать ли регистр, пробелы и Unicode. Затем либо постройте нормализованную обратную строку, либо сравнивайте симметричные позиции с ранним выходом.
