## Что делает решение

```js
const printEvens = (n) => {
  for (let i = 2; i <= n; i += 2) {
    console.log(i);
  }
};
```

Функция выводит все положительные чётные числа до `n`. Решение не перебирает нечётные значения: стартует с `2` и каждый раз прибавляет два.

## Как работает цикл

Для `n = 6` счётчик принимает значения `2`, `4`, `6`, затем становится `8` и не проходит условие. Любое число вида `2 + 2k` чётное, поэтому проверка `i % 2 === 0` внутри тела не нужна.

Можно было пройти все числа от `1` до `n` и фильтровать остатком от деления. Такой код тоже корректен, но делает примерно вдвое больше итераций. Асимптотически оба варианта `O(n)`, однако прямой шаг лучше выражает требуемую последовательность.

## Граничные случаи и ошибки

- При `n < 2` вывод пустой.
- Нечётная верхняя граница, например `7`, корректно заканчивается на `6`.
- Дробное `n` включает все чётные целые, не превышающие его; если дроби запрещены, вход стоит валидировать.
- `Infinity` не даёт циклу завершиться. `NaN` не запускает цикл.
- Условие `< n` пропустит чётное значение, равное `n`; `<=` соответствует слову «до включительно».
- `console.log` — побочный эффект. Для тестируемой утилиты часто удобнее вернуть массив `[2, 4, 6]`.
- Для вывода отрицательных чётных чисел нужен другой диапазон и направление шага; текущий контракт начинается с единицы.

## Сложность

Цикл выполняется примерно `n / 2` раз. В Big O постоянный множитель отбрасывается, поэтому время — `O(n)`, память — `O(1)`. Возвращаемый массив потребовал бы `O(n)` памяти.

## Что запомнить

Если закономерность последовательности известна, кодируйте её в начальном значении и шаге цикла. Это убирает лишнее условие из тела и делает намерение заметным: `2, 4, 6, ...` выражается через `i = 2` и `i += 2`.
