## Что делает решение

```js
const sumTo = (n) => {
  let sum = 0;
  for (let i = 1; i <= n; i++) sum += i;
  return sum;
};
```

Функция сворачивает последовательность `1...n` в одно число. `sum` — аккумулятор: перед каждой итерацией он содержит сумму уже обработанных чисел.

## Пошаговый разбор

Для `n = 4` аккумулятор меняется как `0 → 1 → 3 → 6 → 10`. Начальный ноль выбран не случайно: это нейтральный элемент сложения, поэтому пустой диапазон тоже возвращает `0`. Выражение `sum += i` эквивалентно `sum = sum + i`.

Инвариант помогает проверить код: после обработки значения `i` переменная `sum` равна сумме от `1` до `i`. Когда цикл заканчивается на `n`, в аккумуляторе находится требуемый ответ.

Альтернатива для этого конкретного диапазона — формула `n * (n + 1) / 2`. Она работает за постоянное число операций, но цикл лучше демонстрирует общий паттерн накопления, применимый к произвольным данным.

## Граничные случаи и ошибки

- При `n <= 0` текущая функция возвращает `0`; отрицательные диапазоны она не суммирует.
- Для дробного `n` фактически суммируются целые числа до `Math.floor(n)`. Контракт лучше ограничить безопасными целыми.
- `Infinity` приводит к бесконечному циклу, `NaN` — к немедленному возврату `0`.
- Большие суммы могут выйти за `Number.MAX_SAFE_INTEGER` и потерять целочисленную точность. Для огромных целых нужна версия на `BigInt`.
- Нельзя инициализировать `sum` как `undefined`: первое сложение даст `NaN`.
- Формула `n * (n + 1) / 2` имеет `O(1)` по числу операций JavaScript, но не устраняет ограничения типа `Number`.

## Сложность

Циклическое решение: `O(n)` времени и `O(1)` памяти. Решение по формуле: `O(1)` времени и памяти.

## Что запомнить

Для агрегации задайте нейтральное начальное значение, обновляйте аккумулятор ровно один раз на элемент и возвращайте его после цикла. Всегда отличайте учебный общий паттерн от математической оптимизации конкретной последовательности.
