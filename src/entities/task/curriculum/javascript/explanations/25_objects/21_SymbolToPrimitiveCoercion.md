### Что делает решение
Решение реализует метод `[Symbol.toPrimitive](hint)`, определяющий единый стандартный протокол преобразования пользовательского объекта к примитиву в спецификации ECMAScript.

### Пошаговый разбор алгоритма `ToPrimitive(hint)`

1. **Три значения `hint` (подсказки)**:
   - **`"string"`**: вызывается операциями, ожидающими строку (`String(obj)`, интерполяция шаблона `` `${obj}` ``).
   - **`"number"`**: вызывается явным числовым приведением (`Number(obj)`, унарный `+obj`), математическими операторами вычитания/умножения/деления (`obj - 10`, `obj * 2`), а также функциями `Math.*`.
   - **`"default"`**: вызывается операциями, где тип результата не предопределен (бинарный оператор сложения `obj + 50`, нестрогое равенство `obj == 100`).

2. **Приоритет перед `valueOf()` и `toString()`**:
   - В старом JavaScript (ES5) движок сначала искал `obj.valueOf()`, затем `obj.toString()` (или наоборот, в зависимости от контекста).
   - Если у объекта определен метод `[Symbol.toPrimitive]`, движок вызывает **только его**, а старые методы `valueOf`/`toString` полностью игнорируются.

3. **Практическое применение в DDD и FinTech**:
   - Паттерн `CurrencyAmount` (Money pattern) позволяет безопасно использовать объекты денег в математических формулах (`wallet + bonus`), сохраняя удобное строковое форматирование при выводе в UI (`${wallet}`).

### Граничные случаи и ошибки
- **Возврат непримитива**: метод `Symbol.toPrimitive` обязан возвращать **примитивное значение** (`number`, `string`, `boolean`, `symbol`, `bigint`, `null`, `undefined`). Если метод вернет объект, движок выбросит `TypeError: Cannot convert object to primitive value`.

### Сложность
- **По времени**: `O(1)`.
- **По памяти**: `O(1)`.

### Что запомнить для собеседования
- `Symbol.toPrimitive(hint)` принимает `"number"`, `"string"` или `"default"`.
- Бинарный `+` и `==` передают hint `"default"`.
- Метод обязан вернуть примитив, иначе будет `TypeError`.
