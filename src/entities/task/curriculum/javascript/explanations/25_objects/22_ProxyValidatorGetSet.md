### Что делает решение
Решение использует объект `Proxy` и встроенный модуль `Reflect` для создания защищенного объекта с валидацией схемы данных. Ловушка `get` перехватывает доступ к несуществующим полям (выбрасывая `ReferenceError`), а ловушка `set` проверяет соответствие типов и ограничений схемы перед записью.

### Пошаговый разбор ловушек Proxy и Reflect

1. **Зачем нужен `Reflect` вместе с `Proxy`**:
   - Методы `Reflect.get(target, prop, receiver)` и `Reflect.set(...)` гарантируют корректную работу геттеров/сеттеров и правильную передачу `receiver` (контекста `this` при наследовании от Proxy).
   - `Reflect.set` возвращает `true`/`false`, что идеально соответствует контракту ловушки `set` в Proxy.

2. **Ловушка `get` (Safe Property Access)**:
   - В обычном JS чтение `user.unknown` молча возвращает `undefined`, что часто маскирует опечатки в коде.
   - Проверка `prop in obj` позволяет выбросить явный `ReferenceError`, делая объект строгим.
   - Символы (`typeof prop === 'symbol'`) пропускаются без ошибок для корректной работы системных протоколов JS (`Symbol.iterator`, `Symbol.toStringTag`).

3. **Ловушка `set` (Schema Enforcement)**:
   - Если для свойства `prop` в объекте `schema` зарегистрирован валидатор, он вызывается перед записью.
   - При нарушении правила выбрасывается `TypeError`, предотвращая загрязнение объекта невалидными данными.

### Граничные случаи и ошибки
- **Возврат `false` из ловушки `set` в strict mode**: если ловушка `set` вернет `false` (или не вернет `true`), движок в strict mode выбросит `TypeError: 'set' on proxy: trap returned falsish`.
- **Защита от зацикливания**: валидатор не должен читать другие поля через Proxy, если те могут спровоцировать рекурсивный `get`.

### Сложность
- **По времени**: `O(1)` на чтение и валидацию/запись свойства.
- **По памяти**: `O(1)` — один экземпляр Proxy-обертки.

### Что запомнить для собеседования
- `Proxy` позволяет перехватывать любые 13 внутренних методов объекта (get, set, has, deleteProperty, apply, construct и др.).
- Всегда используйте `Reflect` внутри ловушек `Proxy`.
- `set` ловушка обязана возвращать `true` при успешной записи.
