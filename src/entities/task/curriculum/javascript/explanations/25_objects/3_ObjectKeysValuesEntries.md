### Что делает решение
Функция демонстрирует фундаментальный паттерн функциональной трансформации объектов в современном JavaScript:
1. `Object.entries(obj)` преобразует объект в массив кортежей `[key, value]`.
2. Массив обрабатывается через стандартные методы массивов (`.filter()`, `.map()`).
3. `Object.fromEntries(entries)` собирает обработанный массив пар обратно в новый объект.

### Пошаговый разбор

1. **Тройка методов `Object.keys`, `Object.values`, `Object.entries`**:
   - `Object.keys(obj)` возвращает массив собственных строковых перечислимых ключей `['apple', 'banana', ...]`.
   - `Object.values(obj)` возвращает массив значений `[100, 40, ...]`.
   - `Object.entries(obj)` возвращает массив пар `[['apple', 100], ['banana', 40], ...]`.

2. **Обратный метод `Object.fromEntries(iterable)`**:
   - Появился в стандарте ES2019.
   - Принимает любую итерируемую структуру (массив пар `[[k, v]]`, `Map`) и конструирует из неё обычный JavaScript-объект.
   - Позволяет применять к объектам всю мощь методов массивов (`map`, `filter`, `reduce`), не прибегая к ручным циклам `for...in` или мутациям.

3. **Порядок ключей в объектах (ES2015+ Спецификация)**:
   При вызове `Object.keys / values / entries` порядок элементов строго детерминирован алгоритмом `OrdinaryOwnPropertyKeys`:
   1. Сначала идут целочисленные числовые индексы (`"0"`, `"1"`, `"42"`) в порядке возрастания.
   2. Затем все остальные строковые ключи в хронологическом порядке их добавления в объект.
   3. Затем Symbol-свойства (доступные через `Object.getOwnPropertySymbols`).

### Граничные случаи и ошибки
- **Строковые числа и `NaN`**: свойство со значением `"50"` не проходит проверку `typeof price === "number"`, а значение `NaN` отфильтровывается через `!Number.isNaN(price)`.
- **Иммутабельность**: исходный объект `prices` не модифицируется — создаётся абсолютно новый объект.
- **Неперечислимые свойства**: `Object.entries` игнорирует неперечислимые свойства (enumerable: false).

### Сложность
- **По времени**: `O(N)`, где `N` — количество свойств в объекте.
- **По памяти**: `O(N)` для хранения промежуточного массива пар и результирующего объекта.

### Что запомнить для собеседования
- Связка `Object.entries` + `Array.prototype.map/filter` + `Object.fromEntries` — это идиоматичный стандарт функциональной обработки объектов.
- `Object.fromEntries` также используется для преобразования `new Map()` или `new URLSearchParams()` в простой объект.
