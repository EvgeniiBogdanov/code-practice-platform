### Что делает решение
Функция инвертирует соответствия ключ-значение объекта: все значения исходного объекта становятся ключами в новом объекте, а ключи исходного объекта — их значениями.

### Пошаговый разбор

1. **Итерация по собственным ключам**:
   - `Object.keys(obj)` гарантирует перебор только собственных перечислимых ключей, исключая прототипы.

2. **Приведение значений к строковым ключам**:
   - Ключи любого стандартного JavaScript-объекта (кроме Symbol) являются строками. Если значение было числом (`10`), оно становится строковым ключом (`"10"`).
   - Присвоение `result[val] = key` автоматически приводит `val` к строке.

3. **Коллизии одинаковых значений**:
   - Если в исходном объекте `{ apple: 'fruit', banana: 'fruit' }`, то при инверсии ключ `'fruit'` сначала запишет значение `'apple'`, а затем перезапишет его на `'banana'`. Это стандартное поведение утилиты `_.invert` в Lodash. Если требуется группировка всех ключей с одинаковым значением в массив, используется утилита `invertBy`.

### Граничные случаи и ошибки
- **Значения-объекты**: если значением свойства является объект `{ a: {} }`, то приведение к строке даст `"[object Object]"`. В качестве ключей имеет смысл инвертировать только примитивные значения (строки, числа, булевы).
- **Пустой объект**: для `{}` функция возвращает `{}`.

### Сложность
- **По времени**: `O(N)`, где `N` — количество ключей объекта.
- **По памяти**: `O(N)` для создания нового инвертированного объекта.

### Что запомнить для собеседования
- Ключи объектов в JS всегда строки или Symbol.
- При дублирующихся значениях сохраняется последнее обработанное свойство.
- Альтернативное однострочное решение: `Object.fromEntries(Object.entries(obj).map(([k, v]) => [v, k]))`.
