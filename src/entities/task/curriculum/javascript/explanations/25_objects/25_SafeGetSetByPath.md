### Что делает решение
Решение реализует безопасные функции глубокого чтения (`safeGet`) и записи (`safeSet`) по пути свойства:
1. **Нормализация пути (`parsePath`)**: преобразует синтаксис квадратных скобок `"a[0].b"` в плоский массив ключей `['a', '0', 'b']`.
2. **Безопасная навигация**: на каждом шаге проверяет наличие объекта и возвращает `defaultValue` при отсутствии свойства или встрече `null`/`undefined`.
3. **Автосоздание структур**: `safeSet` анализирует следующий ключ: если он состоит из цифр (`/^\d+$/`), создает массив `[]`, иначе объект `{}`.
4. **Защита от Prototype Pollution**: блокирует запись в ключи `__proto__`, `prototype`, `constructor`.

### Защита от Prototype Pollution на собеседовании

1. **В чем заключается уязвимость**:
   - Если пользовательский ввод содержит путь `"__proto__.isAdmin"`, наивный `set(target, path, true)` запишет свойство напрямую в `Object.prototype`.
   - После этого **все** объекты приложения получат свойство `{}.isAdmin === true`, что приводит к обходу проверок прав доступа и Remote Code Execution.

2. **Черный список ключей**:
   - `FORBIDDEN_KEYS` надежно изолирует цепочку прототипов от несанкционированной модификации.

### Граничные случаи и ошибки
- **Ложные значения по пути (`false`, `0`, `""`)**: корректно возвращаются, а не подменяются на `defaultValue`.
- **Запись в существующий примитив**: если по пути уже лежало число, `safeSet` перезаписывает его контейнером для продолжения пути.

### Сложность
- **По времени**: `O(D)` — где $D$ — глубина пути (количество сегментов).
- **По памяти**: `O(D)` — создание промежуточных объектов при их отсутствии.

### Что запомнить для собеседования
- `safeGet` заменяет цепочки `obj?.a?.b` при динамических строковых путях.
- `safeSet` всегда должен проверять защиту от `__proto__` инъекций.
