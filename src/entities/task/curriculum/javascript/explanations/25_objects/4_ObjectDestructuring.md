### Что делает решение
Функция выполняет нормализацию объекта пользователя с помощью современного синтаксиса деструктуризации ES6+:
1. Извлекает обязательные поля `id` и `name`.
2. Переименовывает поле `email` в `userEmail` с одновременной установкой дефолтного значения (`email: userEmail = "no-email@example.com"`).
3. Задаёт значение по умолчанию для роли (`role = "guest"`).
4. Собирает все оставшиеся неперечисленные свойства в объект `extra` с помощью rest-оператора (`...extra`).

### Пошаговый разбор

1. **Синтаксис алиасов и дефолтных значений**:
   - `email: userEmail` — имя свойства в объекте `email`, но внутри локального скоупа объявляется переменная `userEmail`.
   - `email: userEmail = "default"` — объединение переименования и значения по умолчанию. Если `rawUser.email === undefined`, переменная `userEmail` примет значение `"default"`.

2. **Критическая разница между `null` и `undefined` при деструктуризации**:
   - Дефолтное значение срабатывает **только если значение равно `undefined`** (или свойство отсутствует).
   - Если в объекте явно передано `{ email: null }`, то `userEmail` станет `null`, а не `"no-email@example.com"`. Это частая ловушка на собеседованиях.

3. **Rest-оператор в объектах (`...rest`)**:
   - Оператор `...rest` обязан находиться **строго в самом конце** шаблона деструктуризации.
   - Он создаёт новый неглубокий (shallow) объект, содержащий все собственные перечислимые свойства, которые не были извлечены ранее.

### Граничные случаи и ошибки
- **Деструктуризация `null` или `undefined`**: запись `const { a } = null` выбрасывает фатальную ошибку `TypeError: Cannot destructure property 'a' of null`. Защита через параметр по умолчанию `rawUser = {}` и фолбэк `(rawUser || {})` предотвращает падение.
- **Вложенная деструктуризация**: при глубокой деструктуризации вида `const { address: { city } = {} } = user;` всегда следует предусматривать дефолтный объект `{}` для промежуточных узлов, иначе при `user.address === undefined` произойдёт ошибка.

### Сложность
- **По времени**: `O(K)`, где `K` — общее количество ключей в исходном объекте (требуется для сбора `...extra`).
- **По памяти**: `O(K)` для создания объекта `extra` и итогового объекта.

### Что запомнить для собеседования
- Деструктуризация с `=` срабатывает только на `undefined`, но не на `null`, `false`, `0` или `""`.
- `...rest` создаёт новый чистый объект без ранее деструктурированных свойств.
