### Что делает решение
Решение решает две критические задачи архитектуры и безопасности в JavaScript:
1. Создание «чистых словарей» без прототипа через `Object.create(null)` для предотвращения коллизий со встроенными методами (`toString`, `hasOwnProperty`).
2. Защита от атаки **Prototype Pollution (Загрязнение прототипа)** путем фильтрации опасных мета-ключей (`__proto__`, `constructor`, `prototype`) при рекурсивном слиянии объектов.

### Пошаговый разбор механизма Prototype Pollution

1. **Суть уязвимости Prototype Pollution**:
   - В JavaScript все обычные объекты наследуются от `Object.prototype`.
   - Если функция слияния (deep merge / assign) наивно выполняет `target[key] = source[key]`, то при `key === "__proto__"` выражение `target["__proto__"][subKey] = val` модифицирует **глобальный `Object.prototype`**!
   - В результате ВСЕ объекты в приложении (включая будущие `{}`) получают свойство `({}).isAdmin === true`, что приводит к обходу проверок прав доступа и RCE (Remote Code Execution).

2. **Защита через `FORBIDDEN_KEYS`**:
   - Перед рекурсивным спуском блокируются ключи `__proto__`, `constructor` и `prototype`.
   - Проверка `isPlainObject` гарантирует, что мы не пытаемся модифицировать функции или системные объекты.

3. **Преимущества `Object.create(null)`**:
   - У такого объекта нет скрытого прототипа (`[[Prototype]] === null`).
   - Ключи вроде `"toString"`, `"valueOf"`, `"__proto__"` трактуются как обычные пользовательские строковые свойства, не ломая встроенные методы.

### Граничные случаи и ошибки
- **Вызов методов `Object.prototype` на чистом объекте**: вызов `dict.hasOwnProperty("key")` выбросит `TypeError: dict.hasOwnProperty is not a function`. Для проверки ключей на чистых объектах в современном JS используется `Object.hasOwn(dict, "key")`.

### Сложность
- **По времени**: `O(N)` — где `N` — общее число свойств во входных объектах.
- **По памяти**: `O(D)` — где `D` — глубина вложенности объектов (стек вызовов).

### Что запомнить для собеседования
- `Object.create(null)` создает объект без прототипа, безопасный для роли Hash Map.
- Prototype Pollution возникает при рекурсивном слиянии без фильтрации `__proto__`.
- Всегда используйте `Object.hasOwn(obj, prop)` вместо `obj.hasOwnProperty(prop)`.
