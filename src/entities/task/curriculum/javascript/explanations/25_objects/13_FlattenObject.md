### Что делает решение
Функция выполняет рекурсивное уплощение (flattening) древовидного объекта: обходит все вложенные ветви и формирует плоский одноуровневый объект, где ключи соответствуют полному пути от корня через точку (`'user.address.city'`).

### Пошаговый разбор

1. **Рекурсивный префикс пути**:
   - На каждом уровне рекурсии накапливается текущий путь: `newKey = prefix ? `${prefix}.${key}` : key`.
   - Для корневого уровня префикс пуст, поэтому первый ключ записывается без ведущей точки.

2. **Базовый vs рекурсивный случай**:
   - Если значение `val` является непустым объектом или массивом (`typeof val === 'object' && val !== null && Object.keys(val).length > 0`), вызывается рекурсивный шаг `flattenObject(val, newKey)`.
   - Результат рекурсии подмешивается в общий объект через `Object.assign(result, ...)`.
   - Если значение — примитив или пустой контейнер (`{}` / `[]`), оно записывается как лист дерева `result[newKey] = val`.

3. **Обработка массивов**:
   - `Object.keys([10, 20])` возвращает индексы `['0', '1']`, что автоматически формирует ключи вида `'roles.0'`, `'roles.1'`.

### Граничные случаи и ошибки
- **Пустые объекты и массивы**: если внутри объекта есть `{ flags: {} }`, мы не должны терять ключ `flags`. Проверка `Object.keys(val).length === 0` гарантирует сохранение пустых контейнеров в виде `{ flags: {} }`.
- **`null`**: в JS `typeof null === 'object'`, поэтому проверка `val !== null` строго обязательна.

### Сложность
- **По времени**: `O(N)`, где `N` — общее число примитивных значений и промежуточных объектов в дереве.
- **По памяти**: `O(N)` для хранения результирующего плоского словаря и стека рекурсии `O(D)`.

### Что запомнить для собеседования
- Массивы и объекты обрабатываются единообразно через `Object.keys()`.
- Аккумуляция пути через аргумент `prefix` — стандартный паттерн обхода деревьев в глубину (DFS).
