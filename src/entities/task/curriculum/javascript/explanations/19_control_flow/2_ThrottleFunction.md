# Реализация throttle

## 1. Какое поведение нужно получить

Throttle разрешает выполнять функцию не чаще одного раза за интервал `limit`. В отличие от debounce, он не ждёт полного прекращения событий. Поэтому throttle подходит для непрерывных потоков: `scroll`, `mousemove`, `resize`.

Текущая реализация работает в leading-режиме: первый вызов выполняется сразу, остальные во время закрытого окна отбрасываются.

## 2. Роль замыкания

```js
let inThrottle = false;
```

Флаг живёт между вызовами возвращённой функции. `false` означает «выполнение разрешено», `true` — «период ограничения ещё не закончился».

## 3. Пошаговый разбор

```js
return function (...args) {
  if (!inThrottle) {
    fn.apply(this, args);
    inThrottle = true;
```

Обычная функция выбрана намеренно: она получает `this` в момент вызова. `apply` передаёт этот контекст и все аргументы в исходную `fn`. После выполнения флаг закрывает окно.

```js
setTimeout(() => {
  inThrottle = false;
}, limit);
```

Таймер не вызывает `fn`, а только снова разрешает следующий вызов. Если в закрытом окне было десять событий, все десять будут проигнорированы.

## 4. Временная шкала

Пусть `limit = 200` мс. Вызовы приходят в моменты `0`, `50`, `100` и `250`:

1. вызов в `0` выполняется;
2. вызовы в `50` и `100` отбрасываются;
3. в `200` флаг открывается;
4. вызов в `250` выполняется.

## 5. Ограничения и варианты

- Текущая версия не делает trailing-вызов. Последнее событие закрытого интервала может потеряться.
- Нет метода `cancel`, который очистил бы таймер.
- Если `fn` бросит ошибку, строка `inThrottle = true` не выполнится и ограничитель останется открытым. Для особо надёжной версии состояние закрывают до вызова или используют `try/finally`.
- Значение `limit` должно быть неотрицательным числом.

## 6. Debounce или throttle

Debounce отвечает: «выполни после того, как события затихнут». Throttle отвечает: «во время потока выполняй не чаще заданной частоты».

## 7. Сложность

Каждое событие проверяет один флаг: `O(1)` времени и `O(1)` памяти. В любой момент существует не более одного таймера.

## 8. Что запомнить

Простой throttle — это замок с таймером. Первый вызов закрывает замок, таймер открывает его через `limit`, а вызовы между этими моментами не проходят.
