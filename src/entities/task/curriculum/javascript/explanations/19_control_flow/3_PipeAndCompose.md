# Композиция функций: pipe и compose

## 1. Идея композиции

Композиция соединяет маленькие функции в конвейер: результат одной функции становится аргументом следующей. Это позволяет читать преобразование как последовательность независимых шагов.

Для функций `add2(x)` и `multiply3(x)`:

- `pipe(add2, multiply3)(5)` вычисляет `multiply3(add2(5))`;
- `compose(multiply3, add2)(5)` вычисляет то же самое, но список читается справа налево.

## 2. Разбор pipe

```js
const pipe = (...functions) => (initialValue) =>
  functions.reduce((value, fn) => fn(value), initialValue);
```

Первый rest-параметр собирает функции в массив. Возвращается новая функция, которая позже получит начальное значение.

`reduce` начинает с `initialValue`. На каждой итерации `value` — результат предыдущего шага, а `fn(value)` создаёт значение для следующего. Поэтому порядок естественно идёт слева направо.

## 3. Разбор compose

```js
const compose = (...functions) => (initialValue) =>
  functions.reduceRight((value, fn) => fn(value), initialValue);
```

Разница только в `reduceRight`: массив обходится с конца. Запись `compose(f, g)(x)` соответствует математической композиции `f(g(x))`.

## 4. Почему начальное значение обязательно

Второй аргумент `reduce` и `reduceRight` делает функцию безопасной для пустого списка:

```js
pipe()(5);    // 5
compose()(5); // 5
```

Без initial value `reduce` на пустом массиве бросил бы ошибку.

## 5. Ограничения текущей реализации

- Каждая функция после первой должна принимать ровно один результат предыдущей. Это unary-конвейер.
- Асинхронные функции не ожидаются автоматически. Для них нужен `asyncPipe`, где аккумулятор — промис и каждый шаг вызывается через `await` или `.then`.
- Если один шаг бросит исключение, выполнение цепочки сразу прекратится. Это обычно правильное поведение, но ошибку должен обработать вызывающий код.
- Все функции должны быть переданы в нужном порядке; проверка типов здесь отсутствует.

## 6. Сложность

Для `k` функций выполняется ровно `k` вызовов: `O(k)` времени. Помимо массива функций, созданного rest-параметром, конвейер использует `O(k)` памяти на ссылки и `O(1)` служебного состояния во время одного запуска.

## 7. Что запомнить

`pipe` удобнее читать как поток данных слева направо. `compose` следует математической записи справа налево. Оба варианта — один и тот же `reduce`, различается лишь направление обхода.
