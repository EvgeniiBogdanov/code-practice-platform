### Что делает решение
- `arr.flat(depth = 1)` возвращает новый массив, в котором вложенные массивы «раскрыты» на `depth` уровней. `flat(Infinity)` раскрывает всё.
- `arr.flatMap(fn)` — это `arr.map(fn).flat(1)` за один проход. Если колбэк возвращает массив, его элементы встраиваются в результат.

`getAllTags` — типичный сценарий для `flatMap`: из массива объектов, у каждого из которых есть свой массив, нужно получить один общий список. Пустой массив тегов у черновика просто ничего не добавляет.

### Полезный приём: map и filter одним проходом
Если колбэк вернёт `[]`, элемент пропадёт, а если `[x]` — останется:
```js
const evensDoubled = [1, 2, 3, 4].flatMap((n) => (n % 2 === 0 ? [n * 2] : []));
// [4, 8]
```

### Граничные случаи и ошибки
- `flatMap` раскрывает **только один** уровень. Если колбэк вернёт `[[1]]`, в результате останется `[1]` как вложенный массив.
- `flat` пропускает дыры разреженных массивов: `[1, , 3].flat()` даёт `[1, 3]`.
- Если колбэк `flatMap` возвращает не массив, значение добавляется как есть.
- `"".split(" ")` возвращает `[""]`, а не `[]`. Пустые предложения дадут пустые строки в результате — при необходимости добавьте `.filter(Boolean)`.
- `flat(Infinity)` на очень глубокой вложенности работает медленнее ручного итеративного обхода, но переполнением стека не грозит.

### Сложность
- `flat(depth)` — `O(n)`, где `n` — общее количество элементов на всех раскрываемых уровнях.
- `flatMap` — `O(n + m)`, где `m` — суммарная длина возвращаемых массивов.
- По памяти — `O(n)` для результата.

### Что запомнить для собеседования
- `flatMap(fn)` = `map(fn).flat()` за один проход.
- `flat(Infinity)` — полное «сплющивание».
- Через `flatMap` удобно одновременно фильтровать и преобразовывать.
- Частое продолжение вопроса — «напишите полифил flat» (следующая задача в разделе полифилов).
