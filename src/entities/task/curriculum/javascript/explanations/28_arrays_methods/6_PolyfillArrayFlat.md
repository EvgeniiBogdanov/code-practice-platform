### Что делает решение
Полифил повторяет поведение встроенного `Array.prototype.flat`:
1. Метод объявлен через `function`, а не стрелку: внутри нужен `this` — массив, на котором вызван `myFlat`.
2. Вспомогательная рекурсивная функция `flatten(arr, currentDepth)` проходит по элементам:
   - если элемент — массив и глубина ещё позволяет (`currentDepth > 0`), спускаемся в него с `currentDepth - 1`;
   - иначе кладём элемент в общий результат как есть.
3. `!(i in arr)` пропускает «дыры» разреженного массива — так же ведёт себя встроенный `flat`.
4. Исходный массив не меняется: все элементы складываются в новый `result`.

`depth = Infinity` работает без особых проверок: `Infinity - 1 === Infinity`, поэтому условие `currentDepth > 0` всегда истинно.

### Итеративный вариант
Второе решение использует явный стек пар `[элемент, оставшаяся глубина]`. Элементы кладутся в стек в обратном порядке, чтобы снимать их в исходном. Такой вариант не упирается в лимит стека вызовов при очень глубокой вложенности (десятки тысяч уровней), и интервьюеры часто просят написать его после рекурсивного.

### Граничные случаи и ошибки
- `Array.isArray`, а не `instanceof Array`: второй ломается для массивов из другого iframe/realm.
- `depth = 0` должен вернуть поверхностную копию без раскрытия.
- Проверка «дыр» через `item === undefined` ошибочна: она удалит и настоящие `undefined`. Нужна именно проверка `i in arr`.
- Расширять `Array.prototype` в продакшене не рекомендуется (конфликты с будущими стандартами и библиотеками). В реальном коде полифил ставят только при отсутствии метода: `if (!Array.prototype.flat) { ... }`.
- Стрелочная функция вместо `function` сломает метод: `this` будет указывать не на массив.

### Сложность
- По времени: `O(n)`, где `n` — общее количество элементов на всех раскрываемых уровнях.
- По памяти: `O(n)` для результата плюс `O(d)` стека рекурсии (или явного стека), где `d` — глубина вложенности.

### Что запомнить для собеседования
- Полифил метода прототипа объявляют через `function`, чтобы получить `this`.
- Рекурсия с уменьшением `depth` или итерация со стеком — оба варианта нужно уметь написать.
- Дыры пропускаются через `i in arr`, массивы проверяются через `Array.isArray`.
