# Проверка объекта на пустоту

## 1. Что значит «пустой»

В этой задаче пустой объект — объект без собственных перечислимых строковых свойств. Унаследованные поля не должны делать его непустым.

```js
const isEmpty = (obj) => {
  for (const key in obj) {
    if (Object.hasOwn(obj, key)) return false;
  }
  return true;
};
```

## 2. Почему ранний возврат правильный

Чтобы доказать, что объект **не пуст**, достаточно найти один собственный ключ. Поэтому функция сразу возвращает `false` и не тратит время на оставшиеся свойства.

`true` можно вернуть только после завершения всего цикла: это означает, что ни один подходящий ключ не найден.

## 3. Зачем проверять Object.hasOwn

Объект может наследовать перечислимые свойства. Цикл их увидит, но они не принадлежат самому объекту:

```js
const obj = Object.create({ inherited: true });
isEmpty(obj); // true
```

Без `Object.hasOwn` функция ошибочно вернула бы `false`.

## 4. Альтернатива через Object.keys

```js
Object.keys(obj).length === 0;
```

Этот вариант лаконичен и автоматически игнорирует прототип. Но `Object.keys` всегда строит массив всех ключей. Цикл может закончиться на первом собственном свойстве и не создаёт промежуточный массив.

## 5. Сложность: исправление распространённой оценки

Ранний возврат даёт `O(1)` **в лучшем случае**, когда первый проверенный ключ собственный. Худший случай остаётся `O(n + p)`: пустой объект или объект только с унаследованными перечислимыми свойствами приходится проверить полностью. Поэтому называть решение `O(1) worst case` неверно.

## 6. Граничные случаи

- Символьное или неперечислимое собственное свойство не учитывается и объект будет считаться пустым по этому контракту.
- `Object.create(null)` корректно обрабатывается.
- Массив `[]` формально тоже объект: пустой массив вернёт `true`, массив с индексом — `false`.
- `null` и `undefined` следует отклонять или обрабатывать отдельно, если они допустимы на входе.

## 7. Что запомнить

Проверка на пустоту — задача на квантор «существует хотя бы один». Поэтому нужен ранний `false`, финальный `true` и точное определение, какие виды свойств считаются содержимым.
