# Инверсия ключей и значений объекта

## 1. Что делает функция

Исходная пара `key -> value` превращается в `value -> key`:

```js
{ admin: "1", editor: "2" }
// -> { "1": "admin", "2": "editor" }
```

Решение создаёт новый объект, поэтому исходные данные не мутируются.

## 2. Пошаговый разбор

```js
const inverted = {};

for (const key in obj) {
  if (Object.hasOwn(obj, key)) {
    inverted[obj[key]] = key;
  }
}

return inverted;
```

На каждой итерации `key` — старый ключ. `obj[key]` — старое значение, которое используется в квадратных скобках как новый ключ. Правой частью записывается старый key.

`Object.hasOwn` не позволяет инвертировать поля прототипа. Это особенно важно для произвольных входных объектов.

## 3. Неявное преобразование новых ключей

Ключи обычного объекта могут быть только строками или Symbols. Поэтому числа, boolean и объекты при присваивании преобразуются в строки:

```js
{ first: 1, second: true }
// -> { "1": "first", "true": "second" }
```

Два разных объекта-значения обычно оба превратятся в `'[object Object]'` и столкнутся. Если тип ключа нужно сохранить, лучше возвращать `Map`.

## 4. Дублирующиеся значения

```js
{ first: "x", second: "x" }
```

Обе пары пытаются записать ключ `x`. Вторая запись перезапишет первую, и результат станет `{ x: 'second' }`. Это не баг реализации, а потеря информации из-за неуникальных значений. Если нужно сохранить все ключи, значением нового объекта должен быть массив.

## 5. Альтернатива стандартными методами

```js
Object.fromEntries(
  Object.entries(obj).map(([key, value]) => [value, key])
);
```

Она лаконична и автоматически работает только с собственными перечислимыми ключами, но создаёт промежуточные массивы.

## 6. Безопасность результата

Значение `'__proto__'` как новый ключ может иметь особое поведение у обычного `{}`. Для недоверенных данных безопаснее `Object.create(null)` или `Map`.

## 7. Сложность

Время — `O(n)`, память нового объекта — `O(n)` в случае уникальных значений.

## 8. Что запомнить

Инверсия возможна без потерь только при уникальных и безопасно представимых значениях. Обычный объект приводит новые ключи к строкам; Map сохраняет их тип.
