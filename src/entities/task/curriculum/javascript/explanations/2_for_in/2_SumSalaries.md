# Сумма зарплат в объекте

## 1. Паттерн аккумулятора

Задача использует классический паттерн: создать нейтральное начальное значение, пройти данные и накопить результат.

```js
let sum = 0;

for (const key in salaries) {
  sum += salaries[key];
}

return sum;
```

Ноль — нейтральный элемент сложения. Поэтому пустой объект корректно возвращает `0`: цикл не выполнится ни разу, а начальное значение останется прежним.

## 2. Что происходит на итерациях

Для `{ Olga: 1200, Timur: 950, Lena: 1450 }`:

1. после `Olga` сумма равна `1200`;
2. после `Timur` — `2150`;
3. после `Lena` — `3600`.

Переменная `key` содержит имя сотрудника, а `salaries[key]` — числовое значение.

## 3. Предположения решения

Код предполагает, что все перечисляемые значения — числа. Если встретится строка, оператор `+` может перейти к конкатенации: `1000 + '500'` даст `'1000500'`. В реальной функции контракт стоит валидировать через `typeof value === 'number' && Number.isFinite(value)` или заранее гарантировать тип данных.

Текущая версия также суммирует унаследованные перечислимые свойства. Для входа с неизвестным прототипом добавляют `Object.hasOwn(salaries, key)`.

## 4. Альтернатива через Object.values

```js
Object.values(salaries).reduce(
  (total, salary) => total + salary,
  0
);
```

Этот вариант автоматически берёт только собственные перечислимые значения и явно показывает операцию свёртки. Цикл `for...in` создаёт меньше промежуточных данных, потому что `Object.values` сначала строит массив.

## 5. Граничные случаи

- `{}` возвращает `0`.
- `NaN` сделает итог `NaN`.
- `Infinity` сохранится в результате, если его не отфильтровать.
- Числа JavaScript имеют ограничения точности; для финансовых расчётов часто хранят минимальные единицы целыми числами или используют decimal-библиотеку.

## 6. Сложность

Для `n` свойств время — `O(n)`, дополнительная память цикла — `O(1)`. Вариант с `Object.values` использует `O(n)` дополнительной памяти.

## 7. Что запомнить

Аккумулятор начинается с нейтрального значения. `for...in` даёт ключ, значение берётся через квадратные скобки, а типы и собственность свойств являются частью контракта.
