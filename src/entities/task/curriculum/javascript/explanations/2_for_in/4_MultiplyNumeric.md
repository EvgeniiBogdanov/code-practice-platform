# Умножение числовых свойств

## 1. Что делает функция

Функция проходит объект и удваивает только значения с типом `number`. Строки, boolean и остальные типы остаются прежними.

```js
for (const key in obj) {
  if (typeof obj[key] === "number") {
    obj[key] *= 2;
  }
}
```

Для каждого ключа значение читается как `obj[key]`. Проверка типа отделяет числовые поля от остальных, а `*=` является сокращением `obj[key] = obj[key] * 2`.

## 2. Функция мутирует вход

Решение меняет исходный объект и возвращает ту же ссылку:

```js
const result = multiplyNumeric(menu);
result === menu; // true
```

Это допустимо, если мутация прямо указана в контракте. В состоянии React, Redux или при работе с разделяемыми данными безопаснее создать новый объект и записывать изменения в копию.

## 3. Особенности typeof number

`typeof NaN` и `typeof Infinity` тоже равны `'number'`. Поэтому:

- `NaN * 2` остаётся `NaN`;
- `Infinity * 2` остаётся `Infinity`.

Если нужны только конечные числа, используйте `Number.isFinite(value)`.

## 4. Собственные и унаследованные свойства

Текущий `for...in` видит унаследованные перечислимые свойства. Присваивание унаследованному числовому свойству создаст на объекте собственное свойство, скрывающее значение прототипа. Это может быть неожиданным побочным эффектом. Для обработки только собственных полей добавляют `Object.hasOwn(obj, key)`.

## 5. Почему строки не умножаются

Сам оператор `*` умеет приводить строку `'200'` к числу. Но задача требует менять именно числовые свойства, поэтому проверка `typeof` сознательно оставляет числовую строку без изменений. Это защита контракта, а не защита от конкатенации — оператор умножения строки не склеивает.

## 6. Сложность

Для `n` перечислимых свойств функция работает за `O(n)` времени и использует `O(1)` дополнительной памяти. Иммутабельный вариант потребовал бы `O(n)` памяти на новый объект.

## 7. Что запомнить

Здесь важны три решения: какие значения считать числами, разрешена ли мутация и нужно ли обрабатывать свойства прототипа. Само умножение — самая простая часть задачи.
