# Подсчёт свойств объекта

## 1. Базовое решение

```js
const countProps = (obj) => {
  let count = 0;

  for (const key in obj) {
    count += 1;
  }

  return count;
};
```

Счётчик начинается с нуля и увеличивается на каждой итерации. Само значение свойства не требуется, поэтому в решении переменная названа `_`: это соглашение «значение намеренно не используется». Более явно для junior можно оставить имя `key`.

## 2. Что именно считает for...in

Цикл считает все доступные перечислимые строковые свойства, включая унаследованные. Для простого объектного литерала это обычно совпадает с ожидаемым количеством. Но объект с прототипом может дать другой результат:

```js
const proto = { inherited: true };
const obj = Object.create(proto);
obj.own = true;

countProps(obj); // 2 в текущей реализации
```

Если задача требует только собственные свойства, внутри цикла нужна проверка `Object.hasOwn(obj, key)`.

## 3. Альтернатива через Object.keys

```js
const countProps = (obj) => Object.keys(obj).length;
```

`Object.keys` сразу возвращает массив собственных перечислимых строковых ключей. Его длина точно соответствует этому контракту. Цена лаконичности — создание промежуточного массива.

## 4. Какие свойства не попадут в результат

- Неперечислимые свойства не видны ни `for...in`, ни `Object.keys`.
- Символьные ключи также не учитываются.
- Для всех собственных ключей, включая неперечислимые и Symbols, нужны `Reflect.ownKeys(obj)`.

Поэтому фраза «количество свойств» всегда требует уточнения: собственные или унаследованные, перечислимые или все.

## 5. Граничные случаи

- Пустой объект возвращает `0`.
- `Object.create(null)` работает с `for...in` и не имеет унаследованного прототипа.
- `null` и `undefined` не соответствуют ожидаемому контракту объекта; в production можно валидировать аргумент.

## 6. Сложность

Оба подхода обходят свойства за `O(n)`. Цикл использует `O(1)` дополнительной памяти, а `Object.keys` — `O(n)` на массив ключей.

## 7. Что запомнить

Подсчёт прост, но слово «свойство» неоднозначно. Сначала определите контракт, затем выбирайте `for...in`, `Object.keys` или `Reflect.ownKeys`.
