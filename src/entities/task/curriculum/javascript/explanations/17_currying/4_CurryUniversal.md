### Что делает решение
**Каррирование** превращает функцию `f(a, b, c)` в цепочку `f(a)(b)(c)`. Универсальный `curry` работает для любой функции с фиксированным числом параметров:
1. `fn.length` — количество объявленных параметров исходной функции (для `sum3` это `3`).
2. `curried(...args)` проверяет, сколько аргументов уже собрано.
3. Если `args.length >= fn.length`, вызывается `fn(...args)`.
4. Иначе возвращается новая функция. Она замыкает уже собранные `args` и при следующем вызове передаёт в `curried` старые и новые аргументы вместе.

Благодаря `...args` поддерживаются и вызовы группами: `curriedSum(1, 2)(3)`.

### Почему частично применённая функция переиспользуется
Каждый вызов возвращает **новую** функцию со своим замкнутым массивом аргументов. `addOne = curriedSum(1)` хранит `[1]` и не меняется при вызовах `addOne(10)` и `addOne(20, 200)`. Если накапливать аргументы в одном общем массиве (через `push`), второй вызов `addOne` получит «мусор» от первого. Это самая частая ошибка в этой задаче.

### Где это применяется
- Создание специализированных функций: `const getById = curry(findBy)("id")`.
- Функциональное программирование и композиция (`pipe`, `compose`): в цепочку удобно передавать функции одного аргумента.
- Библиотеки Ramda и lodash/fp, где все функции каррированы.

### Граничные случаи и ошибки
- `fn.length` **не учитывает** параметры по умолчанию и rest: у `(a, b = 1) => ...` значение `length` равно `1`, а у `(...args) => ...` — `0`. Такие функции нужно каррировать с явной арностью: `curry(fn, arity)`.
- Лишние аргументы (`curriedSum(1, 2, 3, 4)`) передаются в `fn`, и она их просто игнорирует.
- Стрелочная реализация не сохраняет `this`. Для каррирования методов используют `function` и `fn.apply(this, args)`.
- Бесконечное каррирование `sum(1)(2)(3)()` — другая задача: там нет фиксированной арности, а завершение определяется пустым вызовом.

### Сложность
- Каждый промежуточный вызов — `O(k)` на копирование накопленных аргументов, где `k ≤ fn.length`.
- По памяти: `O(k)` на каждую частично применённую функцию.

### Что запомнить для собеседования
- Базовое условие — `args.length >= fn.length`.
- Аргументы накапливаются через замыкание и spread, а не мутацией общего массива.
- `fn.length` не видит дефолтные и rest-параметры.
