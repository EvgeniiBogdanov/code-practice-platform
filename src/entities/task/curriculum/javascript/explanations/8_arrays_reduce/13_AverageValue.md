## Что такое среднее арифметическое

Среднее арифметическое — это сумма всех чисел, делённая на их количество. Для `[1, 2, 3, 4, 5]` сумма равна `15`, количество — `5`, результат — `3`.

## Что делает базовое решение

```js
const average = (numbers) => {
  if (numbers.length === 0) return 0;
  const sum = numbers.reduce((acc, num) => acc + num, 0);
  return sum / numbers.length;
};
```

Сначала функция отдельно обрабатывает пустой массив. Без проверки выражение `0 / 0` вернуло бы `NaN`. Затем `reduce` считает сумму, начиная с нуля, и после прохода сумма делится на длину массива.

Трассировка суммы для `[10, 20, 30]`:

| `num` | сумма после шага |
| ---: | ---: |
| старт | 0 |
| 10 | 10 |
| 20 | 30 |
| 30 | 60 |

После `reduce`: `60 / 3 = 20`.

## Два подхода к решению задачи

### Подход 1: Идиоматичный двухэтапный расчет (сумма через reduce, затем деление)

```js
const average = (numbers) => {
  if (numbers.length === 0) return 0;
  const sum = numbers.reduce((acc, num) => acc + num, 0);
  return sum / numbers.length;
};
```

`reduce` отвечает строго за агрегацию суммы за O(N), а деление на общую длину массива выполняется один-единственный раз в конце за O(1). Это самый быстрый, точный и читаемый вариант для продакшена и собеседований.

### Подход 2: Однопроходный расчет через 4-й аргумент колбэка (`array`)

```js
const average = (numbers) => {
  if (numbers.length === 0) return 0;
  return numbers.reduce((acc, num, _index, array) => {
    return acc + num / array.length;
  }, 0);
};
```

Четвёртый параметр `array` — тот массив, на котором вызван `reduce`. Каждый элемент сразу превращается в свою долю среднего: `acc + num / array.length`. Для `[10, 20, 30]` аккумулятор получает `10 / 3`, затем `20 / 3`, затем `30 / 3`.

Этот вариант удобен в функциональных пайплайнах (method chaining), когда нет сохранённой ссылки на массив до вызова метода. Однако он производит N операций деления с плавающей точкой вместо одной и может накапливать погрешность IEEE 754.

## Граничные случаи и ошибки

- В варианте с долями пустой массив возвращает `0`: колбэк ни разу не вызывается, деления на ноль нет.
- Нечисловое значение может превратить результат в строку или `NaN`.
- Для дробей возможна стандартная погрешность IEEE 754.
- Если `0` для пустого набора не имеет предметного смысла, лучше вернуть `null` или явно выбросить ошибку по договорённости API.

## Сложность

Оба решения работают за `O(n)` времени и используют `O(1)` дополнительной памяти.

## Что запомнить

У колбэка `reduce` есть параметры `(accumulator, currentValue, index, array)`. Но использовать все параметры следует не ради краткости, а когда это действительно требуется условием или делает вычисление понятнее.
