## Что делает решение

Функция считает итоговую стоимость корзины. Стоимость одной позиции — это цена одной единицы, умноженная на количество: `price * quantity`. Затем стоимости всех позиций складываются.

Это важно отличать от простой суммы цен. Если яйца стоят `120`, но в корзине их `3`, вклад позиции равен `360`, а не `120`.

## Пошаговый разбор

```js
const totalPrice = (cart) => {
  return cart.reduce(
    (acc, { price, quantity }) => acc + price * quantity,
    0
  );
};
```

- `0` — начальная общая стоимость. Благодаря ему пустая корзина корректно даёт `0`.
- Второй параметр колбэка — очередной товар. Запись `{ price, quantity }` сразу извлекает нужные поля из объекта.
- `price * quantity` вычисляет стоимость текущей позиции.
- `acc + ...` прибавляет её к уже накопленной сумме.
- Стрелочная функция без фигурных скобок неявно возвращает новое значение аккумулятора.

Для тестовой корзины вычисления выглядят так:

| Товар | Расчёт позиции | Общая сумма |
| --- | ---: | ---: |
| Хлеб | `50 * 2 = 100` | 100 |
| Молоко | `80 * 1 = 80` | 180 |
| Яйца | `120 * 3 = 360` | 540 |

Ответ — `540`.

## Почему нужен начальный `0`

Без начального значения первый объект корзины стал бы `acc`. Затем JavaScript попытался бы сложить объект и число. Это уже не числовая агрегация и результат оказался бы ошибочным. Явный `0` также определяет тип аккумулятора: на каждом шаге это число.

## Граничные случаи и ошибки

- Пустой массив возвращает `0`.
- Отсутствующий `price` или `quantity` приводит к `NaN`; в реальном приложении данные нужно валидировать до расчёта.
- Отрицательные значения могут быть допустимы для возврата товара, но это должно быть явно определено бизнес-правилами.
- Для денег числа с плавающей точкой могут давать погрешность, например `0.1 + 0.2`. В платёжном коде обычно считают в минимальных единицах — копейках или центах.
- Решение не изменяет ни массив, ни товары внутри него.

## Сложность

Время — `O(n)`, потому что корзина обходится один раз. Дополнительная память — `O(1)`.

## Что запомнить

Сначала определите вклад одного элемента в результат, здесь это `price * quantity`. После этого `reduce` лишь складывает такие вклады, начиная с безопасного нейтрального значения `0`.
