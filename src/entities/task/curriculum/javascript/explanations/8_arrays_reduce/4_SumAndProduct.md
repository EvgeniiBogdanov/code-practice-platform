## Что делает решение

Функция за один проход считает сразу два результата: сумму всех чисел и их произведение. Поэтому аккумулятор здесь не число, а объект с двумя независимыми полями:

```js
{ sum: 0, prod: 1 }
```

`sum` начинается с `0`, потому что `0 + x = x`. `prod` начинается с `1`, потому что `1 * x = x`. Это нейтральные значения операций. Если начать произведение с нуля, результат навсегда останется нулём.

## Как работает `reduce`

```js
const sumAndProduct = (numbers) => {
  return numbers.reduce((acc, num) => {
    acc.sum += num;
    acc.prod *= num;
    return acc;
  }, { sum: 0, prod: 1 });
};
```

На каждой итерации `num` — очередное число, а `acc` — один и тот же объект с промежуточным результатом. Сначала обновляются оба поля, затем аккумулятор обязательно возвращается. Возвращённое значение станет `acc` следующей итерации.

Для массива `[1, 2, 3, 4, 5]` состояние меняется так:

| `num` | `acc.sum` | `acc.prod` |
| ---: | ---: | ---: |
| старт | 0 | 1 |
| 1 | 1 | 1 |
| 2 | 3 | 2 |
| 3 | 6 | 6 |
| 4 | 10 | 24 |
| 5 | 15 | 120 |

Итог — `{ sum: 15, prod: 120 }`.

## Почему объект можно изменять

Здесь мутируется не исходный массив, а новый объект, созданный специально для этого вызова `reduce`. Такой подход не создаёт копию объекта на каждом шаге и подходит для аккумулятора. Важно не передавать в качестве начального значения объект, который используется где-то ещё.

## Граничные случаи и ошибки

- Пустой массив вернёт `{ sum: 0, prod: 1 }`. Это математически последовательный результат, но продуктовые требования могут ожидать другое поведение.
- Если забыть `return acc`, следующая итерация получит `undefined` и код упадёт.
- Нечисловые значения могут привести к конкатенации в `sum` или к `NaN` в `prod`.
- Произведение больших чисел может выйти за безопасный диапазон `Number`.

## Сложность

Время — `O(n)`: каждый элемент обрабатывается один раз. Дополнительная память — `O(1)`: объект всегда содержит только два поля.

## Что запомнить

Форма аккумулятора должна совпадать с формой результата. Для нескольких агрегатов удобно сразу завести объект, а начальные значения выбирать как нейтральные элементы соответствующих операций.
