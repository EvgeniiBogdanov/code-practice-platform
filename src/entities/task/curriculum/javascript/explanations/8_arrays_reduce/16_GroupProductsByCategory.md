## Что делает решение

Функция группирует продукты по полю `category`, но в результирующий объект помещает не целые объекты, а только массивы их названий (`name`). Из исходного списка товаров формируется структура:

```js
{
  "Фрукты": ["Яблоко", "Банан", "Груша"],
  "Овощи": ["Морковь", "Огурец"]
}
```

Это сочетание двух операций: категория определяет ключ группы, а поле `name` отбирает значение, сохраняемое внутри массива.

## Пошаговый разбор `reduce`

```js
const groupProductsByCategory = (products) => {
  return products.reduce((acc, product) => {
    acc[product.category] ??= [];
    acc[product.category].push(product.name);
    return acc;
  }, {});
};
```

1. **Начальный аккумулятор**: `{}` (пустой объект).
2. **Оператор логического присваивания (`??=`)**: выражение `acc[product.category] ??= []` проверяет, существует ли уже массив для текущей категории. Если свойства нет (или оно `null`/`undefined`), создается пустой массив `[]`. Если массив уже существует, он сохраняется без перезаписи.
3. **Наполнение массива**: метод `push(product.name)` добавляет только название продукта в массив соответствующей категории.
4. **Возврат аккумулятора**: возвращается объект `acc` для следующей итерации.

Трассировка шагов:

| Товар | Категория | Состояние аккумулятора `acc` |
| :--- | :--- | :--- |
| Яблоко | Фрукты | `{ "Фрукты": ["Яблоко"] }` |
| Морковь | Овощи | `{ "Фрукты": ["Яблоко"], "Овощи": ["Морковь"] }` |
| Банан | Фрукты | `{ "Фрукты": ["Яблоко", "Банан"], "Овощи": ["Морковь"] }` |
| Огурец | Овощи | `{ "Фрукты": ["Яблоко", "Банан"], "Овощи": ["Морковь", "Огурец"] }` |
| Груша | Фрукты | `{ "Фрукты": ["Яблоко", "Банан", "Груша"], "Овощи": ["Морковь", "Огурец"] }` |

Порядок названий внутри каждой категории строго соответствует порядку их появления в исходном массиве.

## Вариант со встроенным `Object.groupBy` (ES2024)

В современном стандарте ECMAScript доступен статический метод `Object.groupBy()`:

```js
const grouped = Object.groupBy(products, (product) => product.category);
```

Однако `Object.groupBy()` группирует элементы массива целиком:
```js
{
  "Фрукты": [{ name: "Яблоко", ... }, { name: "Банан", ... }, ...],
  "Овощи": [{ name: "Морковь", ... }, ...]
}
```

Поэтому для получения требуемого формата (только массивы названий `name`) необходим второй шаг преобразования:

```js
const groupProductsByCategory = (products) => {
  const grouped = Object.groupBy(products, (product) => product.category);
  return Object.fromEntries(
    Object.entries(grouped).map(([category, list]) => [
      category,
      list.map((item) => item.name),
    ])
  );
};
```

Такой вариант декларативен и демонстрирует владение ES2024, но требует нескольких промежуточных аллокаций и обходов. Классический `reduce()` решает задачу за один линейный проход.

## Граничные случаи и ошибки

- **Пустой массив**: `groupProductsByCategory([])` возвращает `{}`.
- **Товар без категории**: если `product.category` отсутствует, ключ станет `"undefined"`.
- **Регистрозависимость**: ключи `"Фрукты"` и `"фрукты"` считаются разными группами.
- **Мутации**: мутируются только созданные внутри редюсера массивы в аккумуляторе, исходный массив `products` и его элементы остаются неизменными.

## Сложность

- **Время**: $O(n)$, где $n$ — количество элементов в массиве `products`. Каждый элемент обрабатывается ровно один раз, а операция `push` выполняется за амортизированное $O(1)$.
- **Память**: $O(n)$ для хранения результирующего объекта со всеми сгруппированными строками названий.

## Что запомнить

При группировке данных через `reduce()` используйте оператор `acc[key] ??= []` для лаконичной инициализации списков. Если требуется группировать не объекты целиком, а их конкретные свойства, извлекайте нужное поле (`product.name`) непосредственно при добавлении в массив.
