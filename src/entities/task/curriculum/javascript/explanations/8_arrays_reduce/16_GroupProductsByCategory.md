## Что делает решение

Функция группирует продукты по `category`, но в результат кладёт не целые объекты, а только их названия. Из трёх записей получается объект вида:

```js
{
  Fruit: ['Apple', 'Banana'],
  Vegetable: ['Carrot']
}
```

Это сочетание двух преобразований: категория выбирает группу, а поле `name` определяет, что сохраняется внутри неё.

## Пошаговый разбор `reduce`

```js
const groupProductsByCategory = (products) => {
  return products.reduce((acc, product) => {
    acc[product.category] ??= [];
    acc[product.category].push(product.name);
    return acc;
  }, {});
};
```

Аккумулятор начинается с пустого объекта. Для первого Apple категории Fruit ещё нет, поэтому `??=` создаёт массив. Затем `push` добавляет строку `'Apple'`. Для Banana массив Fruit уже существует и повторно не создаётся. Carrot открывает новую группу Vegetable.

| Продукт | Аккумулятор после шага |
| --- | --- |
| Apple / Fruit | `{ Fruit: ['Apple'] }` |
| Banana / Fruit | `{ Fruit: ['Apple', 'Banana'] }` |
| Carrot / Vegetable | `{ Fruit: [...], Vegetable: ['Carrot'] }` |

Исходный порядок названий внутри каждой категории сохраняется.

## Вариант с `Object.groupBy`

```js
const grouped = Object.groupBy(products, (product) => product.category);
```

Сам по себе этот вызов группирует **целые объекты**, поэтому для требуемых массивов названий нужен второй этап:

```js
return Object.fromEntries(
  Object.entries(grouped).map(([category, list]) => [
    category,
    list.map((product) => product.name),
  ])
);
```

Такой вариант декларативен и использует современный стандарт, но делает несколько проходов и создаёт промежуточные структуры. `reduce` решает конкретную задачу за один проход и работает в более старых окружениях. Выбор зависит от поддержки среды и читаемости для команды.

## Граничные случаи и ошибки

- Пустой массив возвращает `{}`.
- Продукт без `category` попадёт в группу `'undefined'`, а без `name` добавит `undefined`.
- Категории чувствительны к регистру и пробелам: `'Fruit'` и `'fruit'` — разные ключи.
- Если категории приходят из недоверенного источника, для словаря безопаснее рассмотреть `Map` или объект без прототипа.
- `push` меняет только новые массивы аккумулятора; исходные объекты продуктов не мутируются.

## Сложность

Вариант с `reduce` работает за `O(n)` времени. Результат хранит `n` названий и до `k` групп, поэтому память — `O(n + k)`, то есть асимптотически `O(n)`.

## Что запомнить

При группировке отдельно ответьте на два вопроса: «по какому полю выбираем корзину?» и «что кладём в корзину?». Здесь ответы — `category` и `name`; путать их нельзя.
