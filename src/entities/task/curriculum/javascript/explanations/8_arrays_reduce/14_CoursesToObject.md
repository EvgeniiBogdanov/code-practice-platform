## Что делает решение

Функция преобразует массив курсов в объект быстрого доступа: название курса становится ключом, а цена — значением.

```js
[
  { course: 'JavaScript', price: '30000' },
  { course: 'React', price: '40000' }
]

// превращается в
{
  JavaScript: '30000',
  React: '40000'
}
```

## Пошаговый разбор

```js
const coursesToObject = (arr) => {
  return arr.reduce((acc, { course, price }) => {
    acc[course] = price;
    return acc;
  }, {});
};
```

Начальный аккумулятор `{}` определяет форму результата. На каждой итерации второй аргумент деструктурируется: из текущего объекта сразу извлекаются `course` и `price`.

В `acc[course]` используются квадратные скобки, потому что имя свойства хранится в переменной. Если `course === 'HTML + CSS'`, будет создан ключ именно `'HTML + CSS'`. Запись `acc.course` создала бы один буквальный ключ `'course'` и перезаписывала его на каждой итерации.

После первого курса аккумулятор равен `{ JavaScript: '30000' }`, после второго — `{ JavaScript: '30000', React: '40000' }`.

## Почему прямое присвоение лучше spread в этом месте

Альтернативу можно записать так:

```js
arr.reduce(
  (acc, item) => ({ ...acc, [item.course]: item.price }),
  {}
);
```

Она создаёт новый объект и копирует все уже накопленные поля на каждой итерации. Чем больше курсов, тем больше повторного копирования; в худшем случае суммарная работа приближается к `O(n²)`. Прямое присвоение изменяет только локальный аккумулятор, созданный внутри функции, и не мутирует исходный массив.

## Обратите внимание на контракт данных

Показанное решение ожидает поля `{ course, price }`. Если во входном примере используются `{ name, count }`, алгоритм остаётся тем же, но имена должны совпадать с данными:

```js
acc[item.name] = item.count;
```

Нельзя механически копировать решение с другими названиями полей: тогда появится ключ `'undefined'`.

## Граничные случаи и ошибки

- Пустой массив возвращает `{}`.
- Повторное название курса перезапишет прежнюю цену; побеждает последний элемент.
- Сейчас цены — строки. Если дальше нужны вычисления, лучше хранить числа и отдельно форматировать их для интерфейса.
- Числовые и строковые ключи объекта могут приводиться к одной строковой форме.

## Сложность

Вариант с прямым присвоением работает за `O(n)` времени и использует `O(n)` памяти для результирующего объекта.

## Что запомнить

Преобразование списка пар в объект строится паттерном `acc[динамическийКлюч] = значение`. Всегда сверяйте названия полей входных данных и заранее определяйте поведение при одинаковых ключах.
