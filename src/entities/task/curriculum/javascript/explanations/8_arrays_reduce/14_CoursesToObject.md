## Что делает решение

Функция преобразует массив пар `[курс, часы]` в объект быстрого доступа: название курса становится ключом, а количество академических часов — значением.

```js
const courses = [
  ['JavaScript', 40],
  ['React', 30],
  ['TypeScript', 25],
];

// превращается в
{
  JavaScript: 40,
  React: 30,
  TypeScript: 25
}
```

Такая структура данных позволяет получать длительность любого курса по его названию за `O(1)` времени вместо линейного поиска `find()` по массиву за `O(n)`.

## Пошаговый разбор `reduce`

```js
const coursesToObject = (courses) => {
  return courses.reduce((acc, [course, hours]) => {
    acc[course] = hours;
    return acc;
  }, {});
};
```

1. **Начальное значение аккумулятора**: `{}` (пустой объект), переданный вторым аргументом в `reduce`.
2. **Деструктуризация аргументов**: каждый элемент массива пар деструктурируется прямо в сигнатуре колбэка как `[course, hours]`. Это чище и выразительнее, чем ручное обращение по индексам `item[0]` и `item[1]`.
3. **Вычисляемые свойства**: в `acc[course] = hours` используются квадратные скобки, так как имя ключа является переменной. Точечная нотация `acc.course` создала бы литеральное свойство `"course"`, перезаписывая его на каждом шаге.
4. **Возврат аккумулятора**: возвращается ссылка на тот же объект `acc` для следующего шага свертки.

Трассировка шагов:

| Итерация | Текущая пара `[course, hours]` | Состояние аккумулятора `acc` |
| :--- | :--- | :--- |
| Старт | — | `{}` |
| 1 | `['JavaScript', 40]` | `{ JavaScript: 40 }` |
| 2 | `['React', 30]` | `{ JavaScript: 40, React: 30 }` |
| 3 | `['TypeScript', 25]` | `{ JavaScript: 40, React: 30, TypeScript: 25 }` |

## Почему прямое присвоение лучше spread в аккумуляторе

Альтернативный однострочный вариант часто записывают через спред:

```js
const coursesToObject = (courses) =>
  courses.reduce((acc, [course, hours]) => ({ ...acc, [course]: hours }), {});
```

Хотя такой код выглядит лаконично и декларативно, на каждой из $n$ итераций он создает новый объект и копирует в него все ранее накопленные свойства. В результате:
- Время выполнения деградирует с $O(n)$ до $O(n^2)$.
- Создается $n$ промежуточных объектов, нагружающих сборщик мусора (GC).

Прямое присвоение `acc[course] = hours` мутирует локальный изолированный объект-аккумулятор, созданный внутри метода, не затрагивая внешние структуры данных и работая за оптимальное время $O(n)$.

## Альтернатива: `Object.fromEntries()`

В современном JavaScript для массивов пар вида `[ключ, значение]` существует встроенный стандартный метод:

```js
const coursesToObject = (courses) => Object.fromEntries(courses);
```

Если условие задачи или интервьюер не требуют строго использовать `reduce()`, вызов `Object.fromEntries()` является самым лаконичным, нативным и производительным решением в экосистеме ECMAScript.

## Граничные случаи и ошибки

- **Пустой массив**: `coursesToObject([])` корректно возвращает `{}`.
- **Дубликаты курсов**: если в массиве встретится повторный курс с другим количеством часов, победит последнее значение в массиве (перезапишет предыдущее).
- **Специальные ключи**: ключи вроде `__proto__` или `toString` могут переопределить стандартные свойства `Object.prototype`. Если данные приходят из ненадежного внешнего источника, предпочтительнее использовать `Object.create(null)` в качестве начального аккумулятора или коллекцию `Map`.
- **Некорректная структура элементов**: если элемент массива не является парой (например, пустой массив или не массив), деструктуризация `[course, hours]` запишет `undefined` в ключ или значение.

## Сложность

- **Время**: $O(n)$, где $n$ — количество курсов в массиве. Каждый элемент обрабатывается ровно один раз.
- **Память**: $O(n)$ для хранения итогового результирующего объекта.

## Что запомнить

Преобразование массива пар `[key, value]` в объект — классический паттерн ассоциативной индексации. При решении через `reduce()` используйте деструктуризацию кортежей `[key, value]` и прямое присвоение `acc[key] = value`, избегая квадратичного спреда `{ ...acc }`. В реальном продакшене отдавайте предпочтение `Object.fromEntries(entries)`.
