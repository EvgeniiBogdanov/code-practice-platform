## Что делает решение

Функция находит минимальное и максимальное число за один проход. Аккумулятор хранит сразу две границы:

```js
{ min: Infinity, max: -Infinity }
```

`Infinity` гарантированно больше любого конечного числа, поэтому первый элемент заменит `min`. `-Infinity` меньше любого конечного числа, поэтому первый элемент заменит `max`.

## Пошаговый разбор

```js
const findMinMax = (numbers) => {
  return numbers.reduce((acc, num) => {
    acc.min = Math.min(acc.min, num);
    acc.max = Math.max(acc.max, num);
    return acc;
  }, { min: Infinity, max: -Infinity });
};
```

На каждом шаге текущее число сравнивается с обеими накопленными границами. Для `[23, 4, 45, 2]` получится:

| `num` | новый `min` | новый `max` |
| ---: | ---: | ---: |
| старт | `Infinity` | `-Infinity` |
| 23 | 23 | 23 |
| 4 | 4 | 23 |
| 45 | 4 | 45 |
| 2 | 2 | 45 |

Итог — `{ min: 2, max: 45 }`.

## Вариант без `Math.min` и `Math.max`

В альтернативном решении используются условные выражения:

```js
acc.min = acc.min < num ? acc.min : num;
acc.max = acc.max > num ? acc.max : num;
```

Смысл тот же: оставить прежнюю границу или заменить её текущим числом. Оба варианта имеют одинаковую алгоритмическую сложность. Выбирать тернарный вариант только ради предполагаемого микроскопического выигрыша обычно не стоит без измерений; `Math.min` и `Math.max` легче прочитать.

## Граничные случаи и ошибки

- Для пустого массива текущее решение вернёт `{ min: Infinity, max: -Infinity }`. Это технически следует из начального аккумулятора, но обычно вызывающему коду удобнее получить `null`, ошибку или заранее согласованный результат.
- `NaN` «заражает» вычисление: после него обе границы могут стать `NaN`.
- Строковые числа приводятся к числам функциями `Math.min`/`Math.max`, но полагаться на неявное преобразование не стоит.
- Вызовы `Math.min(...numbers)` и `Math.max(...numbers)` короче, но делают два прохода и spread может упереться в лимит аргументов на очень большом массиве.

## Сложность

Время — `O(n)`: для каждого элемента выполняются два сравнения. Дополнительная память — `O(1)`.

## Что запомнить

Когда за один проход нужно получить несколько связанных результатов, используйте объект-аккумулятор. Отдельно определите поведение пустого массива: стартовые бесконечности удобны для вычисления, но редко подходят как пользовательский результат.
