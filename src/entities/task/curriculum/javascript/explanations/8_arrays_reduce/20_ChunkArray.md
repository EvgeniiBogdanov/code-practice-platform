### Что делает решение
Решение реализует популярную библиотечную утилиту `chunk(array, size)` (аналог `lodash.chunk`):
1. Валидирует входные данные: проверяет `Array.isArray(array)` и положительный целочисленный `size`.
2. Шагает по массиву с шагом `chunkSize` и извлекает непересекающиеся подмассивы через `array.slice(i, i + chunkSize)`.
3. Корректно помещает остаток элементов в финальный подмассив без выхода за границы длины массива.

### Пошаговый разбор реализации

1. **Валидация размера**:
   - Приведение к числу и `Math.floor` защищает от дробных размеров (`size = 2.7` округляется до `2`).
   - Проверка `chunkSize <= 0 || !Number.isFinite(chunkSize)` предотвращает зацикливание `for (let i = 0; ...; i += 0)`.

2. **Неизменяемость через `slice`**:
   - Метод `Array.prototype.slice(start, end)` возвращает поверхностную копию фрагмента массива, не мутируя оригинал.

### Граничные случаи и ошибки
- **`size` больше длины массива**: возвращает `[[...array]]` (один чанк со всеми элементами).
- **Пустой массив `[]`**: возвращает `[]`.
- **Некорректный `size` (0, отрицательный, NaN, undefined)**: возвращает `[]`.

### Сложность
- **По времени**: `O(n)` — каждый элемент копируется ровно один раз через `slice`.
- **По памяти**: `O(n)` — создание нового двумерного массива, содержащего ссылки на все элементы.

### Что запомнить для собеседования
- `chunk` группирует массив на чанки фиксированного размера.
- Использование `slice` внутри цикла с шагом `i += size` — наиболее производительный и чистый подход.
