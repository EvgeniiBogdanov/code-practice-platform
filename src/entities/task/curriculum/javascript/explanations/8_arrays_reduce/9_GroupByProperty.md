## Что делает решение

`groupBy(arr, key)` раскладывает объекты по группам. Значение свойства `key` становится ключом результата, а сам объект добавляется в массив соответствующей группы.

Для людей с возрастами `20`, `30`, `20` результат имеет форму:

```js
{
  20: [alice, sem],
  30: [brat]
}
```

## Пошаговый разбор

```js
const groupBy = (arr, key) => {
  return arr.reduce((acc, item) => {
    const groupKey = item[key];
    acc[groupKey] ??= [];
    acc[groupKey].push(item);
    return acc;
  }, {});
};
```

Здесь особенно важна запись `item[key]`. Если `key === 'age'`, она читает `item.age`. Запись `item.key` искала бы буквально свойство с именем `key` и для этих данных вернула бы `undefined`.

На каждой итерации выполняются три действия:

1. Получить значение, по которому группируем.
2. Создать пустой массив, только если такой группы ещё нет. `??=` срабатывает для `undefined` и `null`.
3. Добавить исходный объект в найденную группу.

Для первого человека с возрастом `20` создаётся `acc[20] = []`, затем туда попадает объект Alice. Для возраста `30` создаётся новая группа. Когда встречается Sem с возрастом `20`, массив уже существует, поэтому объект просто добавляется следом.

## Современная альтернатива

В среде с поддержкой `Object.groupBy` ту же операцию можно записать так:

```js
const grouped = Object.groupBy(people, (person) => person.age);
```

Это хороший выбор, когда нужна только группировка. Ручной `reduce` остаётся полезным для старых окружений или когда одновременно нужно преобразовать элементы, посчитать суммы либо построить другую структуру. У `Object.groupBy` результат имеет `null`-прототип, поэтому не стоит предполагать наличие методов вроде `hasOwnProperty` прямо на результате.

## Граничные случаи и ошибки

- Если свойства `key` нет, объект попадёт в группу с ключом `'undefined'`.
- Ключи обычного объекта приводятся к строкам или символам. Числовые `20` и строковые `'20'` окажутся одной группой.
- В группы кладутся ссылки на исходные объекты. Последующая мутация объекта будет видна и в исходном массиве, и в результате.
- Для произвольных ключей можно рассмотреть `Map.groupBy`, если доступен нужный стандарт, либо ручную группировку в `Map`.

## Сложность

Время — `O(n)`. Дополнительная память — `O(n + k)`: хранятся ссылки на все элементы и до `k` групп.

## Что запомнить

Паттерн группировки состоит из двух обязательных шагов: лениво создать контейнер группы и добавить в него элемент. Квадратные скобки нужны, когда имя свойства приходит в переменной.
