## Что делает решение

Функция строит таблицу частот: для каждого уникального элемента запоминает, сколько раз он встретился. Например, из `['a', 'b', 'a']` получается `{ a: 2, b: 1 }`.

Удобная мысленная модель: аккумулятор — это журнал счётчиков. Каждый новый элемент либо открывает в нём новую запись со значением `1`, либо увеличивает существующую.

## Вариант с объектом

```js
const countOccurrences = (arr) => {
  return arr.reduce((acc, el) => {
    acc[el] = (acc[el] || 0) + 1;
    return acc;
  }, {});
};
```

Разберём выражение `(acc[el] || 0) + 1`:

1. `acc[el]` читает текущий счётчик.
2. Для нового ключа результат равен `undefined`.
3. `undefined || 0` даёт стартовый ноль.
4. После `+ 1` первое значение становится единицей.

Трассировка для `['a', 'b', 'a', 'c', 'b', 'a']`:

| Элемент | Аккумулятор после шага |
| --- | --- |
| `a` | `{ a: 1 }` |
| `b` | `{ a: 1, b: 1 }` |
| `a` | `{ a: 2, b: 1 }` |
| `c` | `{ a: 2, b: 1, c: 1 }` |
| `b` | `{ a: 2, b: 2, c: 1 }` |
| `a` | `{ a: 3, b: 2, c: 1 }` |

## Почему в рекомендуемых вариантах есть `Map`

```js
const countOccurrences = (arr) =>
  arr.reduce((acc, el) => {
    acc.set(el, (acc.get(el) || 0) + 1);
    return acc;
  }, new Map());
```

Ключи обычного объекта приводятся к строкам: числа `1` и строка `'1'` попадут в один ключ. Объекты тоже превратятся в строку вроде `'[object Object]'`. `Map` сохраняет тип ключа, поэтому отдельно считает строки, числа, объекты и символы. За это результат читают через `result.get(key)`, а не через квадратные скобки.

## Граничные случаи и ошибки

- Пустой массив возвращает пустой объект или пустой `Map`.
- Объект-аккумулятор не подходит для произвольных ключей без дополнительной защиты от специальных имён свойств.
- `|| 0` здесь безопасен, потому что корректный счётчик не бывает отрицательным или `NaN`. Для общих данных точнее использовать `?? 0`.
- Объекты в `Map` сравниваются по ссылке: два одинаково выглядящих литерала — разные ключи.

## Сложность

В среднем время — `O(n)`, дополнительная память — `O(k)`, где `k` — число уникальных элементов.

## Что запомнить

Для строковых ключей объект прост и удобен. Для ключей любых типов выбирайте `Map`. Сам паттерн всегда один: прочитать прежний счётчик, подставить ноль, увеличить и вернуть аккумулятор.
