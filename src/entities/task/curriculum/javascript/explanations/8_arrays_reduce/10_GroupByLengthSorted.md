## Что требуется от результата

Слова нужно сначала распределить по длине, а затем отсортировать по алфавиту внутри каждой группы. Это две разные операции: `reduce` отвечает за группировку, `sort` — за порядок элементов группы.

## Что делает представленное решение

```js
const groupByLength = (words) => {
  return words.reduce((acc, word) => {
    const len = word.length;
    acc[len] ??= [];
    acc[len].push(word);
    return acc;
  }, {});
};
```

Аккумулятор — объект, где ключом служит длина слова. Для каждого слова вычисляется `len`, при необходимости создаётся массив `acc[len]`, затем слово добавляется в него.

Но важно заметить: этот код **только группирует** и сохраняет исходный порядок слов. Он не вызывает `sort`, поэтому не полностью выполняет формулировку «с сортировкой внутри».

## Вариант, который действительно сортирует группы

Понятнее разделить работу на два этапа:

```js
const groupByLength = (words) => {
  const groups = words.reduce((acc, word) => {
    acc[word.length] ??= [];
    acc[word.length].push(word);
    return acc;
  }, {});

  Object.values(groups).forEach((group) => {
    group.sort((a, b) => a.localeCompare(b, 'ru'));
  });

  return groups;
};
```

Почему сортировка выполняется после `reduce`? Если вызывать `sort()` после каждого добавленного слова, одна и та же группа будет пересортировываться много раз. Это лишняя работа. Гораздо дешевле сначала собрать все группы, а каждую затем отсортировать один раз.

`localeCompare` задаёт языковые правила сравнения. Обычный `sort()` сравнивает строки по последовательности UTF-16 и не всегда соответствует ожидаемому алфавитному порядку для пользовательского текста.

## Что происходит с ключами

`word.length` — число, но ключи обычного объекта становятся строками: `3`, `4`, `7`. Целочисленные ключи объекта при перечислении выводятся по возрастанию, однако это не заменяет сортировку слов внутри массивов.

## Граничные случаи и ошибки

- Пустой массив возвращает `{}`.
- Пустая строка попадёт в группу с ключом `0`.
- `length` считает кодовые единицы UTF-16, а не всегда визуальные символы: некоторые эмодзи занимают две единицы. Для пользовательского понятия «количество символов» может понадобиться `Array.from(word).length`.
- `sort` мутирует массивы групп, но они созданы внутри функции, поэтому исходный массив `words` не меняется.

## Сложность

Группировка занимает `O(n)`. Сортировка — `O(Σ mᵢ log mᵢ)`, где `mᵢ` — размер отдельной группы; в худшем случае все слова попадут в одну группу и получится `O(n log n)`. Память результата — `O(n)`.

## Что запомнить

Не смешивайте группировку и сортировку на каждой итерации. Сначала постройте группы одним проходом, затем один раз отсортируйте каждую группу — так код и понятнее, и эффективнее.
