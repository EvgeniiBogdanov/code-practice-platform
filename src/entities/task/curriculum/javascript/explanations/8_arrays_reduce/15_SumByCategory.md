## Что делает решение

Здесь одновременно выполняются группировка и агрегация. Транзакции объединяются по `category`, но вместо массива транзакций для каждой категории хранится одно число — накопленная сумма `amount`.

```js
[
  { category: 'food', amount: 150 },
  { category: 'transport', amount: 50 },
  { category: 'food', amount: 300 }
]

// результат
{ food: 450, transport: 50 }
```

## Пошаговый разбор рекомендуемого варианта

```js
const sumByCategory = (arr) => {
  return arr.reduce((acc, { category, amount }) => {
    acc[category] ??= 0;
    acc[category] += amount;
    return acc;
  }, {});
};
```

Для каждой транзакции происходят два шага:

1. `acc[category] ??= 0` создаёт счётчик категории, если значение равно `null` или `undefined`.
2. `acc[category] += amount` добавляет текущую сумму к уже накопленной.

Трассировка первых трёх элементов:

| Транзакция | Аккумулятор |
| --- | --- |
| `food: 150` | `{ food: 150 }` |
| `transport: 50` | `{ food: 150, transport: 50 }` |
| `food: 300` | `{ food: 450, transport: 50 }` |

Название «merge объектов» означает, что множество записей с одинаковой категорией сливается в одно свойство результата. Значения не перезаписываются, а суммируются.

## `??=` и вариант через `||`

Классическая запись выглядит так:

```js
acc[category] = (acc[category] || 0) + amount;
```

Для обычных неотрицательных сумм она даст тот же результат. Но `||` подставляет ноль для любого falsy-значения: `0`, `NaN`, пустой строки, `false`. `??=` считает отсутствием только `null` и `undefined`, поэтому точнее выражает намерение «инициализировать ещё не созданную категорию».

## Граничные случаи и ошибки

- Пустой массив возвращает `{}`.
- Отрицательные `amount` могут корректно представлять возвраты и уменьшать итог.
- Если `amount` — строка, оператор `+=` может выполнить конкатенацию: `150 + '300'` даст `'150300'`. Контракт должен гарантировать числа.
- Разный регистр создаст разные категории: `'Food'` и `'food'` не объединятся без нормализации.
- Отсутствующая категория создаст ключ `'undefined'`; такие данные лучше отклонить или отнести в явно названную группу.

## Сложность

Время — `O(n)`. Дополнительная память — `O(k)`, где `k` — число уникальных категорий.

## Что запомнить

Группировка с суммированием — это «получить ключ, лениво создать ноль, прибавить значение». `??=` здесь семантически точнее `||`, потому что не смешивает отсутствие значения с другими falsy-значениями.
