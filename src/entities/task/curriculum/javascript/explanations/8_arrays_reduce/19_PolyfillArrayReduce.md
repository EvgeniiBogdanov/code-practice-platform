### Что делает решение
Решение реализует полифил `Array.prototype.reduce` (`customReduce` / `myReduce`) с полным соответствием спецификации ECMAScript:
1. Корректно определяет наличие `initialValue` через `arguments.length >= 3` (даже если передан `undefined` в качестве начального значения).
2. При отсутствии `initialValue` ищет первый существующий элемент в разреженном массиве и использует его в качестве базы аккумулятора.
3. Выбрасывает `TypeError`, если массив пуст (или не содержит существующих элементов) и `initialValue` не был передан.
4. Пропускает дыры (`sparse slots`) в цикле итерации.

### Пошаговый разбор механики

1. **Разница между `initialValue === undefined` и непереданным аргументом**:
   - Вызов `reduce(arr, cb, undefined)` означает, что `initialValue` передан (и равен `undefined`). В этом случае начальный аккумулятор = `undefined`, а итерация начинается с индекса 0.
   - Вызов `reduce(arr, cb)` означает, что `initialValue` отсутствует. В этом случае первый элемент массива становится аккумулятором, а итерация стартует с индекса 1.
   - Проверка `arguments.length >= 3` разрешает этот критический edge case.

2. **Поиск первого непустого элемента**:
   - В массиве `[, , 'first', 'second']` цикл ищет первый валидный индекс (`i in obj`), сохраняет `'first'` в аккумулятор и устанавливает `startIndex = 3`.

### Граничные случаи и ошибки
- **Пустой массив без initialValue**: выбрасывает `TypeError`.
- **Пустой массив с initialValue**: возвращает `initialValue` без единого вызова callback.
- **Массив из 1 элемента без initialValue**: возвращает этот элемент без вызова callback.

### Сложность
- **По времени**: `O(n)` — однократный линейный проход по элементам массива.
- **По памяти**: `O(1)` — константное использование памяти под аккумулятор и указатели.

### Что запомнить для собеседования
- `reduce` принимает аргументы: `(callback, initialValue)`.
- `callback` принимает: `(accumulator, currentValue, index, array)`.
- Если `initialValue` не передан, первый элемент становится начальным аккумулятором.
- Для пустого массива без начального значения reduce бросает TypeError.
