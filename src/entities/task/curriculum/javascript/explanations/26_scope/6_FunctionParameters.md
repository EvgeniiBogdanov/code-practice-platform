### Что делает решение
Решение показывает три инструмента для работы с аргументами функции:

1. **Параметры по умолчанию** `name = "гость"`. Значение подставляется, когда аргумент не передан или явно равен `undefined`.
2. **Rest-параметр** `...numbers` собирает все оставшиеся аргументы в **настоящий массив**, поэтому сразу доступен `reduce`.
3. **`arguments`** — псевдомассив всех аргументов обычной функции. Чтобы применить методы массива, его нужно преобразовать: `Array.from(arguments)` или `[...arguments]`.

### Пошаговый разбор
- `greet("Анна")` — `greeting` не передан, подставляется `"Привет"`.
- `greet(undefined, "Добрый день")` — явный `undefined` тоже включает значение по умолчанию.
- `greet(null)` — `null` считается **переданным значением**, поэтому выводится `"Привет, null!"`. Если нужно обрабатывать и `null`, используйте `name ?? "гость"` внутри функции.
- `sumAll()` без аргументов — пустой массив, `reduce` с начальным значением `0` возвращает `0`. Без второго аргумента `reduce` на пустом массиве бросил бы `TypeError`.

### Граничные случаи и ошибки
- Значения по умолчанию вычисляются **при каждом вызове**: `function f(list = []) {}` каждый раз создаёт новый массив. Это отличается от Python, где значение создаётся один раз.
- Параметры по умолчанию могут ссылаться на предыдущие параметры: `function f(a, b = a * 2)`.
- Rest-параметр должен быть последним: `function f(...a, b)` — `SyntaxError`.
- У стрелочных функций нет своего `arguments`, только rest.
- `fn.length` не учитывает параметры с дефолтами и rest: у `greet` значение `length` равно `0`. Это важно для каррирования через `fn.length`.

### Сложность
`greet` — `O(1)`. `sumAll` и `collectArgs` — `O(n)` по времени и памяти, где `n` — количество аргументов.

### Что запомнить для собеседования
- Дефолт срабатывает только на `undefined`.
- Rest даёт настоящий массив, `arguments` — псевдомассив, и его нет у стрелок.
- В современном коде вместо `arguments` используют rest-параметры.
