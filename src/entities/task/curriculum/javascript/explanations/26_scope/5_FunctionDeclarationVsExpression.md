### Что делает решение
Код сравнивает три способа создать функцию и показывает, чем они отличаются на практике.

| | Function Declaration | Function Expression | Стрелочная функция |
|---|---|---|---|
| Синтаксис | `function f() {}` | `const f = function () {}` | `const f = () => {}` |
| Поднятие | целиком | как переменная | как переменная |
| Свой `this` | да, по способу вызова | да, по способу вызова | нет, берёт внешний |
| `arguments` | есть | есть | нет |
| Вызов через `new` | можно | можно | `TypeError` |
| `prototype` | есть | есть | нет |

### Пошаговый разбор
1. `typeof declared` — `"function"` ещё до строки объявления: Function Declaration поднимается вместе с телом.
2. `typeof expressed` — `"undefined"`: поднята только переменная `var expressed`, функция присваивается позже.
3. **Named Function Expression** (`function fact`). Имя `fact` доступно только внутри тела функции, поэтому рекурсия работает, а снаружи `typeof fact` — `"undefined"`. Такое имя полезно для рекурсии и читаемых стек-трейсов.
4. У стрелочных функций нет `arguments`, вместо него используют rest-параметр `...args`.
5. Стрелочная функция не может быть конструктором: у неё нет внутреннего метода `[[Construct]]`, поэтому `new ArrowPerson()` даёт `TypeError`.

### Граничные случаи и ошибки
- Стрелочная функция внутри обычной видит `arguments` **внешней** функции, а не свои.
- Стрелку нельзя использовать как метод объекта, если нужен `this` этого объекта: `this` будет взят из внешней области.
- В строгом режиме Function Declaration внутри блока `if { }` видна только в этом блоке.

### Сложность
Задача на понимание: `O(1)`. Рекурсивный `factorial(n)` работает за `O(n)` по времени и `O(n)` по стеку.

### Что запомнить для собеседования
- Declaration поднимается целиком, Expression — нет.
- У стрелочных функций нет своих `this`, `arguments`, `prototype`, и их нельзя вызывать через `new`.
- Named Function Expression — способ сделать рекурсию, не завязанную на внешнюю переменную.
