### Что делает решение
Код демонстрирует **hoisting (поднятие)**. Перед выполнением движок проходит по коду и создаёт все объявления в текущей области видимости. На этом этапе разные объявления ведут себя по-разному:

| Объявление | Что поднимается | Значение до строки объявления |
|---|---|---|
| `var x = ...` | только имя | `undefined` |
| `function f() {}` | имя **и тело** | готовая функция |
| `var f = function () {}` | только имя `f` | `undefined` |
| `let` / `const` / `class` | имя, но без инициализации | `ReferenceError` (TDZ) |

### Пошаговый разбор
1. `console.log(a)` выводит `undefined`: переменная уже существует, но присваивание `= 5` ещё не выполнено.
2. `sayHi()` работает до объявления, потому что Function Declaration поднимается целиком.
3. `greet` объявлен через `var`, поэтому до присваивания там `undefined` и `typeof` возвращает `"undefined"`.
4. `helper()` до присваивания — это вызов `undefined()`. Ошибка будет `TypeError: helper is not a function`, а **не** `ReferenceError`: переменная существует, просто в ней не функция.

### Граничные случаи и ошибки
- Поднятие не «переносит код вверх» физически. Это результат того, что объявления обрабатываются до выполнения.
- Если `var` и `function` объявлены с одним именем, при поднятии приоритет у функции, но первое же присваивание `var` её перезапишет.
- Стрелочные функции и Function Expression подчиняются правилам переменной (`var`/`let`/`const`), в которую их записали.
- С `let`/`const` вместо `var` пример с `helper` дал бы `ReferenceError` — см. задачу про TDZ.

### Сложность
Задача на понимание: `O(1)`.

### Что запомнить для собеседования
- `var` поднимается со значением `undefined`, Function Declaration — полностью.
- Вызов «поднятой» переменной с функцией до присваивания — это `TypeError`, а не `ReferenceError`.
- Хорошая практика — объявлять переменные до использования и не полагаться на hoisting (кроме Function Declaration для вспомогательных функций).
