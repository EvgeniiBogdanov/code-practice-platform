### Что делает решение
Код сравнивает три способа объявить переменную. Главное различие — **область видимости**: `var` ограничен функцией, а `let` и `const` ограничены блоком `{ ... }`.

| | `var` | `let` | `const` |
|---|---|---|---|
| Область видимости | функция | блок | блок |
| Повторное объявление | можно | `SyntaxError` | `SyntaxError` |
| Переприсваивание | можно | можно | `TypeError` |
| Обращение до объявления | `undefined` | `ReferenceError` (TDZ) | `ReferenceError` (TDZ) |

### Пошаговый разбор
1. `a` объявлен через `var` внутри `if`, но блок для `var` не граница — поэтому `1`.
2. `b` и `c` существуют только внутри `if`. `typeof` для несуществующей переменной не бросает ошибку, а возвращает `"undefined"`.
3. Повторный `var x` просто перезаписывает значение — `20`.
4. `const` защищает **ссылку**, а не содержимое: менять свойства объекта и элементы массива можно.
5. `limit = 10` — попытка переприсвоить константу, получаем `TypeError`.
6. После `for (var i ...)` переменная `i` остаётся доступной и равна `3` — значению, на котором условие стало ложным.

### Граничные случаи и ошибки
- `let x = 1; let x = 2;` — это `SyntaxError` ещё на этапе разбора, поэтому такой код вообще не запустится. Его нельзя «поймать» через `try/catch` в том же скрипте.
- `const` без инициализации (`const a;`) — тоже `SyntaxError`.
- Чтобы запретить мутацию объекта, нужен `Object.freeze`, а не `const`.
- В строгом режиме присваивание необъявленной переменной (`y = 5`) бросает `ReferenceError`, а не создаёт глобальную переменную.

### Сложность
Задача на понимание: `O(1)` по времени и памяти.

### Что запомнить для собеседования
- По умолчанию используйте `const`, `let` — когда значение будет меняться, `var` — никогда в новом коде.
- `var` ограничен функцией, `let/const` — блоком.
- `const` ≠ неизменяемость: это запрет на переприсваивание ссылки.
- `typeof` — единственный безопасный способ проверить необъявленную переменную (но не переменную в TDZ).
