### Что делает решение
**IIFE** (Immediately Invoked Function Expression) — функция, которая вызывается сразу после создания: `(() => { ... })()`. Она создаёт собственную область видимости, а значит и место для приватных данных.

Паттерн «Модуль» соединяет IIFE и замыкание:
1. Внутри IIFE объявляется приватная переменная `count`.
2. IIFE возвращает объект с методами. Эти методы — замыкания: они ссылаются на `count` из окружения, в котором были созданы.
3. Снаружи доступен только возвращённый объект. Добраться до `count` напрямую нельзя, поэтому `counterModule.count === undefined`.

### Зачем это было нужно и где встречается сейчас
До ES-модулей (`import/export`) IIFE были главным способом не засорять глобальную область и изолировать код библиотек (jQuery, ранние сборки webpack). Сейчас изоляцию даёт сама модульная система, но паттерн всё ещё встречается:
- в бандлах, которые собираются в формате IIFE/UMD для подключения через `<script>`;
- в фабриках, где нужно несколько независимых экземпляров с приватным состоянием;
- на собеседованиях — как проверка понимания замыканий.

### Граничные случаи и ошибки
- Без скобок вокруг функции `function () {}()` — `SyntaxError`: строка начинается со слова `function` и разбирается как Function Declaration. Скобки превращают её в выражение.
- Если предыдущая строка не закончилась `;`, конструкция `(...)()` может склеиться с ней в вызов. Отсюда привычка писать `;(() => {})()` в коде без точек с запятой.
- Возвращать `count` как свойство (`return { count }`) нельзя: скопируется текущее число, и оно не будет обновляться.
- IIFE создаёт **один** экземпляр (синглтон). Для нескольких независимых счётчиков нужна обычная фабричная функция `createCounter()`.

### Сложность
Все методы работают за `O(1)` по времени и памяти.

### Что запомнить для собеседования
- IIFE = функция-выражение, вызванная сразу; даёт изолированную область видимости.
- Модуль = IIFE + замыкание: приватные данные внутри, публичный API в возвращаемом объекте.
- В современном JS ту же инкапсуляцию дают ES-модули и приватные поля классов `#count`.
