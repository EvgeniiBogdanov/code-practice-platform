### Что делает решение
Решение реализует безопасный паттерн выполнения критических операций с гарантированной очисткой ресурсов через `try/catch/finally` и демонстрирует правила передачи управления в рантайме JavaScript.

### Пошаговый разбор механизма JS Engine

1. **Гарантия выполнения блока `finally`**:
   - Блок `finally` выполняется **всегда**, независимо от того, выбросило ли тело `try` ошибку или выполнило успешный `return`.
   - Даже если внутри `try` или `catch` стоит `return`, движок временно сохраняет возвращаемое значение в регистре, выполняет блок `finally`, и только затем завершает вызов функции.

2. **Ловушка с `return` внутри `finally` (Unconditional Completion)**:
   ```js
   function badExample() {
     try {
       throw new Error("fatal!");
     } finally {
       return "suppressed!"; // Ошибка "проглочена", функция вернет 'suppressed!'
     }
   }
   ```
   Если в `finally` выполняется явный `return` или `throw`, сохраненное ранее возвращаемое значение или ошибка **полностью перезаписываются**. Линтеры (ESLint: `no-unsafe-finally`) запрещают `return` внутри `finally`.

3. **Корректный паттерн**:
   - В `finally` выполняются только чистые сайд-эффекты освобождения ресурсов (закрытие дескрипторов, сброс флагов, удаление слушателей), без использования операторов возврата `return`.

### Граничные случаи и ошибки
- **Ошибка внутри `cleanupFn`**: если функция в `finally` выбросит исключение, оно прервет выполнение и перекроет результат `try/catch`.
- **Перехват не-Error объектов**: в JS можно выбросить примитив (`throw "error_string"` или `throw 404`). Проверка `err instanceof Error ? err.message : String(err)` защищает от `TypeError`.

### Сложность
- **По времени**: `O(1)` — зависит исключительно от сложности `actionFn` и `cleanupFn`.
- **По памяти**: `O(1)` — объект результата.

### Что запомнить для собеседования
- Блок `finally` выполняется всегда.
- `return` внутри `finally` подавляет и ошибки, и предыдущие `return`.
- В `finally` нельзя писать `return` или `throw` (правило `no-unsafe-finally`).
