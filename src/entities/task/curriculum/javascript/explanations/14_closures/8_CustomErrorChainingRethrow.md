### Что делает решение
Решение реализует современную архитектуру кастомных ошибок в JavaScript:
1. Корректное наследование от `Error` с сохранением правильного имени класса (`this.name = this.constructor.name`) и стека вызовов (`Error.captureStackTrace`).
2. Использование стандарта **ES2022 Error Chaining**: `new Error(message, { cause })` для связывания исходной причины ошибки.
3. Паттерн **Selective Rethrow**: перехват и обработка только целевых бизнес-ошибок (валидация, ожидаемые сетевые статусы) и проброс непредвиденных системных сбоев (SyntaxError, ReferenceError) выше по стеку.

### Пошаговый разбор механизма JS Engine

1. **Почему `this.name = this.constructor.name`**:
   - По умолчанию у `new Error()` поле `name` равно `'Error'`. Если отнаследовать класс без переопределения `name`, `console.log(new ValidationError())` выведет `'Error: ...'`.
   - Привязка к `this.constructor.name` гарантирует, что каждый дочерний класс (`ValidationError`, `NetworkError`) автоматически получит правильное имя в стек-трейсе.

2. **Опция `{ cause }` (ES2022)**:
   - В `super(message, options)` движок автоматически сохраняет `options.cause` в свойство `err.cause`.
   - Это позволяет оборачивать низкоуровневые ошибки в высокоуровневые доменные сущности без потери контекста отладки.

3. **Паттерн Selective Rethrow**:
   - Никогда не перехватывайте все ошибки вслепую (`catch (e) { /* swallow */ }`).
   - Если класс ошибки не входит в `handledClasses`, выполнение `throw err` передает ошибку глобальным обработчикам или Sentry/мониторингу.

### Граничные случаи и ошибки
- **Забытый вызов `super(message)`**: в классах-наследниках обращение к `this` до `super()` вызовет `ReferenceError`.
- **Проверка через `instanceof`**: корректно работает по всей цепочке прототипов (`ValidationError instanceof AppError === true` и `ValidationError instanceof Error === true`).

### Сложность
- **По времени**: `O(k)` — где `k` — количество классов в `handledClasses` (обычно 1–3 проверки).
- **По памяти**: `O(1)`.

### Что запомнить для собеседования
- `super(message, { cause })` — современный способ связывания цепочек ошибок в JS.
- При наследовании от `Error` обязательно устанавливать `this.name`.
- Выборочный `rethrow` — золотой стандарт надежной обработки исключений.
