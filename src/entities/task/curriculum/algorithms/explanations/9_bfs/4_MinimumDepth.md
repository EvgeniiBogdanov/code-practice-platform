## 1. Паттерн

**BFS: Level Order with Early Exit** — очередь обходит дерево по возрастанию глубины. Поэтому первый извлечённый из очереди лист гарантированно находится на минимальной глубине.

## 2. Решение

```javascript
const minDepth = (root) => {
  if (root === null) return 0;

  const queue = [[root, 1]];
  let head = 0;

  while (head < queue.length) {
    const [node, depth] = queue[head++];

    if (node.left === null && node.right === null) {
      return depth;
    }

    if (node.left !== null) queue.push([node.left, depth + 1]);
    if (node.right !== null) queue.push([node.right, depth + 1]);
  }

  return 0;
};
```

## 3. Почему ранний выход корректен

BFS сначала обрабатывает все узлы глубины `d` и только потом узлы глубины `d + 1`. Более близкий лист не может остаться необработанным за более глубоким.

## 4. Сложность

- Время: `O(n)` в худшем случае, но ранний выход часто завершает обход раньше.
- Память: `O(w)`, где `w` — максимальная ширина дерева.

## 5. Частые ошибки

- Считать узел с одним отсутствующим ребёнком листом. Лист не имеет **обоих** детей.
- Использовать `Math.min(depth(left), depth(right))` без отдельной обработки одностороннего дерева.
- Вызывать `shift()` на большой очереди; индекс `head` сохраняет операции очереди амортизированно `O(1)`.
