## 1. Паттерн и шаблон алгоритма

**Паттерн:** Hash Map (хеш-таблица)  
**Разновидность:** `Hash Map: Grouping` (группировка по вычисленному ключу)

### В чём суть паттерна и разновидности
Паттерн **Hash Map: Grouping** используется всякий раз, когда коллекцию объектов нужно разбить на эквивалентные классы (бакеты). Ключевой шаг — найти или сгенерировать **канонический инвариант (хэш-ключ)**, который строго совпадает для всех элементов одной группы и различается для разных. В `Map` по этому ключу создаётся массив значений, куда складываются все подходящие элементы за $O(1)$ на операцию вставки.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Hash Map: Grouping (группировка элементов по ключу-инварианту)
const groupByTemplate = (items, getKeyFn) => {
  const groups = new Map();

  for (const item of items) {
    const key = getKeyFn(item); // вычисление канонического ключа группы

    if (!groups.has(key)) {
      groups.set(key, []);
    }
    groups.get(key).push(item);
  }

  return [...groups.values()]; // возврат списка групп
};
```

## 2. Суть задачи

Дан массив строк `strs`. Нужно сгруппировать строки, которые являются
анаграммами друг друга (состоят из одних и тех же букв, просто в разном
порядке), и вернуть массив таких групп.

- Группы идут в порядке первого появления их слов во входном массиве.
- Внутри группы слова сохраняют исходный порядок.

Оба требования решение выполняет бесплатно: `Map` помнит порядок вставки ключей.

## 3. Ключевая идея решения

Если два слова — анаграммы, значит, у них **одинаковый набор букв**.
А если отсортировать буквы в слове по алфавиту, то все анаграммы одного
и того же слова превратятся **в одну и ту же строку**.

Например:
- `"stop"` → отсортировать буквы → `"opst"`
- `"pots"` → отсортировать буквы → `"opst"`
- `"tops"` → отсортировать буквы → `"opst"`

Все три слова после сортировки дают одинаковую строку `"opst"` — значит,
это анаграммы, и их можно использовать как **общий ключ** для группировки.

А вот:
- `"bat"` → отсортировать буквы → `"abt"`

Это другой ключ, значит, `"bat"` попадёт в отдельную группу.

## 4. Пошаговый разбор кода

1. Создаём пустую `Map`, где ключ — отсортированная строка (например,
   `"opst"`), а значение — массив всех исходных слов с таким ключом.
2. Проходим по каждому слову из `strs`.
3. Для текущего слова строим ключ: разбиваем строку на буквы (`.split("")`),
   сортируем их по алфавиту (`.sort()`) и снова собираем в строку (`.join("")`).
4. Если такого ключа в `Map` ещё нет — создаём для него пустой массив.
5. Добавляем исходное (не отсортированное!) слово в массив по этому ключу.
6. После обработки всех слов возвращаем все значения `Map` в виде массива
   массивов — это и есть готовые группы анаграмм.

```js
const groupAnagrams = (strs) => {
  // map хранит пары "отсортированные буквы -> список исходных слов"
  const map = new Map();

  for (const str of strs) {
    // Строим ключ: сортируем буквы строки по алфавиту
    // "stop" -> ["s","t","o","p"] -> ["o","p","s","t"] -> "opst"
    const key = str.split("").sort().join("");

    // Если такой ключ встречается впервые — заводим для него новый массив
    if (!map.has(key)) {
      map.set(key, []);
    }

    // Добавляем исходное слово (не отсортированное!) в его группу
    map.get(key).push(str);
  }

  // Забираем из map только массивы значений — это и есть группы анаграмм
  return [...map.values()];
};
```

### Трассировка на примере `strs = ["stop", "pots", "melon", "tops", "lemon", "pear"]`

| Слово | Ключ (отсортированные буквы) | map после шага |
|-------|-------------------------------|-----------------|
| stop  | opst                           | `{ "opst": ["stop"] }` |
| pots  | opst                           | `{ "opst": ["stop", "pots"] }` |
| melon | elmno                          | `{ "opst": [...], "elmno": ["melon"] }` |
| tops  | opst                           | `{ "opst": ["stop","pots","tops"], "elmno": ["melon"] }` |
| lemon | elmno                          | `{ "opst": [...], "elmno": ["melon", "lemon"] }` |
| pear  | aepr                           | `{ "opst": [...], "elmno": [...], "aepr": ["pear"] }` |

В конце `[...map.values()]` вернёт три группы:
`[["stop", "pots", "tops"], ["melon", "lemon"], ["pear"]]`

Группы идут в порядке первого появления (`stop` → `melon` → `pear`), а слова внутри
групп — в исходном порядке. Ровно этого и требует условие.

## 5. Сложность и альтернативный способ построения ключа

Пусть `n` — количество строк в массиве, а `k` — максимальная длина строки.

- **Время: O(n · k log k)** — для каждой из `n` строк тратим `O(k log k)`
  на сортировку её букв (сортировка строки длины `k` занимает `O(k log k)`).
- **Память: O(n · k)** — храним все исходные строки в `Map`, суммарный
  объём данных пропорционален количеству строк и их длине.

### Альтернативный способ построения ключа (без сортировки)

Вместо сортировки букв можно построить ключ через **подсчёт количества
каждой буквы** (как в задаче Valid Anagram) — например, массив из 26 чисел
(по одному на каждую букву латинского алфавита), превращённый в строку.
Это позволяет построить ключ за `O(k)` вместо `O(k log k)`, и итоговая
сложность становится `O(n · k)` — быстрее на больших строках. Такой подход
чуть сложнее для новичка, поэтому в этом решении используется более
наглядный вариант через сортировку.
