## 1. Паттерн и шаблон алгоритма

**Паттерн:** Hash Map (хеш-коллекции)  
**Разновидность:** `Hash Map: Index as Key` (массив как хеш-таблица, пометка знаком / In-place marking)

### В чём суть паттерна и разновидности
Если значения лежат в диапазоне `[1, n]`, то каждое значение `x` можно использовать как **ключ**, а ячейку `nums[x - 1]` — как **слот хеш-таблицы**. Вместо отдельного `Set` с флагом «видел / не видел» мы кодируем этот флаг **знаком числа** прямо в исходном массиве. Хеш-функция тривиальна (`x - 1`), коллизий нет, а дополнительная память — $O(1)$.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Hash Map: Index as Key (пометка знаком в диапазоне [1, n])
const markAndCollectTemplate = (nums) => {
  for (const num of nums) {
    const index = Math.abs(num) - 1; // число могло быть уже помечено отрицательным
    if (nums[index] > 0) {
      nums[index] = -nums[index];    // помечаем: значение index + 1 встречалось
    }
  }

  const result = [];
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] > 0) {
      result.push(i + 1);            // ячейка не помечена — значения i + 1 не было
    }
  }
  return result;
};
```

## 2. Суть задачи

Дан массив `nums` из `n` чисел, значения которых лежат в диапазоне `[1, n]`.
Часть чисел из этого диапазона отсутствует, а часть встречается дважды.
Нужно вернуть все **пропущенные** числа, не используя дополнительную память
(результирующий массив не считается).

## 3. Наивное решение (для понимания)

Заводим `Set` из всех чисел массива и проверяем каждое число от `1` до `n`.

```js
const findDisappearedNumbers = (nums) => {
  const seen = new Set(nums);
  const missing = [];
  for (let i = 1; i <= nums.length; i++) {
    if (!seen.has(i)) {
      missing.push(i);
    }
  }
  return missing;
};
```

- Время: **O(n)**.
- Память: **O(n)** — условие задачи это запрещает.

## 4. Пошаговый разбор кода

Ключевое наблюдение: в массиве длины `n` ровно `n` ячеек с индексами `0 … n-1`,
а значения лежат в `1 … n`. Значит, значение `x` однозначно соответствует
ячейке `x - 1`. Используем это как хеш-таблицу:

1. **Проход 1 — пометка.** Для каждого числа вычисляем `index = Math.abs(num) - 1`
   и делаем значение в ячейке `index` отрицательным. `Math.abs` нужен, потому что
   к моменту чтения число могло быть уже помечено знаком.
2. **Проход 2 — сбор.** Ячейка с **положительным** значением ни разу не была
   помечена, а значит, число `i + 1` в массиве не встречалось.

Условие `if (nums[index] > 0)` защищает от повторной смены знака: если число
встречается дважды, второй раз ячейка уже отрицательна, и менять её нельзя.

```js
const findDisappearedNumbers = (nums) => {
  for (const num of nums) {
    // Модуль — потому что nums[i] мог быть уже помечен минусом
    const index = Math.abs(num) - 1;
    if (nums[index] > 0) {
      nums[index] = -nums[index];
    }
  }

  const missing = [];
  for (let i = 0; i < nums.length; i++) {
    if (nums[i] > 0) {
      missing.push(i + 1);
    }
  }
  return missing;
};
```

### Трассировка на примере `nums = [4, 3, 2, 7, 8, 2, 3, 1]`

| Шаг | num | index | массив после шага |
|---|---|---|---|
| 1 | 4 | 3 | `[4, 3, 2, -7, 8, 2, 3, 1]` |
| 2 | 3 | 2 | `[4, 3, -2, -7, 8, 2, 3, 1]` |
| 3 | 2 | 1 | `[4, -3, -2, -7, 8, 2, 3, 1]` |
| 4 | 7 | 6 | `[4, -3, -2, -7, 8, 2, -3, 1]` |
| 5 | 8 | 7 | `[4, -3, -2, -7, 8, 2, -3, -1]` |
| 6 | 2 | 1 | ячейка уже отрицательна — без изменений |
| 7 | 3 | 2 | ячейка уже отрицательна — без изменений |
| 8 | 1 | 0 | `[-4, -3, -2, -7, 8, 2, -3, -1]` |

Положительные значения остались в ячейках с индексами `4` и `5`, поэтому
пропущены числа `5` и `6`.

## 5. Сложность и сравнение альтернатив

- **Время: O(n)** — два линейных прохода.
- **Память: O(1)** — используем только исходный массив и несколько переменных
  (массив ответа не считается).

### Цена оптимизации
Решение **мутирует входной массив**. Если исходные данные нужны после вызова,
надо либо восстановить знаки вторым проходом (`nums[i] = Math.abs(nums[i])`),
либо вернуться к варианту с `Set` и заплатить $O(n)$ памяти.

## Альтернативный подход

**Cyclic Sort.** Идём по массиву и каждый раз обмениваем `nums[i]` с ячейкой
`nums[nums[i] - 1]`, пока число не окажется на своём месте (или там уже стоит такой
же дубликат). После этого индексы `i`, где `nums[i] !== i + 1`, дают пропущенные
значения `i + 1`. Сложность та же: O(n) времени и O(1) памяти, но массив
переупорядочивается, а не только помечается знаком.
