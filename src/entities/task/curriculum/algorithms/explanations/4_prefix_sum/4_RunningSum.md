## 1. Паттерн

**Prefix Sum: Running Accumulation** — сохраняем результат для каждого префикса массива.

`prefix[i]` равен сумме элементов от начала массива до позиции `i` включительно:

```text
prefix[i] = prefix[i - 1] + nums[i]
```

Это самая простая задача на префиксные суммы: она учит строить накопление до перехода к запросам на произвольных отрезках.

## 2. Решение

```javascript
const runningSum = (nums) => {
  const prefix = [];
  let sum = 0;

  for (const num of nums) {
    sum += num;
    prefix.push(sum);
  }

  return prefix;
};
```

Для `[1, 2, 3, 4]` состояния `sum` будут равны `1`, `3`, `6`, `10`.

## 3. Сложность

- Время: `O(n)`.
- Дополнительная память: `O(n)` для возвращаемого массива.

Если разрешено менять входной массив, накопление можно записывать прямо в `nums`, но на собеседовании это нужно сначала согласовать.

## 4. Краевые случаи

- Пустой массив возвращает `[]`.
- Отрицательные числа не требуют отдельной обработки.
- Для одного элемента ответ совпадает с исходным массивом по значениям.

## 5. Следующий шаг

В `Range Sum Query - Immutable` строится почти такой же массив, но с дополнительным нулём в начале. Благодаря этому сумма `[left, right]` вычисляется как `prefix[right + 1] - prefix[left]`.
