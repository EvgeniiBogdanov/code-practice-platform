## 1. Паттерн и шаблон алгоритма

**Паттерн:** Dynamic Programming (динамическое программирование)  
**Разновидность:** `DP: 1D Take / Skip` (на каждом шаге выбор: взять элемент или пропустить)

### В чём суть паттерна и разновидности
В задачах с запретом «нельзя брать соседей» для каждого элемента есть два варианта: **взять** (тогда соседний слева брать нельзя, прибавляем значение к лучшему результату на два шага назад) или **пропустить** (результат равен лучшему на предыдущем шаге). Выбираем максимум из двух. Для рекуррентной формулы нужны только два последних значения, поэтому память $O(1)$.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: DP: 1D Take / Skip
const takeSkipTemplate = (items) => {
  let beforeBest = 0; // лучший результат на два шага назад
  let best = 0;       // лучший результат на предыдущем шаге

  for (const value of items) {
    [beforeBest, best] = [best, Math.max(best, beforeBest + value)];
    //                          пропустить ^   ^ взять
  }

  return best;
};
```

## 2. Суть задачи

Вдоль улицы стоят дома, в `nums[i]` лежат деньги. Два соседних дома грабить нельзя.
Найти максимальную сумму.

```
nums = [3, 10, 3, 1, 2]  ->  12   (10 + 2)
```

## 3. Наивное решение (для понимания)

Перебрать все допустимые наборы домов рекурсией: для каждого дома либо берём его и переходим
через один, либо пропускаем.

```js
const rob = (nums, i = 0) =>
  i >= nums.length ? 0 : Math.max(nums[i] + rob(nums, i + 2), rob(nums, i + 1));
```

- Время: **O(2ⁿ)** — одни и те же суффиксы улицы считаются многократно.
- Память: O(n) на стек вызовов.

Жадные идеи («брать самый богатый дом», «брать чётные») ломаются на простых примерах: `[2, 1, 1, 2]`
даёт `4` (первый и последний), а не `3`.

## 4. Пошаговый разбор кода

```js
const rob = (nums) => {
  let beforeBest = 0;
  let best = 0;

  for (const money of nums) {
    [beforeBest, best] = [best, Math.max(best, beforeBest + money)];
  }

  return best;
};
```

1. `best` — максимум, который можно унести из уже просмотренных домов. `beforeBest` — то же,
   но без последнего просмотренного дома.
2. Для нового дома: **пропустить** — остаётся `best`; **взять** — прибавляем `money` к `beforeBest`, потому что сосед слева брать нельзя.
3. Новое `best` — максимум из этих вариантов, новое `beforeBest` — прежнее `best`. Присваивание
   делается одновременно через деструктуризацию.
4. Пустой массив даёт `0`, массив из одного дома — его значение.

### Трассировка на примере `nums = [3, 10, 3, 1, 2]`

| Дом | money | Пропустить (`best`) | Взять (`beforeBest + money`) | best после |
|---|---|---|---|---|
| 1 | 3 | 0 | 0 + 3 = 3 | 3 |
| 2 | 10 | 3 | 0 + 10 = 10 | 10 |
| 3 | 3 | 10 | 3 + 3 = 6 | 10 |
| 4 | 1 | 10 | 10 + 1 = 11 | 11 |
| 5 | 2 | 11 | 10 + 2 = 12 | 12 |

Ответ: `12`.

## 5. Сложность и сравнение альтернатив

- **Время: O(n)**.
- **Память: O(1)**.

## Альтернативные подходы

- **Массив `dp`:** `dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])`. Нагляднее, память O(n).
- **Top-down с мемоизацией:** рекурсия из наивного решения плюс `Map` результатов. Время O(n).
- **Вариация «дома по кругу»** (LeetCode «House Robber II», #213): решается двумя запусками этого же алгоритма — без первого дома и без последнего.
