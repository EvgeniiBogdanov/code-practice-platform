## 1. Паттерн

**Backtracking: Binary Choice** — на каждом уровне дерева решений есть ровно две ветки: добавить `0` или добавить `1`.

Это входная задача в backtracking: нет массива `used`, индекса `start`, сложных ограничений и отсечения ветвей.

## 2. Дерево решений для `n = 2`

```text
       ""
      /  \
    "0"  "1"
    / \   / \
  "00" "01" "10" "11"
```

Каждый лист на глубине `n` становится одним ответом.

## 3. Решение

```javascript
const generateBinaryStrings = (n) => {
  const result = [];

  const backtrack = (current) => {
    if (current.length === n) {
      result.push(current);
      return;
    }

    backtrack(`${current}0`);
    backtrack(`${current}1`);
  };

  backtrack("");
  return result;
};
```

Строки неизменяемы, поэтому явный `pop()` здесь не нужен: каждый рекурсивный вызов получает собственное значение `current`.

## 4. Сложность

- Результатов: `2^n`.
- Время: `O(n * 2^n)`, потому что каждая строка длины `n` создаётся и сохраняется.
- Память стека: `O(n)`, без учёта результата.

## 5. Частые ошибки

- Остановиться на длине `n - 1`.
- После добавления готовой строки забыть `return` и продолжить рекурсию.
- Для `n = 0` вернуть `[]`: правильный результат — `[""]`, одна комбинация без символов.

## 6. Следующий шаг

В `Subsets` бинарный выбор «взять или пропустить» применяется уже к реальным элементам массива, а результат сохраняется на разных глубинах дерева решений.
