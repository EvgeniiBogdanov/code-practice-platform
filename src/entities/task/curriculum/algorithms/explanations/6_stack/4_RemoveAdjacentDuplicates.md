## 1. Паттерн

**Stack: LIFO** — последний добавленный символ первым сравнивается с новым символом строки.

Стек хранит уже обработанную часть ответа. Если новый символ совпадает с вершиной, пара уничтожается; иначе символ становится новой вершиной.

## 2. Решение

```javascript
const removeAdjacentDuplicates = (s) => {
  const stack = [];

  for (const char of s) {
    if (stack[stack.length - 1] === char) {
      stack.pop();
    } else {
      stack.push(char);
    }
  }

  return stack.join("");
};
```

Для `abbaca`:

```text
a -> ab -> a -> [] -> c -> ca
```

После удаления `bb` символы `aa` становятся соседними и тоже удаляются. Стек обрабатывает эту цепную реакцию без повторных проходов по строке.

## 3. Инвариант

После обработки каждого символа в стеке нет пары одинаковых соседних символов. Поэтому в конце стек уже содержит готовый ответ.

## 4. Сложность

- Время: `O(n)` — каждый символ добавляется и удаляется не более одного раза.
- Дополнительная память: `O(n)`.

## 5. Частые ошибки

- Сравнивать новый символ со всей строкой вместо вершины стека.
- Забыть собрать строку через `join("")`.
- Выполнять повторные `replace` в цикле: в худшем случае это приводит к `O(n²)`.

## 6. Следующий шаг

В `Valid Parentheses` вершина стека тоже определяет допустимость следующего символа, но вместо равенства потребуется таблица соответствия открывающих и закрывающих скобок.
