## 1. Паттерн и шаблон алгоритма

**Паттерн:** Stack (стек)  
**Разновидность:** `Stack: Expression Parsing` (стек слагаемых для разбора выражения с приоритетом операций)

### В чём суть паттерна и разновидности
Приоритет `*` и `/` над `+` и `-` легко учесть, если хранить в стеке **слагаемые**, а не числа. Операторы `*` и `/` сразу применяются к верхнему слагаемому, а `+` и `-` кладут в стек новое слагаемое (со знаком). В конце сумма стека и есть ответ. Оператор применяется не в момент, когда он встретился, а когда прочитано число **после** него: поэтому мы запоминаем *предыдущий* оператор.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Stack: Expression Parsing (слагаемые со знаком, * и / сразу сворачиваются)
const calcTemplate = (s) => {
  const stack = [];
  let number = 0;
  let operator = "+";

  for (let i = 0; i <= s.length; i++) {     // i === s.length: последнее число
    const char = s[i];

    if (char >= "0" && char <= "9") {
      number = number * 10 + Number(char);
    } else if (char !== " ") {
      if (operator === "+") stack.push(number);
      else if (operator === "-") stack.push(-number);
      else if (operator === "*") stack.push(stack.pop() * number);
      else stack.push(Math.trunc(stack.pop() / number));

      operator = char;
      number = 0;
    }
  }

  return stack.reduce((sum, term) => sum + term, 0);
};
```

## 2. Суть задачи

Вычислить значение выражения из неотрицательных целых чисел, операторов `+ - * /` и пробелов,
без `eval`. Деление целочисленное, с округлением к нулю.

```
"8-2*3"      -> 2
"1 + 10/3*2" -> 7
```

## 3. Наивное решение (для понимания)

Два прохода: сначала вычислить все `*` и `/` (подставляя результат в строку), затем
пройти по оставшимся `+` и `-`.

- Приходится переписывать строку или список токенов, а многозначные числа и пробелы
  усложняют код.
- Время может деградировать до O(n²) из-за повторных замен подстрок.

Стек делает это за один проход.

## 4. Пошаговый разбор кода

```js
const calculate = (s) => {
  const stack = [];
  let number = 0;
  let operator = "+";

  for (let i = 0; i <= s.length; i++) {
    const char = s[i];

    if (char >= "0" && char <= "9") {
      number = number * 10 + Number(char);
    } else if (char !== " ") {
      if (operator === "+") {
        stack.push(number);
      } else if (operator === "-") {
        stack.push(-number);
      } else if (operator === "*") {
        stack.push(stack.pop() * number);
      } else {
        stack.push(Math.trunc(stack.pop() / number));
      }

      operator = char;
      number = 0;
    }
  }

  return stack.reduce((sum, term) => sum + term, 0);
};
```

1. **Цифра.** Накапливаем многозначное число: `number = number * 10 + digit`.
2. **Пробел.** Игнорируем.
3. **Оператор или конец строки.** Число закончилось. Применяем **предыдущий** оператор:
   `+` и `-` кладут слагаемое со знаком, `*` и `/` изменяют верхнее слагаемое. Затем
   запоминаем новый оператор и обнуляем число.
4. **Конец строки.** Цикл идёт до `i === s.length`, где `char` равно `undefined`: это не цифра
   и не пробел, поэтому последнее число обрабатывается тем же кодом, отдельной ветки не нужно.
5. **Деление.** `Math.trunc` округляет к нулю (в отличие от `Math.floor` для отрицательных).

### Трассировка на примере `"20-15/4"`

| char | number | operator | stack после шага |
|---|---|---|---|
| `2` | 2 | `+` | `[]` |
| `0` | 20 | `+` | `[]` |
| `-` | 0 | `-` (предыдущий `+` применён: push 20) | `[20]` |
| `1` | 1 | `-` | `[20]` |
| `5` | 15 | `-` | `[20]` |
| `/` | 0 | `/` (предыдущий `-`: push -15) | `[20, -15]` |
| `4` | 4 | `/` | `[20, -15]` |
| конец | 0 | (`/` применён: `Math.trunc(-15 / 4) = -3`) | `[20, -3]` |

Сумма стека: `20 + (-3) = 17`. Здесь видно, зачем нужен именно `Math.trunc`, а не
`Math.floor`: `Math.floor(-3.75)` дал бы `-4` и неверный ответ `16`.

## 5. Сложность и сравнение альтернатив

- **Время: O(n)** — один проход по строке.
- **Память: O(n)** — в стеке не больше слагаемых, чем операторов `+` и `-`.

## Альтернативный подход

**Без стека, за O(1) памяти.** Храним только `lastTerm` (последнее слагаемое) и `sum`
(сумма закрытых слагаемых). При `+` и `-` переносим `lastTerm` в `sum`, при `*` и `/` меняем
`lastTerm` на месте. Идея та же, но стек не нужен: он всегда использовался только
ради верхнего элемента. Для выражений со скобками (LeetCode «Basic Calculator», #224)
стек, напротив, необходим: он хранит промежуточные суммы и знаки внешних уровней.
