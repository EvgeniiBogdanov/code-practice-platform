## 1. Паттерн и шаблон алгоритма

**Паттерн:** Stack (стек)  
**Разновидность:** `Stack: Min Stack` (стек с поддержкой минимума за $O(1)$ через вспомогательный стек)

### В чём суть паттерна и разновидности
Обычный стек не сохраняет историю минимумов: если удалить текущий минимум, узнать новый без полного обхода $O(n)$ невозможно.
Паттерн **Stack: Min Stack** решает эту проблему за счёт синхронного вспомогательного стека (или стека пар `[значение, минимум]`). На каждом шаге `push` вычисляется и сохраняется минимум на текущей глубине стека. При `pop` верхушка вспомогательного стека снимается синхронно с основным, и предыдущий минимум восстанавливается моментально за $O(1)$.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Stack: Min Stack (отслеживание минимума за O(1))
class MinStackTemplate {
  constructor() {
    this.stack = [];
    this.minStack = [];
  }

  push(val) {
    this.stack.push(val);
    const prevMin = this.minStack.length > 0 
      ? this.minStack[this.minStack.length - 1] 
      : val;
    this.minStack.push(Math.min(val, prevMin));
  }

  pop() {
    this.stack.pop();
    this.minStack.pop();
  }

  top() {
    return this.stack[this.stack.length - 1];
  }

  getMin() {
    return this.minStack[this.minStack.length - 1];
  }
}
```

---

## 2. Суть задачи

Нужно спроектировать стек, у которого, помимо обычных операций
(`push`, `pop`, `top`), есть ещё одна: `getMin()` — вернуть минимальный
элемент среди всех, что сейчас лежат в стеке.

Главная сложность в том, что **все** операции, включая `getMin()`,
должны работать за **O(1)** — константное время, независимо от того,
сколько элементов в стеке.

Пример из условия:
```
push(-2)
push(0)
push(-3)
getMin() -> -3   (минимум сейчас -3)
pop()            (удаляем -3)
top()    -> 0    (на вершине теперь 0)
getMin() -> -2   (минимум среди оставшихся -2 и 0)
```

## 3. Разбор решения

Идея: завести **второй, вспомогательный стек** — `minStack` — который
растёт и уменьшается **синхронно** с основным стеком `stack`, и хранит
не сами значения, а "минимум на этот момент".

То есть на каждом шаге `minStack[i]` — это минимум среди
`stack[0], stack[1], ..., stack[i]` (всех элементов от начала до
текущей позиции). У `minStack` всегда **та же длина**, что и у
основного стека.

Пошагово:

1. `push(value)`:
   - кладём `value` в основной стек, как обычно;
   - параллельно вычисляем "минимум на этот момент": это либо `value`
     (если `minStack` пуст — стек был пустым до этого), либо минимум
     между `value` и предыдущей вершиной `minStack` (то есть
     "прошлым минимумом");
   - кладём этот минимум в `minStack`.
2. `pop()`:
   - удаляем верхний элемент из **обоих** стеков одновременно.
     Раз `minStack` хранил "минимум до этой позиции" для каждого
     уровня стека, после удаления его новая вершина автоматически
     окажется правильным минимумом для оставшихся элементов —
     ничего пересчитывать не нужно.
3. `top()`:
   - просто возвращаем вершину основного стека — как в обычном стеке.
4. `getMin()`:
   - просто возвращаем вершину `minStack` — она уже готова, никаких
     вычислений на лету не требуется.

Все четыре операции работают за O(1), потому что и `push`/`pop`
у массива, и обращение к последнему элементу по индексу —
это константное время.

### Почему `pop()` из `minStack` "просто работает"

Ключевая деталь: **каждому** элементу `stack` соответствует **свой**
элемент `minStack` на том же месте — это как две колонки таблицы,
растущие и уменьшающиеся синхронно. Когда мы стираем последнюю строку
таблицы (`pop()` из обоих стеков), в `minStack` автоматически остаётся
"минимум по состоянию на предыдущий шаг" — то есть именно то значение,
которое нам и нужно после удаления. Пересчитывать заново не нужно,
потому что оно уже было посчитано заранее, при соответствующем `push`.

## 4. Пошаговый разбор кода

```javascript
const createMinStack = () => {
  // Основной стек — хранит реальные значения
  const stack = [];

  // Вспомогательный стек — хранит минимум "на момент" каждого push.
  // minStack всегда той же длины, что и stack
  const minStack = [];

  const push = (value) => {
    stack.push(value);

    // Если minStack ещё пуст — value автоматически является минимумом.
    // Если не пуст — сравниваем value с текущим минимумом (вершиной
    // minStack) и берём меньшее из двух
    const currentMin = minStack.length
      ? Math.min(value, minStack[minStack.length - 1])
      : value;

    // Кладём вычисленный минимум на ту же позицию, что и value в stack
    minStack.push(currentMin);
  };

  const pop = () => {
    // Удаляем верхний элемент из ОБОИХ стеков одновременно,
    // чтобы они оставались синхронизированы по длине
    stack.pop();
    minStack.pop();
  };

  // Верхний элемент основного стека — обычная операция top()
  const top = () => stack[stack.length - 1];

  // Минимум уже посчитан заранее и лежит на вершине minStack —
  // просто читаем его, без каких-либо вычислений
  const getMin = () => minStack[minStack.length - 1];

  return { push, pop, top, getMin };
};
```

### Пошаговая трассировка

| Действие | `stack` | `minStack` | Результат |
|---|---|---|---|
| `push(-2)` | `[-2]` | `[-2]` | — |
| `push(0)` | `[-2, 0]` | `[-2, -2]` | — |
| `push(-3)` | `[-2, 0, -3]` | `[-2, -2, -3]` | — |
| `getMin()` | `[-2, 0, -3]` | `[-2, -2, -3]` | `-3` |
| `pop()` | `[-2, 0]` | `[-2, -2]` | — |
| `top()` | `[-2, 0]` | `[-2, -2]` | `0` |
| `getMin()` | `[-2, 0]` | `[-2, -2]` | `-2` |

Видно, что после `pop()` вершина `minStack` сама "откатилась"
до правильного значения `-2` — никакого дополнительного пересчёта
не потребовалось.

## 5. Сложность

- **Время:** O(1) — для каждой операции: `push`, `pop`, `top`, `getMin`
- **Память:** O(n) — минимум хранится для каждого элемента отдельно,
  поэтому память пропорциональна количеству элементов в стеке (O(n))
