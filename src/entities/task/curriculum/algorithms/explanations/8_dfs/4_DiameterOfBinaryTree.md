## 1. Паттерн и шаблон алгоритма

**Паттерн:** DFS (Depth-First Search, поиск в глубину)  
**Разновидность:** `DFS: Bottom-Up` (обход «снизу вверх» с глобальным аккумулятором метрики)

### В чём суть паттерна и разновидности
Диаметр дерева (самый длинный путь между любыми двумя узлами) может проходить через любой узел, не обязательно корень. Для каждого конкретного узла длина пути через него равна `leftDepth + rightDepth`.
В паттерне **DFS: Bottom-Up с аккумулятором**:
1. Функция рекурсивно обходит поддеревья и возвращает их высоту (`Math.max(left, right) + 1`).
2. На этапе подъёма (post-order) текущий узел сопоставляет сумму высот детей с глобальным максимумом `diameter = Math.max(diameter, left + right)`.
Это решает задачу за один единственный проход по дереву со сложностью $O(n)$.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: DFS: Bottom-Up с отслеживанием максимального пути
const diameterOfBinaryTreeTemplate = (root) => {
  let maxDiameter = 0;

  const dfs = (node) => {
    if (!node) return 0; // Базовый случай: пустое поддерево

    // Рекурсивно собираем высоту левой и правой веток
    const leftHeight = dfs(node.left);
    const rightHeight = dfs(node.right);

    // Обновляем глобальный диаметр через текущий узел
    maxDiameter = Math.max(maxDiameter, leftHeight + rightHeight);

    // Возвращаем высоту поддерева наверх
    return Math.max(leftHeight, rightHeight) + 1;
  };

  dfs(root);
  return maxDiameter;
};
```

## 2. Суть задачи

Дано бинарное дерево. Нужно найти **диаметр** — длину самого длинного
пути между любыми двумя узлами дерева. Путь измеряется в рёбрах
(связях), а не в узлах, и **не обязан** проходить через корень.

Пример:

```
        1
       / \
      2   3
     / \
    4   5
```

Самый длинный путь тут — `4 → 2 → 1 → 3` (или `5 → 2 → 1 → 3`),
в нём 3 ребра, значит диаметр = 3. Обратите внимание: путь проходит
через корень, но чаще всего диаметр "прячется" где-то в глубине
дерева и корня вообще не касается — как раз поэтому нельзя просто
посчитать "высоту левого поддерева + высоту правого поддерева" для
одного только корня.

## 3. Разбор решения

### Ключевая идея

Для **любого** узла дерева самый длинный путь, который проходит
именно через этот узел (и никакой другой узел выше по дереву), равен:

```
высота левого поддерева + высота правого поддерева
```

Потому что путь может "спуститься" по самой длинной цепочке влево,
дойти до текущего узла, а затем "спуститься" по самой длинной цепочке
вправо.

Диаметр всего дерева — это **максимум** такой суммы среди **всех**
узлов дерева, а не только среди корня. Поэтому идея решения такая:
1. Написать функцию, которая считает высоту поддерева (обычная
   рекурсия: `1 + max(высота левого, высота правого)`).
2. Пока эта функция "спускается и поднимается" по дереву, на каждом
   узле заодно проверять сумму `leftHeight + rightHeight` и
   запоминать максимум из всех таких сумм — это и есть диаметр.

## 4. Пошаговый разбор кода

```js
const diameterOfBinaryTree = (root) => {
  let diameter = 0;
  // Здесь будем хранить лучший (максимальный) найденный диаметр.
  // Обновляется "по пути", пока функция height() обходит дерево.

  const height = (node) => {
    if (node === null) {
      return 0;
    }
    // Высота пустого поддерева — 0 (заодно это и базовый случай рекурсии).

    const leftHeight = height(node.left);
    const rightHeight = height(node.right);
    // Сначала честно считаем высоту левого и правого поддеревьев —
    // это тоже рекурсивные вызовы той же функции height().

    diameter = Math.max(diameter, leftHeight + rightHeight);
    // Проверяем: а что если самый длинный путь проходит именно
    // через ТЕКУЩИЙ узел? Его длина — это высота левого поддерева
    // плюс высота правого. Сравниваем с лучшим найденным диаметром
    // и запоминаем большее значение.

    return Math.max(leftHeight, rightHeight) + 1;
    // Возвращаем наверх высоту ТЕКУЩЕГО поддерева (для родителя):
    // это большая из высот детей плюс 1 (само ребро до текущего узла).
  };

  height(root);
  // Запускаем обход от корня — нам не важен результат, важны побочные
  // обновления переменной diameter внутри рекурсии.

  return diameter;
};
```

### Почему это работает за один проход
Функция `height` в любом случае обязана посетить каждый узел дерева
ровно один раз, чтобы посчитать его высоту. Мы просто "довешиваем"
на этот обход дополнительную проверку (`leftHeight + rightHeight`),
не делая никакого отдельного прохода по дереву.

## 5. Сложность и особенности
- **Время:** O(n), где n — количество узлов, так как каждый узел
  посещается ровно один раз.
- **Память:** O(h), где h — высота дерева, за счёт стека рекурсивных
  вызовов (в худшем случае, если дерево вырождено в "цепочку",
  h = n).
