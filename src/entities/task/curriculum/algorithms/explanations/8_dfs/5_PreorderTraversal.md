## 1. Паттерн

**DFS: Preorder Traversal** — сначала обрабатываем текущий узел, затем полностью обходим левое и правое поддеревья.

```text
node -> left -> right
```

Это базовый DFS без вычисления высоты, сравнения деревьев или изменения структуры.

## 2. Решение

```javascript
const preorderTraversal = (root) => {
  const values = [];

  const dfs = (node) => {
    if (node === null) return;

    values.push(node.val);
    dfs(node.left);
    dfs(node.right);
  };

  dfs(root);
  return values;
};
```

Для дерева

```text
    1
   / \
  2   3
 / \
4   5
```

результат будет `[1, 2, 4, 5, 3]`.

## 3. Инвариант рекурсии

Каждый вызов `dfs(node)` обязан полностью обработать поддерево с корнем `node`. Базовый случай для `null` останавливает спуск.

## 4. Сложность

- Время: `O(n)` — каждый узел посещается один раз.
- Память: `O(h)` для стека вызовов, где `h` — высота дерева; возвращаемый массив занимает `O(n)`.

## 5. Частые ошибки

- Забыть базовый случай `node === null`.
- Добавить значение после рекурсивных вызовов и случайно получить postorder.
- Поменять местами `left` и `right` и изменить порядок результата.

## 6. Следующий шаг

В `Maximum Depth of Binary Tree` обход останется тем же DFS, но узел будет обрабатываться на возврате из рекурсии — это уже bottom-up агрегация.
