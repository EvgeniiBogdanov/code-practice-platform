## 1. Паттерн и шаблон алгоритма

**Паттерн:** DFS (Depth-First Search, поиск в глубину)  
**Разновидность:** `DFS: Transformation` (рекурсивная трансформация / мутация структуры дерева)

### В чём суть паттерна и разновидности
В задачах класса **DFS: Transformation** обход в глубину используется не просто для сбора метрик, а для изменения связей между узлами дерева.
Для каждого узла задача "инвертировать дерево" сводится к двум шагам:
1. Рекурсивно инвертировать левое и правое поддеревья.
2. Поменять местами указатели `root.left` и `root.right`.
Важно сохранить исходные ссылки до мутации, чтобы не потерять поддерево.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: DFS: Transformation (зеркальный разворот поддеревьев)
const invertTreeTemplate = (root) => {
  if (root === null) {
    return null; // Базовый случай: пустое дерево
  }

  // Запоминаем оригинальные ссылки на потомков
  const originalLeft = root.left;
  const originalRight = root.right;

  // Меняем местами левого и правого ребёнка с рекурсивным разворотом
  root.left = invertTreeTemplate(originalRight);
  root.right = invertTreeTemplate(originalLeft);

  return root;
};
```

---

## 2. Суть задачи

Дано бинарное дерево. Нужно "отзеркалить" его: у каждого узла левый и
правый потомок должны поменяться местами. В результате дерево, которое
раньше "росло" влево, будет расти вправо, и наоборот.

Пример:

```
Было:            Стало:
     4                 4
   /   \              /  \
  2     7            7    2
 / \   / \          / \  / \
1   3 6   9        9  6 3   1
```

## 3. Разбор решения

Ключевое наблюдение: перевёрнутое дерево — это узел, у которого:
- слева стоит **перевёрнутое правое** поддерево,
- справа стоит **перевёрнутое левое** поддерево.

То есть задача "инвертировать дерево из N узлов" сводится к двум
задачам поменьше — "инвертировать левое поддерево" и "инвертировать
правое поддерево". Это классический признак рекурсии: большая задача
решается через точно такую же, но меньшую.

Базовый случай (когда рекурсия останавливается) — пустой узел
(`null`): у него нечего переворачивать, поэтому просто возвращаем
`null`.

## 4. Пошаговый разбор кода

```js
const invertTree = (root) => {
  if (root === null) {
    return null;
  }
  // Базовый случай: дошли до "пустого" потомка — переворачивать нечего.

  const { left, right } = root;
  // Запоминаем исходные left и right ДО того, как начнём их менять,
  // иначе потеряем ссылку на одно из поддеревьев.

  root.left = invertTree(right);
  // В левый потомок кладём результат инверсии ПРАВОГО поддерева.

  root.right = invertTree(left);
  // В правый потомок кладём результат инверсии ЛЕВОГО поддерева.

  return root;
  // Возвращаем тот же узел, но уже с переставленными и
  // перевёрнутыми внутри детьми.
};
```

Рекурсия идёт "до самого низа" дерева (до листьев), а перестановка
`left`/`right` фактически происходит на обратном пути — когда вызовы
`invertTree` возвращают значения снизу вверх.

## 5. Сложность и особенности
- **Время:** O(n), где n — количество узлов, потому что каждый узел
  посещается ровно один раз.
- **Память:** O(h), где h — высота дерева, за счёт стека рекурсивных
  вызовов (в худшем случае, если дерево вырождено в "цепочку",
  h = n).

### Про вспомогательные функции в task.js / solution.js
`buildTree` и `treeToArray` — это не часть самой задачи, а просто
удобные помощники, чтобы можно было задавать деревья и проверять

а не собирать узлы вручную.
