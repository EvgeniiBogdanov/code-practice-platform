## 1. Паттерн и шаблон алгоритма

**Паттерн:** Sliding Window (скользящее окно)  
**Разновидность:** `Sliding Window: Dynamic` (динамическое окно / поиск минимальной длины)

### В чём суть паттерна и разновидности
В задачах на **поиск минимального валидного окна** паттерн Sliding Window работает в инвертированном режиме по отношению к задачам на максимум:
1. Мы расширяем окно (`right++`), накапливая состояние (например, сумму), пока оно не станет валидным (`sum >= target`).
2. Как только условие выполнено — запускается внутренний цикл `while (sum >= target)`, в котором мы обновляем текущий минимум длины `minLength = Math.min(minLength, right - left + 1)` и **жадно сжимаем окно слева** (`sum -= nums[left]; left++`), пытаясь найти еще более компактный отрезок.
Такая схема работает строго за $O(n)$ времени и $O(1)$ памяти.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Sliding Window: Dynamic (поиск минимального окна, удовлетворяющего условию)
const minWindowSubarrayTemplate = (arr, target) => {
  let left = 0;
  let currentSum = 0;
  let minLen = Infinity;

  for (let right = 0; right < arr.length; right++) {
    currentSum += arr[right]; // 1. Расширяем окно вправо

    // 2. Пока условие валидно — фиксируем длину и сжимаем окно слева
    while (currentSum >= target) {
      minLen = Math.min(minLen, right - left + 1);
      currentSum -= arr[left];
      left++;
    }
  }

  return minLen === Infinity ? 0 : minLen;
};
```

## 2. Суть задачи

В массиве `nums` — выручка магазина по дням (только положительные числа). Нужно найти
самый короткий отрезок идущих подряд дней, выручка за который не меньше `target`,
и вернуть его длину. Если даже за все дни `target` не набрать — вернуть `0`.

Важное условие: все числа в массиве **положительные**. Именно это
позволяет использовать скользящее окно — потому что если мы добавляем
элемент, сумма только растёт, а если убираем — только уменьшается.
Никакой "неопределённости" в поведении суммы нет.

## 3. Разбор решения

Идея — держим "окно" (участок массива) с помощью двух указателей:
- `left` — левая граница окна
- `right` — правая граница окна

Мы двигаем `right` вперёд, расширяя окно и накапливая сумму. Как только
сумма становится `>= target`, мы пытаемся **сжать окно слева**
(двигаем `left` вправо), чтобы найти минимально возможную длину именно
для этой суммы. Как только сумма опять становится меньше `target` —
останавливаемся и снова двигаем `right`.

Таким образом каждый элемент массива добавляется в окно один раз и
убирается из него максимум один раз — отсюда линейная сложность O(n).

## 4. Пошаговый разбор кода

```js
const minSubArrayLen = (target, nums) => {
  let left = 0;        // левая граница окна
  let sum = 0;          // сумма элементов внутри текущего окна
  let minLength = Infinity; // сюда будем сохранять минимальную найденную длину

  for (let right = 0; right < nums.length; right++) {
    sum += nums[right]; // расширяем окно вправо, добавляем новый элемент в сумму

    // пока сумма окна достаточна (>= target) — пробуем сжать окно слева,
    // чтобы найти наименьшую возможную длину именно для этой суммы
    while (sum >= target) {
      minLength = Math.min(minLength, right - left + 1); // запоминаем длину, если она меньше текущего минимума
      sum -= nums[left]; // убираем самый левый элемент из суммы
      left++;             // сдвигаем левую границу окна вправо
    }
  }

  // если minLength так и остался Infinity — значит подходящего подмассива не нашлось
  return minLength === Infinity ? 0 : minLength;
};
```

### Трассировка на примере `target = 9, nums = [1, 4, 2, 5, 3, 1]`

Столбец `sum` — сумма сразу после добавления `nums[right]`.

| right | nums[right] | sum | что происходит |
|---|---|---|---|
| 0 | 1 | 1 | sum < 9, ничего не сжимаем |
| 1 | 4 | 5 | sum < 9, ничего не сжимаем |
| 2 | 2 | 7 | sum < 9, ничего не сжимаем |
| 3 | 5 | 12 | sum >= 9 → minLength = 4, sum -= 1 → 11, left = 1; sum >= 9 → minLength = min(4, 3) = 3, sum -= 4 → 7, left = 2 |
| 4 | 3 | 10 | sum >= 9 → minLength = min(3, 3) = 3, sum -= 2 → 8, left = 3 |
| 5 | 1 | 9 | sum >= 9 → minLength = min(3, 3) = 3, sum -= 5 → 4, left = 4 |

Итог: `minLength = 3` → ответ `3` (например, отрезок `[4, 2, 5]` с суммой `11`).

## 5. Сложность и усложнение

- **Время:** O(n) — каждый элемент добавляется и удаляется из окна максимум по одному разу.
- **Память:** O(1) — используем только несколько переменных, без дополнительных структур данных.

Для тренировки можно решить задачу и другим способом — за O(n log n).
Для этого можно использовать бинарный поиск по длине подмассива в
сочетании с префиксными суммами — это более сложный вариант, который
стоит изучить отдельно, когда освоите базовый способ.
