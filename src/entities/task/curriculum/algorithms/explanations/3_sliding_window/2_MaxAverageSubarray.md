## 1. Паттерн и шаблон алгоритма

**Паттерн:** Sliding Window (скользящее окно)  
**Разновидность:** `Sliding Window: Fixed` (окно фиксированного размера $K$)

### В чём суть паттерна и разновидности
Паттерн **Sliding Window: Fixed** применяется, когда длина непрерывного отрезка строго зафиксирована ($k$). Вместо повторного суммирования всех $k$ элементов на каждом шаге за $O(n \cdot k)$, мы инициализируем сумму первого окна за $O(k)$, а затем сдвигаем окно вправо за $O(1)$ на шаг: **вычитаем элемент, покинувший окно слева (`arr[i - k]`), и прибавляем вошедший справа (`arr[i]`)**. Это обеспечивает линейное время $O(n)$ и константную память $O(1)$.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Sliding Window: Fixed (окно фиксированного размера K)
const fixedSlidingWindowTemplate = (arr, k) => {
  if (arr.length < k) return null;

  // 1. Инициализация первого окна
  let windowSum = 0;
  for (let i = 0; i < k; i++) {
    windowSum += arr[i];
  }

  let bestResult = windowSum;

  // 2. Скольжение окна от k до конца массива
  for (let i = k; i < arr.length; i++) {
    windowSum += arr[i] - arr[i - k]; // +новый справа, -старый слева
    bestResult = Math.max(bestResult, windowSum);
  }

  return bestResult;
};
```

## 2. Суть задачи

Дан массив чисел `nums` и число `k`. Нужно найти **непрерывный**
(идущий подряд) подмассив длиной **ровно `k`**, у которого **среднее
значение** элементов максимально, и вернуть это среднее значение.

Среднее значение = сумма элементов подмассива, делённая на `k`.

Поскольку `k` фиксирован для всех подмассивов, а делитель у всех подмассивов
один и тот же, задача фактически сводится к более простой: **найти
максимальную сумму** подмассива длины `k`, а затем разделить её на `k`.

## 3. Наивное решение (для понимания)

Самый простой способ — перебрать все возможные стартовые позиции окна и
для каждой заново посчитать сумму `k` элементов.

```js
const findMaxAverageBruteForce = (nums, k) => {
  let maxSum = -Infinity;

  for (let i = 0; i <= nums.length - k; i++) {
    let currentSum = 0;
    for (let j = i; j < i + k; j++) {
      currentSum += nums[j];
    }
    maxSum = Math.max(maxSum, currentSum);
  }

  return maxSum / k;
};
```

- Время: **O(n · k)** — для каждой из примерно `n` стартовых позиций
  тратим `O(k)` на подсчёт суммы её `k` элементов.
- Память: **O(1)**.

Работает, но лишняя работа: соседние окна почти полностью совпадают,
а мы каждый раз пересчитываем сумму заново.

## 4. Оптимальное решение — разбор пошагово

Ключевая идея: когда окно сдвигается на 1 позицию вправо, из него
"выпадает" ровно один элемент слева и "входит" ровно один новый элемент
справа. Все остальные элементы окна остаются теми же самыми. Значит,
новую сумму можно получить из старой всего за одну операцию:

```
новая сумма = старая сумма - элемент, который выпал слева + элемент, который вошёл справа
```

Шаги алгоритма:

1. Считаем сумму **первого окна** — первых `k` элементов массива.
   Запоминаем её как текущий максимум `maxSum`.
2. Двигаем правую границу окна (`right`) от индекса `k` до конца массива.
3. На каждом шаге:
   - прибавляем к сумме окна новый элемент `nums[right]`, который только
     что вошёл в окно справа;
   - вычитаем из суммы окна элемент `nums[right - k]`, который "выпал"
     из окна слева (это элемент, который был `k` позиций назад);
   - сравниваем полученную сумму с `maxSum` и обновляем её при необходимости.
4. В конце делим `maxSum` на `k`, чтобы получить среднее значение.

```js
const findMaxAverage = (nums, k) => {
  // Считаем сумму первого окна (первые k элементов)
  let windowSum = 0;
  for (let i = 0; i < k; i++) {
    windowSum += nums[i];
  }

  // Запоминаем сумму первого окна как текущий максимум
  let maxSum = windowSum;

  // Двигаем окно вправо на один элемент за раз
  for (let right = k; right < nums.length; right++) {
    // Прибавляем новый элемент справа и убираем элемент, который выпал слева
    windowSum += nums[right] - nums[right - k];
    maxSum = Math.max(maxSum, windowSum);
  }

  // Среднее значение = максимальная сумма окна, делённая на длину окна
  return maxSum / k;
};
```

### Трассировка на примере `nums = [1, 12, -5, -6, 50, 3], k = 4`

**Шаг 1.** Сумма первого окна `[1, 12, -5, -6]`:
`1 + 12 - 5 - 6 = 2`. `maxSum = 2`.

**Шаг 2.** Сдвигаем окно:

| right | nums[right] (входит) | nums[right-k] (выходит) | windowSum | maxSum | Текущее окно |
|---|---|---|---|---|---|
| 4 | 50 | nums[0] = 1 | 2 + 50 - 1 = 51 | 51 | [12, -5, -6, 50] |
| 5 | 3  | nums[1] = 12 | 51 + 3 - 12 = 42 | 51 | [-5, -6, 50, 3] |

**Итог:** `maxSum = 51`, `51 / 4 = 12.75` — ответ совпадает с ожидаемым.

## 5. Сложность

- **Время: O(n)** — сумма первого окна считается за `O(k)`, а затем
  каждый следующий элемент массива обрабатывается ровно один раз при
  сдвиге окна, что даёт в сумме `O(n)`.
- **Память: O(1)** — используется только несколько переменных
  (`windowSum`, `maxSum`), независимо от размера входных данных.

Это заметно быстрее наивного решения `O(n · k)`, особенно когда `k`
близко к размеру массива.
