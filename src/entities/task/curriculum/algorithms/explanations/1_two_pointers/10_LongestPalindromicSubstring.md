## 1. Паттерн и шаблон алгоритма

**Паттерн:** Two Pointers (два указателя)  
**Разновидность:** `Two Pointers: Expand From Center` (расширение от центра в обе стороны)

### В чём суть паттерна и разновидности
Раньше указатели шли **к центру** (проверка палиндрома: `left` и `right` с краёв). Здесь наоборот: они стартуют из одной точки (или двух соседних) и расходятся **от центра**, пока символы совпадают. Каждый палиндром однозначно определяется своим центром, а центров ровно `2n - 1`: `n` символов (нечётная длина) и `n - 1` промежутков между ними (чётная длина).

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Two Pointers: Expand From Center
const expandTemplate = (s, left, right) => {
  while (left >= 0 && right < s.length && s[left] === s[right]) {
    left--;
    right++;
  }
  return right - left - 1; // длина найденного палиндрома
};

// Использование:
//   expandTemplate(s, i, i)     — нечётный палиндром с центром в символе i
//   expandTemplate(s, i, i + 1) — чётный палиндром с центром между i и i + 1
```

## 2. Суть задачи

Найти в строке `s` самую длинную подстроку, которая читается одинаково слева направо
и справа налево.

```
"bananas" -> "anana"
"xyzzyq"  -> "yzzy"
```

## 3. Наивное решение (для понимания)

Перебрать все подстроки и для каждой проверить, палиндром ли она.

```js
const isPalindrome = (s, l, r) => {
  while (l < r) {
    if (s[l++] !== s[r--]) return false;
  }
  return true;
};

const longestPalindrome = (s) => {
  let best = "";
  for (let i = 0; i < s.length; i++) {
    for (let j = i; j < s.length; j++) {
      if (j - i + 1 > best.length && isPalindrome(s, i, j)) {
        best = s.slice(i, j + 1);
      }
    }
  }
  return best;
};
```

- Время: **O(n³)** — `O(n²)` подстрок, на каждую проверка за `O(n)`.
- Память: **O(1)**.

## 4. Пошаговый разбор кода

```js
const longestPalindrome = (s) => {
  let start = 0;
  let maxLength = 0;

  const expand = (left, right) => {
    while (left >= 0 && right < s.length && s[left] === s[right]) {
      left--;
      right++;
    }
    return right - left - 1;
  };

  for (let i = 0; i < s.length; i++) {
    const length = Math.max(expand(i, i), expand(i, i + 1));

    if (length > maxLength) {
      maxLength = length;
      start = i - Math.floor((length - 1) / 2);
    }
  }

  return s.slice(start, start + maxLength);
};
```

1. Для каждой позиции `i` пробуем **два центра**: символ `i` (нечётная длина) и пару
   `i, i + 1` (чётная длина).
2. `expand` двигает `left` влево, а `right` вправо, пока границы не вышли за строку
   и символы равны. На выходе из цикла `left` и `right` стоят уже на **первых
   несовпавших** позициях, поэтому длина равна `right - left - 1`.
3. Если новый палиндром длиннее лучшего, запоминаем его длину и вычисляем начало:
   `start = i - ⌊(length - 1) / 2⌋`. Для нечётной длины центр в `i`, для чётной
   «левая половина» заканчивается в `i`, и формула покрывает оба случая.

### Трассировка на примере `s = "cbbd"`

| i | expand(i, i) | expand(i, i + 1) | length | maxLength | start |
|---|---|---|---|---|---|
| 0 | 1 (`"c"`) | 0 (`c` ≠ `b`) | 1 | 1 | 0 |
| 1 | 1 (`"b"`) | 2 (`"bb"`) | 2 | 2 | 1 |
| 2 | 1 (`"b"`) | 0 (`b` ≠ `d`) | 1 | 2 | 1 |
| 3 | 1 (`"d"`) | 0 (конец строки) | 1 | 2 | 1 |

Результат: `s.slice(1, 3) = "bb"`.

## 5. Сложность и сравнение альтернатив

- **Время: O(n²)** — `2n - 1` центров, расширение каждого в худшем случае `O(n)`
  (например, строка из одинаковых символов).
- **Память: O(1)** — только несколько переменных.

## Альтернативные подходы

- **Динамическое программирование** `dp[i][j]` («подстрока `i..j` — палиндром») даёт
  то же время O(n²), но память O(n²). Проще расширения в рассуждениях, хуже по памяти.
- **Алгоритм Манакера** находит ответ за **O(n)**, но на собеседованиях его почти не
  требуют: достаточно расширения от центра и умения объяснить, почему центров `2n - 1`.
