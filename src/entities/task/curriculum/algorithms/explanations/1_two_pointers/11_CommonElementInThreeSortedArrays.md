## 1. Паттерн и шаблон алгоритма

**Паттерн:** Two Pointers (два указателя)  
**Разновидность:** `Two Pointers: Merge` (параллельный обход нескольких отсортированных массивов)

### В чём суть паттерна и разновидности
У каждого отсортированного массива свой указатель. Смотрим на три текущих значения: самое большое из них — «планка», а всё, что меньше планки, **не может** быть общим для всех трёх массивов (в остальных массивах такого значения правее уже нет). Поэтому такие указатели сдвигаем. Когда три значения совпали, общее число найдено. Каждый указатель идёт только вперёд, поэтому всё работает за $O(p + q + r)$ без дополнительной памяти.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Two Pointers: Merge для трёх массивов
const mergeThreeTemplate = (a, b, c) => {
  let i = 0;
  let j = 0;
  let k = 0;

  while (i < a.length && j < b.length && k < c.length) {
    if (a[i] === b[j] && b[j] === c[k]) return a[i]; // общее значение

    const max = Math.max(a[i], b[j], c[k]);
    if (a[i] < max) i++;
    if (b[j] < max) j++;
    if (c[k] < max) k++;
  }

  return null;
};
```

## 2. Суть задачи

Даны три неубывающих массива чисел. Нужно найти число, которое присутствует во всех трёх.
Эта задача приведена как пример на странице [секции программирования](https://github.com/Tinkoff/career/blob/main/interview/sections/programming.md)
в официальных материалах Т-Банка для подготовки к собеседованию. Там же указано целевое
решение: $O(p + q + r)$ по времени и $O(1)$ по памяти.

В нашей версии функция возвращает **наименьшее** общее число или `null`, если его нет.

```
a = [1, 2, 4, 5]   b = [3, 3, 4]   c = [2, 3, 4, 5, 6]   ->  4
```

## 3. Наивное решение (для понимания)

Построить `Set` по двум массивам и проверить элементы третьего.

```js
const findCommonElement = (a, b, c) => {
  const inA = new Set(a);
  const inB = new Set(b);
  for (const value of c) {
    if (inA.has(value) && inB.has(value)) return value;
  }
  return null;
};
```

- Время: **O(p + q + r)**.
- Память: **O(p + q)**, а интервьюер ждёт O(1).
- Подвох: возвращается первое общее значение **в порядке `c`**, а не наименьшее.

## 4. Пошаговый разбор кода

```js
const findCommonElement = (a, b, c) => {
  let i = 0;
  let j = 0;
  let k = 0;

  while (i < a.length && j < b.length && k < c.length) {
    if (a[i] === b[j] && b[j] === c[k]) {
      return a[i];
    }

    const max = Math.max(a[i], b[j], c[k]);
    if (a[i] < max) i++;
    if (b[j] < max) j++;
    if (c[k] < max) k++;
  }

  return null;
};
```

1. Пока ни один массив не закончился, сравниваем три текущих значения.
2. Если все равны, это общее число. Массивы неубывающие, поэтому первое найденное
   совпадение ещё и наименьшее.
3. Иначе считаем максимум из трёх. Значение, которое меньше максимума, в других массивах
   уже «пройдено», и общим быть не может. Двигаем **все** указатели, которые указывают
   на значения меньше максимума. Хотя бы один указатель сдвинется всегда, потому что
   значения не все равны.
4. Если один из массивов закончился, общего числа нет.

### Трассировка на примере `a = [1, 2, 4, 5]`, `b = [3, 3, 4]`, `c = [2, 3, 4, 5, 6]`

| i | j | k | a[i] | b[j] | c[k] | max | Действие |
|---|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 1 | 3 | 2 | 3 | сдвигаем `i` и `k` |
| 1 | 0 | 1 | 2 | 3 | 3 | 3 | сдвигаем `i` |
| 2 | 0 | 1 | 4 | 3 | 3 | 4 | сдвигаем `j` и `k` |
| 2 | 1 | 2 | 4 | 3 | 4 | 4 | сдвигаем `j` |
| 2 | 2 | 2 | 4 | 4 | 4 | 4 | все равны, ответ `4` |

## 5. Сложность и сравнение альтернатив

- **Время: O(p + q + r)** — каждый указатель только увеличивается.
- **Память: O(1)**.

## Альтернативные подходы

- **`Set` по двум массивам** (см. выше): проще, но память O(n) и порядок ответа зависит от
  третьего массива.
- **Попарное пересечение:** найти пересечение `a` и `b` слиянием, затем пересечь результат с `c`.
  Время то же, но нужен промежуточный массив.
- **Все общие значения, а не одно** (вариант LeetCode «Intersection of Three Sorted Arrays»):
  вместо `return` кладём значение в результат и сдвигаем все три указателя.
