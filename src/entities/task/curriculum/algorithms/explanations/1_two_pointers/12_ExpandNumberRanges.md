## 1. Паттерн и шаблон алгоритма

**Паттерн:** разбор строки (String Parsing)  
**Разновидность:** `Parsing: Split → Map → Expand` (разбить на токены, преобразовать, развернуть)

### В чём суть паттерна и разновидности
Входная строка — это **последовательность токенов** с понятным разделителем. Разбор делится на три шага: разбить строку на токены (`split`), преобразовать каждый токен в структуру (`map(Number)`) и выполнить действие над структурой (развернуть диапазон в числа). Главное — заранее перечислить **виды токенов** (число или диапазон) и продумать **крайние случаи** (пустая строка, один элемент).

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Parsing: Split → Map → Expand
const parseTemplate = (input) => {
  if (input === "") return []; // пустой вход: "".split(",") дал бы [""]

  const result = [];
  for (const token of input.split(",")) {
    const [start, end = start] = token.split("-").map(Number); // "5" → end = start
    for (let value = start; value <= end; value++) {
      result.push(value);
    }
  }
  return result;
};
```

## 2. Суть задачи

Дана строка вида `"1-6,8-9,11"`: числа и диапазоны через запятую. Нужно получить
все числа по возрастанию: `[1, 2, 3, 4, 5, 6, 8, 9, 11]`.

Похожая задача описана в [публичном отчёте участника контеста Т-Банка](https://habr.com/ru/articles/850926/)
(в статье она названа «Интервалы», год и направление отбора не указаны).
Условие в нашей версии сформулировано самостоятельно: числа неотрицательные,
пробелов нет, пустая строка даёт пустой массив.

## 3. Наивное решение (для понимания)

Разобрать строку регулярным выражением `(\d+)-(\d+)`.

```js
const expandRanges = (ranges) => {
  const result = [];
  for (const part of ranges.split(",")) {
    const match = part.match(/(\d+)-(\d+)/);
    if (match) {
      for (let v = Number(match[1]); v <= Number(match[2]); v++) result.push(v);
    }
  }
  return result;
};
```

Ловушка: регулярка не срабатывает на **одиночных** числах (`"11"`), и они молча теряются.
Это типичная ошибка в таких задачах: код проходит пример с диапазонами и падает на тестах
с одиночными значениями.

## 4. Пошаговый разбор кода

```js
const expandRanges = (ranges) => {
  if (ranges === "") {
    return [];
  }

  const result = [];

  for (const part of ranges.split(",")) {
    const [start, end = start] = part.split("-").map(Number);

    for (let value = start; value <= end; value++) {
      result.push(value);
    }
  }

  return result;
};
```

1. **Пустая строка.** `"".split(",")` возвращает `[""]`, а `Number("")` равен `0`. Без
   проверки мы получили бы `[0]` вместо `[]`.
2. **Токены.** `split(",")` режет строку на `"1-6"`, `"8-9"`, `"11"`.
3. **Диапазон или число.** `part.split("-")` даёт `["1", "6"]` или `["11"]`. В деструктуризации
   `[start, end = start]` значение по умолчанию подставляется, когда второго элемента нет.
   Одиночное число превращается в диапазон `11-11`.
4. **Разворачивание.** Внутренний цикл добавляет все числа от `start` до `end` включительно.

### Трассировка на примере `"1-6,8-9,11"`

| part | start | end | Добавлено |
|---|---|---|---|
| `"1-6"` | 1 | 6 | 1, 2, 3, 4, 5, 6 |
| `"8-9"` | 8 | 9 | 8, 9 |
| `"11"` | 11 | 11 (по умолчанию) | 11 |

## 5. Сложность и сравнение альтернатив

- **Время: O(n + k)**, где `n` — длина строки, `k` — число чисел в ответе.
- **Память: O(k)** под результат.

### Что проверить на собеседовании
- Одиночное число без дефиса.
- Пустая строка.
- Диапазон из одного числа (`"7-7"`).
- Нулевые значения: `"0-2"`.

## Альтернативный подход

**Ручной разбор по символам** с накоплением числа (`number = number * 10 + digit`) и флагом
«после дефиса». Память та же, но код длиннее и подвержен ошибкам. `split` читается лучше,
а на ограничениях таких задач разницы в скорости нет. Обратная задача (свернуть массив
в диапазоны) — LeetCode «Summary Ranges» (#228), решается двумя указателями.
