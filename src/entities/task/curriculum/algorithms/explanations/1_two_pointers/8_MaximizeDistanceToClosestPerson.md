## 1. Паттерн и шаблон алгоритма

**Паттерн:** Two Pointers (два указателя)  
**Разновидность:** `Two Pointers: Last Seen` (один проход с указателем на предыдущий «маркер»)

### В чём суть паттерна и разновидности
Мы идём по массиву одним указателем `i` и держим второй — `prev`, индекс последнего встреченного «маркера» (здесь — занятого места). Каждый раз, когда находим следующий маркер, у нас есть **пара соседних маркеров** `(prev, i)`, и всё, что лежит между ними, можно оценить за $O(1)$ по формуле. Хранить сами промежутки или делать второй проход не нужно.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Two Pointers: Last Seen (оценка промежутков между соседними маркерами)
const gapsTemplate = (items) => {
  let prev = -1;
  let best = 0;

  for (let i = 0; i < items.length; i++) {
    if (items[i] === 1) {
      best = prev === -1
        ? i                                        // край массива до первого маркера
        : Math.max(best, Math.floor((i - prev) / 2)); // промежуток между двумя маркерами
      prev = i;
    }
  }

  return Math.max(best, items.length - 1 - prev); // край массива после последнего маркера
};
```

## 2. Суть задачи

В ряду коворкинга `seats[i] = 1` — место занято, `0` — свободно. Нужно выбрать свободное
место так, чтобы расстояние до **ближайшего** занятого было как можно больше, и
вернуть это расстояние.

Свободные места бывают трёх видов, и у каждого своя формула:

| Где находится свободный отрезок | Куда садимся | Расстояние до ближайшего |
|---|---|---|
| Между двумя занятыми (`prev` и `i`) | Посередине | `⌊(i - prev) / 2⌋` |
| В начале, до первого занятого (`i`) | В самый край (индекс `0`) | `i` |
| В конце, после последнего (`prev`) | В самый край (индекс `n - 1`) | `n - 1 - prev` |

## 3. Наивное решение (для понимания)

Для каждого свободного места найти расстояние до ближайшего занятого перебором
в обе стороны и выбрать максимум.

```js
const maxDistToClosest = (seats) => {
  let best = 0;
  for (let i = 0; i < seats.length; i++) {
    if (seats[i] === 1) continue;
    let distance = Infinity;
    for (let j = 0; j < seats.length; j++) {
      if (seats[j] === 1) distance = Math.min(distance, Math.abs(i - j));
    }
    best = Math.max(best, distance);
  }
  return best;
};
```

- Время: **O(n²)**.
- Память: **O(1)**.

## 4. Пошаговый разбор кода

```js
const maxDistToClosest = (seats) => {
  let prev = -1; // индекс последнего занятого места
  let best = 0;

  for (let i = 0; i < seats.length; i++) {
    if (seats[i] === 1) {
      best = prev === -1 ? i : Math.max(best, Math.floor((i - prev) / 2));
      prev = i;
    }
  }

  return Math.max(best, seats.length - 1 - prev);
};
```

1. Пока не встретили ни одного занятого места, `prev === -1`. Первое занятое место
   на индексе `i` означает, что слева `i` свободных мест, и лучше сесть на самый
   край: расстояние равно `i`.
2. Каждое следующее занятое место `i` вместе с `prev` ограничивает промежуток.
   Между ними выгодно сесть посередине, до обоих соседей будет `⌊(i - prev) / 2⌋`.
3. После цикла остаётся «хвост» справа от последнего занятого места. Там тоже
   садимся в край, расстояние `n - 1 - prev`. Если массив заканчивается занятым
   местом, то `n - 1 - prev = 0`, и хвост ни на что не влияет.

### Трассировка на примере `seats = [1, 0, 1, 0, 0]`

| i | seats[i] | prev до | Действие | best | prev после |
|---|---|---|---|---|---|
| 0 | 1 | -1 | первое занятое: `best = i = 0` | 0 | 0 |
| 1 | 0 | 0 | пропускаем | 0 | 0 |
| 2 | 1 | 0 | `max(0, ⌊(2-0)/2⌋) = 1` | 1 | 2 |
| 3–4 | 0 | 2 | пропускаем | 1 | 2 |

Хвост: `5 - 1 - 2 = 2`, итог `max(1, 2) = 2` — выгоднее всего сесть на последнее место.

Левый край работает так же: в `[0, 0, 0, 1, 0]` первое занятое место стоит на индексе `3`,
поэтому сразу `best = 3`, и ни промежутки, ни хвост (`5 - 1 - 3 = 1`) этот результат не улучшат.

## 5. Сложность и сравнение альтернатив

- **Время: O(n)** — один проход по массиву.
- **Память: O(1)** — только `prev` и `best`.

## Альтернативный подход

**Два прохода (слева направо и справа налево).** Первым проходом считаем для каждой
позиции расстояние до ближайшего занятого места слева, вторым — справа, и берём
`min` из двух. Время тоже O(n), но нужен дополнительный массив O(n). Решение с
`prev` короче по памяти, зато требует аккуратной работы с краями. Этот приём с
проходами в обе стороны полезно знать: он же решает «01 Matrix» и «Product of Array
Except Self».
