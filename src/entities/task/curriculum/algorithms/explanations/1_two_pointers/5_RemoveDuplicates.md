## 1. Паттерн и шаблон алгоритма

**Паттерн:** Two Pointers (два указателя)  
**Разновидность:** `Two Pointers: Slow / Fast` (медленный и быстрый указатели)

### В чём суть паттерна и разновидности
Паттерн **Two Pointers: Slow / Fast** для отсортированных данных использует факт, что все дубликаты расположены последовательно. `slow` указывает на конец уже сформированного уникального префикса массива, а `fast` бежит вперёд, исследуя новые значения. Как только `fast` находит элемент, отличный от `slow`, граница `slow` сдвигается вперёд (`slow++`), и в неё записывается новое значение. Это гарантирует $O(n)$ время и $O(1)$ память без единого сдвига массива.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Two Pointers: Slow / Fast (удаление дубликатов в отсортированном массиве)
const removeDuplicatesSortedTemplate = (sortedArr) => {
  if (sortedArr.length === 0) return 0;

  let slow = 0; // индекс последнего уникального элемента

  for (let fast = 1; fast < sortedArr.length; fast++) {
    if (sortedArr[fast] !== sortedArr[slow]) {
      slow++;
      sortedArr[slow] = sortedArr[fast];
    }
  }

  return slow + 1; // длина массива без дубликатов
};
```

## 2. Суть задачи
В журнале `nums` идентификаторы записаны по возрастанию, и некоторые повторяются.
Нужно на месте оставить каждый идентификатор по одному разу и вернуть их количество $k$.
Уникальные значения должны занять первые $k$ ячеек в исходном порядке, а что лежит дальше — не важно.

```
removeDuplicates([2, 2, 2, 5, 7, 7])  ->  3   (первые ячейки: [2, 5, 7])
```

Ограничения: дополнительная память $O(1)$ — новый массив или `Set` создавать нельзя, время $O(n)$.

## 3. Разбор решения

Поскольку массив уже **отсортирован**, все одинаковые числа расположены строго рядом друг с другом. Это позволяет решить задачу за один линейный проход с помощью двух указателей:
1. Если длина массива равна `0`, сразу возвращаем `0`.
2. Заводим указатель `slow = 0`. Он указывает на позицию последнего найденного уникального элемента.
3. Запускаем указатель `fast = 1` по остальной части массива:
   - Если `nums[fast] !== nums[slow]`, значит, мы встретили новое уникальное значение!
   - Увеличиваем `slow++` и перезаписываем ячейку: `nums[slow] = nums[fast]`.
   - Если `nums[fast] === nums[slow]`, значит, это дубликат — указатель `fast` просто идёт дальше.
4. В конце `slow` указывает на индекс последнего уникального элемента, поэтому длина уникального префикса равна `slow + 1`.

## 4. Пошаговый разбор кода

```js
const removeDuplicates = (nums) => {
  // Базовый случай для пустого массива
  if (nums.length === 0) {
    return 0;
  }

  // slow указывает на последний зафиксированный уникальный элемент
  let slow = 0;

  // fast ищет следующее новое значение
  for (let fast = 1; fast < nums.length; fast++) {
    if (nums[fast] !== nums[slow]) {
      slow++;
      nums[slow] = nums[fast];
    }
  }

  // Количество уникальных элементов равно индексу + 1
  return slow + 1;
};
```

### Трассировка для `nums = [2, 2, 2, 5, 7, 7]`

| `fast` | `nums[fast]` | `nums[slow]` | Сравнение | Действие | `nums` (префикс) | `slow` |
|:---:|:---:|:---:|:---|:---|:---|:---:|
| 1 | 2 | 2 | `2 === 2` | Дубликат, пропускаем | `[2, ...]` | 0 |
| 2 | 2 | 2 | `2 === 2` | Дубликат, пропускаем | `[2, ...]` | 0 |
| 3 | 5 | 2 | `5 !== 2` | Новое! `slow++`, `nums[1] = 5` | `[2, 5, ...]` | 1 |
| 4 | 7 | 5 | `7 !== 5` | Новое! `slow++`, `nums[2] = 7` | `[2, 5, 7, ...]` | 2 |
| 5 | 7 | 7 | `7 === 7` | Дубликат, пропускаем | `[2, 5, 7, ...]` | 2 |

Ответ: `slow + 1 = 3`.

## 5. Сложность и типичные ошибки на собеседовании
- **По времени**: $O(n)$, так как `fast` совершает ровно $n - 1$ шаг.
- **По памяти**: $O(1)$, перезапись значений происходит непосредственно во входном массиве `nums`.

### Частые ошибки
1. **Попытка решить через `new Set(nums)`**:
   `return [...new Set(nums)].length` возвращает число, но **не мутирует исходный массив `nums`**, переданный вызывающей стороне по ссылке, а также требует $O(n)$ дополнительной памяти.
2. **Использование `nums.splice()` для удаления каждого дубликата**:
   Вызов `splice(i, 1)` сдвигает весь хвост массива, превращая сложность в $O(n^2)$.
