## 1. Паттерн и шаблон алгоритма

**Паттерн:** Two Pointers (два указателя)  
**Разновидность:** `Two Pointers: Slow / Fast` (медленный и быстрый указатели)

### В чём суть паттерна и разновидности
Паттерн **Two Pointers: Slow / Fast** (указатели чтения и записи) — фундаментальный приём для **in-place модификации и фильтрации массивов** без выделения дополнительной памяти ($O(1)$ Space).
- `fast` (указатель чтения / разведчик) быстро сканирует каждый элемент массива.
- `slow` (указатель записи / барьер) отслеживает позицию, куда должен быть помещен следующий валидный элемент.
Это исключает сдвиги элементов через `splice()` за $O(n^2)$ и создание копий через `filter()` за $O(n)$ памяти.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Two Pointers: Slow / Fast (in-place перезапись / фильтрация)
const inPlaceFilterTemplate = (arr) => {
  let slow = 0; // позиция для записи валидного элемента

  for (let fast = 0; fast < arr.length; fast++) {
    if (/* условие сохранения arr[fast] */) {
      if (slow !== fast) {
        // перенос или обмен элементов
        arr[slow] = arr[fast];
      }
      slow++; // сдвигаем границу валидной части
    }
  }

  return slow; // новая длина валидной части (или массив)
};
```

## 2. Суть задачи
Дан массив чисел `nums`. Нужно переместить все нули в конец массива **на месте (in-place)**, сохранив относительный порядок всех ненулевых элементов.

Функция возвращает изменённый массив `nums`. Дополнительное ограничение: нельзя создавать копию массива, сложность по памяти должна быть $O(1)$, а по времени — $O(n)$.

## 3. Разбор решения

Паттерн «медленный и быстрый указатель» (Slow / Fast) идеально подходит для задач in-place фильтрации:
1. Заводим указатель `slow = 0`. Он указывает на позицию, в которую должен быть записан следующий встреченный ненулевой элемент.
2. Запускаем указатель `fast = 0`, который бежит по всему массиву от начала до конца:
   - Если `nums[fast] !== 0`: меняем местами элементы `nums[slow]` и `nums[fast]` (если `slow !== fast`), после чего сдвигаем `slow++`.
   - Если `nums[fast] === 0`: просто идём дальше (`fast++`), ожидая следующего ненулевого числа.
3. В результате все ненулевые элементы компактно перемещаются в начало массива с сохранением своего исходного порядка, а нули вытесняются в хвост.

## 4. Пошаговый разбор кода

```js
const moveZeroes = (nums) => {
  // slow указывает на позицию для вставки следующего ненулевого элемента
  let slow = 0;

  // fast сканирует массив в поисках ненулевых чисел
  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== 0) {
      // Меняем местами только если указатели разошлись (микрооптимизация)
      if (slow !== fast) {
        [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
      }
      slow++;
    }
  }

  return nums;
};
```

## Трассировка для `nums = [0, 1, 0, 3, 12]`

| `fast` | `nums[fast]` | Действие | `nums` после шага | `slow` |
|:---:|:---:|:---|:---|:---:|
| 0 | 0 | Ноль, пропускаем | `[0, 1, 0, 3, 12]` | 0 |
| 1 | 1 | Ненулевой: swap(0, 1) | `[1, 0, 0, 3, 12]` | 1 |
| 2 | 0 | Ноль, пропускаем | `[1, 0, 0, 3, 12]` | 1 |
| 3 | 3 | Ненулевой: swap(1, 3) | `[1, 3, 0, 0, 12]` | 2 |

## 5. Сложность и типичные ошибки на собеседовании
- **По времени**: $O(n)$, так как быстрый указатель `fast` проходит по массиву ровно один раз.
- **По памяти**: $O(1)$, все перестановки выполняются на месте без выделения дополнительных массивов.

### Частые ошибки
1. **Использование `splice` и `push` внутри цикла**:
   ```js
   // АНТИПАТТЕРН: O(n²) по времени!
   for (let i = 0; i < nums.length; i++) {
     if (nums[i] === 0) {
       nums.splice(i, 1);
       nums.push(0);
       i--;
     }
   }
   ```
   Метод `splice` сдвигает все последующие элементы массива за $O(n)$, что приводит к квадратичной сложности $O(n^2)$ и сбивает индексы обхода.
2. **Создание нового массива через `filter`**:
   `nums.filter(x => x !== 0).concat(...)` создаёт новый массив и расходует $O(n)$ дополнительной памяти, нарушая требование in-place.
