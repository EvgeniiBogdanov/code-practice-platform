## 1. Паттерн и шаблон алгоритма

**Паттерн:** Two Pointers (два указателя)  
**Разновидность:** `Two Pointers: Classic` (навстречу друг другу)

### В чём суть паттерна и разновидности
Паттерн **Two Pointers: Classic** применяется, когда данные (массив или строка) **отсортированы** либо симметричны. Вместо вложенных циклов с перебором всех пар за $O(n^2)$, мы ставим один указатель в начало (`left = 0`), а второй — в конец (`right = n - 1`) и сдвигаем их навстречу друг другу за один проход $O(n)$ с расходом памяти $O(1)$.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Two Pointers: Classic (навстречу друг другу)
const twoPointersClassic = (sortedArr, target) => {
  let left = 0;
  let right = sortedArr.length - 1;

  while (left < right) {
    const current = sortedArr[left] + sortedArr[right];

    if (current === target) {
      return [left, right]; // пара найдена
    }

    if (current < target) {
      left++; // сумма мала — сдвигаем левый край вправо
    } else {
      right--; // сумма велика — сдвигаем правый край влево
    }
  }

  return null; // пара не найдена
};
```

## 2. Суть задачи
Цены в каталоге отсортированы по неубыванию. Нужно найти два разных товара,
которые вместе стоят ровно `target`, и вернуть их позиции, считая с единицы.
Подходящая пара всегда есть, и она одна.

```
twoSum([1, 3, 4, 6, 9], 13)  ->  [3, 5]   (4 + 9)
```

Главное ограничение — дополнительная память $O(1)$. Хеш-таблица, как в задаче
«Two Sum» из раздела про хеш-таблицы, здесь не подходит: она требует $O(n)$ памяти.
Зато массив уже отсортирован, и это позволяет обойтись двумя указателями.

## 3. Разбор решения
1. Заводим два указателя: `left` — на первый элемент массива (индекс 0),
   `right` — на последний элемент (индекс `numbers.length - 1`).
2. В цикле, пока `left < right`, считаем сумму `numbers[left] + numbers[right]`.
3. Если сумма равна `target` — нашли ответ, возвращаем `[left + 1, right + 1]`.
4. Если сумма меньше `target` — значит, нужно число побольше. Так как массив
   отсортирован по возрастанию, сдвигаем `left` на 1 вправо: `left++`.
5. Если сумма больше `target` — значит, нужно число поменьше, сдвигаем
   `right` на 1 влево: `right--`.
6. Цикл продолжается, пока указатели не сойдутся. Поскольку по условию
   задачи решение гарантированно существует, цикл всегда завершится
   успешным `return` раньше, чем указатели встретятся.

## 4. Пошаговый разбор кода

```js
const twoSum = (numbers, target) => {
  // Указатель на начало массива (самый маленький элемент, т.к. массив отсортирован)
  let left = 0;
  // Указатель на конец массива (самый большой элемент)
  let right = numbers.length - 1;

  // Двигаем указатели, пока они не встретятся
  while (left < right) {
    // Считаем сумму элементов под текущими указателями
    const sum = numbers[left] + numbers[right];

    if (sum === target) {
      // Нашли нужную пару — возвращаем их 1-based индексы
      return [left + 1, right + 1];
    }

    if (sum < target) {
      // Сумма меньше нужной — берём число побольше слева
      left++;
    }

    if (sum > target) {
      // Сумма больше нужной — берём число поменьше справа
      right--;
    }
  }

  // По условию задачи сюда мы дойти не должны (решение всегда есть),
  // но на всякий случай возвращаем пустой массив
  return [];
};
```

### Пример пошагового выполнения
`numbers = [1, 3, 4, 6, 9]`, `target = 13`

| Шаг | left | right | numbers[left] | numbers[right] | sum | Действие |
|-----|------|-------|----------------|------------------|-----|----------|
| 1   | 0    | 4     | 1              | 9                | 10  | sum < target → left++ |
| 2   | 1    | 4     | 3              | 9                | 12  | sum < target → left++ |
| 3   | 2    | 4     | 4              | 9                | 13  | sum === target → return [3, 5] |

## 5. Сложность
- **По времени**: $O(n)$ — каждый элемент рассматривается не более одного раза, так как на каждой итерации указатели сближаются минимум на один шаг.
- **По памяти**: $O(1)$ — используются только две числовые переменные для хранения индексов `left` и `right`, дополнительная память не выделяется.
