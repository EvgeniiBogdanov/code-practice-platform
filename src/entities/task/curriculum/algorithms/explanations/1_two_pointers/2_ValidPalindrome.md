## 1. Паттерн и шаблон алгоритма

**Паттерн:** Two Pointers (два указателя)  
**Разновидность:** `Two Pointers: Classic` (навстречу друг другу)

### В чём суть паттерна и разновидности
Паттерн **Two Pointers: Classic** — золотой стандарт проверки симметрии строк или массивов. Указатели идут навстречу друг другу с противоположных концов (`left = 0`, `right = s.length - 1`). Если на каком-то шаге зеркальные элементы не совпадают — условие симметрии нарушено, и мы сразу возвращаем `false` (fail-fast), затрачивая $O(1)$ дополнительной памяти вместо создания перевёрнутой строки за $O(n)$ памяти.

### Шаблон кода для запоминания синтаксиса
```javascript
// Шаблон: Two Pointers: Classic (проверка симметрии)
const isSymmetricTemplate = (sequence) => {
  let left = 0;
  let right = sequence.length - 1;

  while (left < right) {
    if (sequence[left] !== sequence[right]) {
      return false; // асимметрия обнаружена
    }
    left++;
    right--;
  }

  return true; // полностью симметрично
};
```

## 2. Суть задачи
Дана строка. Нужно определить, является ли она палиндромом, если:
- привести все буквы к нижнему регистру;
- убрать все символы, кроме букв и цифр (знаки препинания, пробелы
  и т.д. не учитываются).

Например, строка `"A man, a plan, a canal: Panama"` после очистки
превращается в `"amanaplanacanalpanama"`, а это уже классический
палиндром — читается одинаково в обе стороны.

## 3. Разбор решения
1. Заводим вспомогательную функцию `isAlphanumeric`, которая с помощью
   регулярного выражения проверяет, является ли символ буквой или
   цифрой.
2. Заводим два указателя: `left = 0` (начало строки) и
   `right = s.length - 1` (конец строки).
3. Пока `left < right`:
   - "Прокручиваем" `left` вправо, пока под ним не окажется
     буквенно-цифровый символ (пропускаем пробелы, запятые и т.п.).
   - Аналогично "прокручиваем" `right` влево.
   - Сравниваем символы `s[left]` и `s[right]` в нижнем регистре.
     Если они разные — строка не палиндром, возвращаем `false`.
   - Если совпали — сдвигаем оба указателя навстречу друг другу
     (`left++`, `right--`) и переходим к следующей итерации.
4. Если цикл завершился без несовпадений — строка палиндром,
   возвращаем `true`.

## 4. Пошаговый разбор кода

```js
const isPalindrome = (s) => {
  // Проверка: является ли символ буквой (a-z, A-Z) или цифрой (0-9)
  const isAlphanumeric = (char) => /[a-z0-9]/i.test(char);

  // Указатель на начало строки
  let left = 0;
  // Указатель на конец строки
  let right = s.length - 1;

  // Двигаем указатели навстречу друг другу, пока не встретятся
  while (left < right) {
    // Пропускаем не буквенно-цифровые символы слева
    while (left < right && !isAlphanumeric(s[left])) {
      left++;
    }
    // Пропускаем не буквенно-цифровые символы справа
    while (left < right && !isAlphanumeric(s[right])) {
      right--;
    }

    // Сравниваем символы без учёта регистра
    if (s[left].toLowerCase() !== s[right].toLowerCase()) {
      // Символы не совпали — это не палиндром
      return false;
    }

    // Символы совпали — сдвигаем оба указателя навстречу друг другу
    left++;
    right--;
  }

  // Все пары символов совпали — строка является палиндромом
  return true;
};
```

### Пример пошагового выполнения
`s = "race a car"`

| Шаг | left | right | s[left] | s[right] | Совпадают? | Действие |
|-----|------|-------|---------|----------|------------|----------|
| 1   | 0    | 9     | "r"     | "r"      | да         | left++, right-- |
| 2   | 1    | 8     | "a"     | "a"      | да         | left++, right-- |
| 3   | 2    | 7     | "c"     | "c"      | да         | left++, right-- |
| 4   | 3    | 6     | "e"     | " " → "a" (после пропуска пробела) | нет | return false |

На шаге 4 после сравнения `"e"` и `"a"` алгоритм сразу завершает
работу и возвращает `false`, не проверяя оставшуюся часть строки.

## 5. Сложность
- **По времени**: $O(n)$ — строка обходится указателями слева и справа за один проход, каждый символ посещается максимум дважды.
- **По памяти**: $O(1)$ — мы работаем с исходной строкой по индексам, не создавая промежуточных массивов и новых строк.
