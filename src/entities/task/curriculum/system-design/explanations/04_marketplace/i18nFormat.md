# Разбор задачи: «Форматтер сообщений с плюрализацией и запасным языком»

## 1. Что ломается без этого

Строка «Осталось N шт.» кажется простой, пока не появляется второй язык:

- **Склейка** `"В корзине " + n + " товаров"` даёт «1 товаров» и «2 товаров»: формы слова зависят от числа.
- **Плюрализация на `if`** (`n === 1 ? ... : ...`) не работает для русского, где три формы, и для арабского, где шесть.
- **Нет строки в языке** — пользователь видит пустоту или ключ вместо текста.

## 2. Решение по шагам

### Шаг 1. Поиск с запасным языком

Ищем строку сначала в языке интерфейса, потом в запасном. Вместе со строкой запоминаем язык, из которого она взята:

```ts
for (const language of [locale, fallbackLocale]) {
  const message = dictionaries[language]?.[key];
  if (message !== undefined) return { message, language };
}
```

Язык запоминаем не случайно: правила плюрализации принадлежат языку строки. Если русская строка показана в английском интерфейсе, формы выбираются по русским правилам.

### Шаг 2. Выбор формы

`Intl.PluralRules` говорит, какая категория у числа в языке: `one`, `few`, `many`, `other`. Если нужной формы в словаре нет, берём `other`:

```ts
const category = new Intl.PluralRules(language).select(count);
return forms[category] ?? forms.other;
```

Для русского `1` → `one`, `2` → `few`, `5` и `11` → `many`, `1.5` → `other`.

### Шаг 3. Плейсхолдеры

`{name}` заменяем на параметр. Если параметра нет, плейсхолдер остаётся в тексте: так ошибка видна, а не скрыта пустотой.

## 3. Подводные камни

- **`in` вместо `hasOwnProperty`.** Ключи вроде `constructor` есть в прототипе, и `in` вернёт `true`. Проверяйте собственное свойство.
- **Порядок слов.** Плейсхолдеры в строке, а не в коде: только так перевод может переставить слова.
- **Число как строка.** `count` в параметрах должен быть числом, иначе правила плюрализации не сработают.

## 4. Связь с реальными библиотеками

i18next, FormatJS (react-intl) и Lingui решают ту же задачу: ключи, плейсхолдеры, формы по числу, запасной язык. Здесь мы строим их ядро, чтобы понимать, что происходит при вызове `t`.

Сами форматы даты, числа и валюты берутся через `Intl`, а не пишутся руками.

## 5. Что обсудить на интервью

- Где хранить переводы и почему загрузка по локали лучше бандла.
- Как работать с RTL: логические свойства CSS, а не только `dir`.
- Как выбрать язык: URL, cookie, `Accept-Language`, и в каком порядке.
