# Разбор задачи: «Составные значения»

## 1. Что дано

Есть пара `["Alice", 30]` и функция `printEntry`, которая выводит первый и второй элементы. По смыслу первая позиция — имя, вторая — возраст. Здесь важен не только набор допустимых типов, но и место каждого значения.

Без аннотации обычный изменяемый массив с такими элементами получает тип `(string | number)[]`. Он не сообщает, что строка обязательно находится на позиции `0`, а число — на позиции `1`.

## 2. Что нужно получить

Нужен тип `Entry`, которому соответствует пара из двух элементов:

```ts
["Alice", 30] // Подходит.
// [30, "Alice"] // Неверный порядок.
// ["Alice"] // Не хватает возраста.
// ["Alice", 30, true] // Лишний элемент.
```

Функция принимает такую пару и ничего полезного не возвращает: её результатом для пользователя является вывод в консоль.

## 3. Почему обычного массива недостаточно

Тип `(string | number)[]` разрешил бы `[]`, `[30, "Alice"]` и `["Alice", "Bob", 30]`. Он говорит лишь: «каждый элемент — строка или число». Для структуры с фиксированными позициями нужен **кортеж**.

Кортеж остаётся массивом в JavaScript, но на уровне типов хранит отдельное описание каждой позиции. Это удобно для координат, пар «ключ — значение» и результатов функций, где порядок заранее оговорён.

## 4. Решение по шагам

### Шаг 1. Объявить кортеж

```ts
type Entry = [name: string, age: number];
```

`type` даёт конструкции имя. Квадратные скобки здесь описывают две позиции, а метки `name` и `age` помогают читать подсказки редактора. Они не создают свойства `entry.name` и `entry.age`: доступ по-прежнему идёт через индексы.

### Шаг 2. Применить один контракт к данным и функции

Если типизировать только переменную, параметр функции останется без собственного контракта. Поэтому `Entry` нужен в обоих местах.

### Полный код

```ts
type Entry = [name: string, age: number];

const entry: Entry = ["Alice", 30];

const printEntry = (entry: Entry): void => {
  console.log(`${entry[0]} - ${entry[1]}`);
};
```

`void` сообщает вызывающему коду, что использовать возвращаемое значение не предполагается. Здесь функция доходит до конца без `return`, поэтому JavaScript фактически возвращает `undefined`.

## 5. Разбор вызова по шагам

При `printEntry(entry)` происходят следующие действия:

1. В параметр попадает массив `["Alice", 30]`.
2. `entry[0]` имеет тип `string` и значение `"Alice"`.
3. `entry[1]` имеет тип `number` и значение `30`.
4. Шаблонная строка превращает эти значения в текст `Alice - 30`.
5. `console.log` выводит текст, функция завершает работу.

Система типов также разрешит `entry[0].toUpperCase()` и `entry[1].toFixed(0)`: для каждой позиции известен свой тип.

## 6. Важные детали и частые ошибки

- `[string, number]` и `(string | number)[]` описывают разные требования. Скобки и запятые здесь влияют на смысл.
- `const entry` запрещает присвоить переменной другой массив, но не запрещает менять его элементы.
- Обычный изменяемый кортеж не является абсолютной защитой длины во время выполнения: методы наподобие `push` могут оставаться доступны. Фиксированная форма контролируется при типизации присваиваний и обращений по известным индексам.
- Если по условию вообще нельзя изменять пару, контракт можно усилить до `readonly [name: string, age: number]`. В текущем упражнении это дополнительное требование не задано.

## 7. Что запомнить

Кортеж описывает смысл каждой позиции. Метки улучшают читаемость, единый псевдоним `Entry` связывает данные с функцией, а `void` показывает, что функция выполняет действие без полезного возвращаемого результата.
