# Разбор задачи: «Обобщённый репозиторий»

## 1. Что дано

Класс-хранилище без типов: внутри `Map`, счётчик id и три метода. Он должен работать с разными сущностями, и для каждой — со своим точным типом. Кроме того, внутреннее состояние должно быть по-настоящему скрыто.

## 2. Что нужно получить

| Требование | Инструмент |
| --- | --- |
| контракт хранилища | `interface Repository<T>` |
| один класс для разных сущностей | параметр типа класса `InMemoryRepository<T>` |
| класс соблюдает контракт | `implements Repository<T>` |
| `create` добавляет `id` | `WithId<T> = T & { id: number }` |
| состояние скрыто и в рантайме | приватные поля `#items`, `#nextId` |

## 3. Решение по шагам

### Шаг 1. Тип сущности с id

```ts
type WithId<T> = T & { id: number };
```

Данные для создания не содержат `id` — его назначает хранилище. Результат — те же данные плюс `id`.

### Шаг 2. Контракт

```ts
interface Repository<T extends object> {
  create(data: T): WithId<T>;
  findById(id: number): WithId<T> | undefined;
  findAll(): WithId<T>[];
}
```

Интерфейс позволяет позже подменить реализацию, например на хранилище с HTTP-запросами, не меняя код, который им пользуется.

### Шаг 3. Обобщённый класс

```ts
class InMemoryRepository<T extends object> implements Repository<T> { ... }
```

Параметр типа объявлен у **класса**, а не у методов: один экземпляр хранит сущности одного типа, и все методы должны работать с одним и тем же `T`. `new InMemoryRepository<UserData>()` фиксирует `T` для экземпляра.

### Шаг 4. create без утверждений

```ts
const entity: WithId<T> = { ...data, id: this.#nextId++ };
```

Для объекта обобщённого типа спред даёт пересечение: `{ ...data, id }` имеет тип `T & { id: number }`. Это ровно `WithId<T>`, и `as` не нужен.

Если бы контракт был «`T` уже содержит `id`, а `create` принимает `Omit<T, "id">`», то `{ ...data, id }` имел бы тип `Omit<T, "id"> & { id: number }`, и TypeScript не смог бы доказать, что это `T`. Пришлось бы писать `as T`. Выбор модели `WithId<T>` позволяет обойтись без утверждения.

### Шаг 5. Приватные поля JavaScript

`#items` — приватное поле стандарта JavaScript. В отличие от модификатора `private`, оно недоступно и во время выполнения: `repo["#items"]` вернёт `undefined`, а `repo.#items` снаружи класса — синтаксическая ошибка.

### Полный код

```ts
type WithId<T> = T & { id: number };

interface Repository<T extends object> {
  create(data: T): WithId<T>;
  findById(id: number): WithId<T> | undefined;
  findAll(): WithId<T>[];
}

class InMemoryRepository<T extends object> implements Repository<T> {
  #items = new Map<number, WithId<T>>();
  #nextId = 1;

  create(data: T): WithId<T> {
    const entity: WithId<T> = { ...data, id: this.#nextId++ };
    this.#items.set(entity.id, entity);
    return entity;
  }

  findById(id: number): WithId<T> | undefined {
    return this.#items.get(id);
  }

  findAll(): WithId<T>[] {
    return [...this.#items.values()];
  }
}
```

## 4. Что implements делает и чего не делает

`implements` только **проверяет**, что класс совместим с интерфейсом. Он не меняет тип класса и не выводит типы параметров методов из интерфейса: если написать `create(data) {...}`, параметр всё равно будет неявным `any`. Поэтому методы аннотируются явно.

## 5. private, #private и protected

| Модификатор | Где доступно | Во время выполнения |
| --- | --- | --- |
| `public` | везде | обычное поле |
| `protected` | класс и наследники | обычное поле |
| `private` | только класс | обычное поле, доступно через `obj["name"]` |
| `#name` | только класс | действительно скрыто |

## 6. Частые ошибки

- Объявлять параметр типа у каждого метода: `create<T>(data: T)`. Тогда один экземпляр принимает любые типы, и `findAll` не знает, что вернуть.
- Писать `as T` в `create`, хотя модель можно выбрать так, чтобы утверждение не понадобилось.
- Считать, что `private` защищает данные в рантайме.
- Ожидать, что `implements` подставит типы параметров методов.

## 7. Что запомнить

Обобщённый класс фиксирует тип для экземпляра и связывает все его методы. Интерфейс отделяет контракт от реализации, `implements` проверяет соответствие, а приватные поля `#` скрывают состояние по-настоящему.
