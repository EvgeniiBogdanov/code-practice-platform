## <a id="v2-1-4"></a>🚀 v2.1.4 — Стандартизация Задач и Исправления Навигации Сайдбара

### 📝 Задачи и Решения
- **Стандартизация структуры задач (JavaScript и Алгоритмы)**: Все файлы задач и решений приведены к единому формату:
  - Вверху — задокументированное описание задачи.
  - В теле — чистый скелет функции с плейсхолдером `// Решение тут` (для задач на синтаксис — только описание без готового кода).
  - Внизу — единый блок `// Пример вызова:` с `console.log(...)` для проверки в консоли.
  - Решения очищены от лишних комментариев и содержат только чистый код с результатами вывода.
- **Исправление условий и путей**: Устранены ошибки в условиях, сигнатурах и путях к эталонным решениям в разделах JavaScript и Алгоритмы.

### 🧭 Навигация и UI/UX
- **Подсветка корневой папки (Group Header)**: Исправлена логика активности группы в сайдбаре — заголовок подсвечивается только при прямом совпадении `selectedTaskIdStr` с `group-...` либо при открытом обзоре группы без подгруппы.

## <a id="v2-1-3"></a>🚀 v2.1.3 — Раздел «Алгоритмы», Страницы Папок, Оптимизация Сайдбара и Улучшения Markdown

### 📚 Новые разделы и задачи
- **Раздел «Алгоритмы»**: Запущен полноценный раздел алгоритмической практики с первыми темами и задачами.
- **Подраздел «while» в JavaScript**: В тему «Циклы» добавлен подраздел `while` с 8 практическими задачами (от базового синтаксиса до двух указателей и бинарного поиска) и детальными теоретическими разборами.

### 🧭 Навигация и страницы папок (Folder Overview Pages)
- **Страницы папок и подпапок**: Корневые папки и подгруппы получили собственные обзорные страницы с вводными статьями, списком задач, фильтрацией («Все», «Решено», «Не решено») и сохранением режима («Список» / «Карточки») в `localStorage`.
- **Синхронизация меню навигации**: Устранён рассинхрон между Header (Finder) и Sidebar — открытие меню в одном месте автоматически закрывает остальные.
- **Паттерн клика**: Клик в любую точку строки папки в сайдбаре надёжно открывает страницу, а клик по шеврону изолированно управляет аккордеоном.

### ⚡ Оптимизация производительности Sidebar
- **Мемоизация элементов**: `SidebarTaskItem`, `SidebarGroupHeader`, `SidebarSubgroupHeader` изолированы в `React.memo` — при смене задачи перерисовывается только активный элемент.
- **Неблокирующий UI**: Раскрытие групп переведено на `useTransition`, вычисления группировок задач оптимизированы через `useMemo`.

### 📝 Markdown Parser и вкладка «Разбор и теория»
- **GFM-таблицы**: Добавлена поддержка Markdown-таблиц с адаптивными стилями для тёмной и светлой тем.
- **Поддержка Plaintext**: Добавлена обработка форматов `notepad`, `text`, `plaintext`, `txt`, `none` для отображения чистого текста без подсветки.
- **Типографика и вёрстка**: Единый дизайн Callout-блоков, плавная якорная прокрутка содержания, растягивание теоретических блоков по ширине и удаление дублирующихся заголовков H1.

### 🐛 Исправления ошибок и интерфейса
- **Полноэкранный режим**: Исправлена работа изолированного режима (`/open`) для алгоритмических задач.
- **Тени выпадающих списков**: Смягчены и оптимизированы тени меню в Header.
- **Точность бейджей**: Исправлено отображение счётчиков задач в фильтрах подгрупп.

## <a id="v2-0-8"></a>🧭 v2.0.8 — Файловый Роутинг (TanStack Router), Синхронизация Finder/Sidebar и CSS-Токены

### 🧭 Файловый роутинг и Deep Linking (TanStack Router)
- **Файловая маршрутизация**: Интегрирован TanStack Router с автоматической генерацией типизированного дерева маршрутов (`src/routeTree.gen.ts`) через Vite-плагин `TanStackRouterVite`.
- **Синхронизация URL и Deep Linking**: Полноценное отображение разделов, задач и вкладок в адресной строке браузера (например, `/react/1?tab=solution`, `/javascript/js-loops-1?tab=materials`, `/home`, `/algorithms`). Любую ссылку можно скопировать и открыть напрямую в новой вкладке.
- **Нативная навигация**: Хлебные крошки Header, дерево задач Sidebar, карточки дашборда и вкладки TaskView переведены на `<Link>`-компоненты. Палитра быстрого поиска (<kbd>Cmd</kbd>+<kbd>K</kbd>) интегрирована через роутер `navigate()`.
- **DevTools и деплой**: Подключена панель `TanStackRouterDevtools` для отладки маршрутов, добавлена поддержка `basepath` (`import.meta.env.BASE_URL`) для бесшовной работы как локально, так и на GitHub Pages.

### 🔄 Синхронизация навигации: Finder (Header) и Sidebar
- **Единое состояние папок и категорий**: Состояния раскрытия категорий React и групп/подгрупп JS объединены в единый источник истины между `Header` и `Sidebar`.
- **Автоматическое раскрытие при переходе**: При переходе к задаче через Finder, поиск <kbd>Cmd</kbd>+<kbd>K</kbd>, дашборд или прямой URL автоматически раскрывается нужная категория (React) либо группа и вложенная подгруппа (JavaScript).
- **Синхронизация при выборе группы/подгруппы**: Клик по группе или подгруппе в Finder моментально раскрывает соответствующую папку в Sidebar и плавно подскролливает к ней.
- **Фокусировка и автоскролл**: Задачи в сайдбаре получили уникальные DOM ID (`sidebar-task-${id}`), обеспечивая плавную прокрутку активного элемента в зону видимости (`scrollIntoView`).

### 🎨 Единая дизайн-система и CSS-токены
- **Токенизация `playground.css`**:
  - **Типографика**: 12 токенов размера шрифта (`--fs-2xs` ... `--fs-5xl`), начертания (`--fw-*`) и межстрочные интервалы (`--lh-*`).
  - **Цвета и поверхности**: Системные токены фонов (`--bg-*`), границ (`--border-*`), текста (`--text-*`), семантических статусов (`--color-success`, `--color-error`, `--color-warning`, `--color-info`, `--color-accent-purple`) и элементов окна macOS (`--dot-*`).
  - **Подсветка синтаксиса**: Переменные подсветки кода (`--hl-*`) с автоматической адаптацией под светлую и тёмную темы (`[data-theme="light"]`).
  - **Геометрия и слои**: Токены скруглений (`--radius-*`), переходов (`--transition-*`), эффектов свечения фокуса (`--shadow-glow-*`) и 13 стандартизированных уровней `z-index` (`--z-*`).
- **Токенизация `reset.css`**: Элементы форм (`input`, `textarea`, `select`, `checkbox`, `radio`, `button`) переведены на глобальные CSS-переменные.
- **Рефакторинг JSX-компонентов**: Устранены инлайновые хардкод-цвета в `CodeEditor.jsx`, `Header.jsx`, `Sidebar.jsx` и модальных окнах с переводом на системные токены.

## <a id="v2-1-0"></a>📱 v2.0.1 — Адаптивность и Оптимизация Интерфейса

> **Ключевая реализация:**  
> Небольшие правки, связанные с адаптивностью интерфейса под любые устройства и разрешения экрана.

### 📱 Мобильный режим и адаптивная панель (Notion Mobile Overlay Drawer)
- **Автоматическое скрытие и выездная панель**: Автоматическое сворачивание сайдбара на малых экранах (≤ 768px). При нажатии на кнопку вызова сайдбар плавно выезжает поверх интерфейса в виде оверлея (`z-index: 2000`) с полупрозрачным размытым фоном (`backdrop-filter: blur(3px)`).
- **Умная память состояния (Smart Desktop Memory)**: При возврате с мобильного экрана на десктоп (> 768px) сайдбар автоматически восстанавливается в то состояние, в котором находился на компьютере (открытый остаётся открытым).
- **Закрытие по жестам и клавишам**: Автоматическое скрытие панели при выборе задачи, клике по фону или нажатию клавиши <kbd>Escape</kbd>.

### ✂️ Однострочная обрезка текста (Ellipsis Truncation)
- **Гарантированное троеточие (`text-overflow: ellipsis`)**: Однострочное сжатие текста с троеточием для хлебных крошек Finder, выпадающих контекстных меню, вкладок задач и файловых вкладок редактора.
- **Корректные отступы и фиксированные иконки**: Закрепленный размер иконки (`flex-shrink: 0`) без разрывов между иконкой и текстом.

### 📐 Система эталонных брейкпоинтов
- **Стандартизированная адаптивная сетка**: Полная поддержка брейкпоинтов (`xs < 480px`, `sm/md <= 768px`, `lg 1024px-1279px`, `xl/2xl >= 1280px`).

## <a id="v2-0-0"></a>🚀 v2.0.0 — Полноценный Редактор Кода и Консоль в Браузере

> **Ключевая реализация:**  
> Изменена механика раздела задач и песочницы. Теперь пользователь может редактировать код сразу в браузере и там же запускать его проверку! Старый способ с правками в вашей любимой IDE также полностью работает. Выбор за вами, где удобнее практиковать задачи — можно даже комбинировать подходы!

### 💻 Встроенный редактор кода (Code Editor)
- **Редактирование в браузере**: Поддержка редактирования JavaScript, TypeScript и React-разметки (JSX / TSX).
- **Поддержка многофайловых задач**: Компактные вкладки переключения файлов в шапке редактора для задач с несколькими модулями (Redux Toolkit, `useReducer` и др.).
- **Инструменты редактора**: Быстрые кнопки Undo, Redo, Word Wrap, форматирование, сброс кода, копирование и полноэкранный режим с сохранением состояния при смене файлов.

### ⚡ Встроенная Node.js Консоль (JsConsole)
- **Мгновенный запуск кода**: Выполнение JavaScript по кнопке «Запустить» или <kbd>Ctrl</kbd> + <kbd>Enter</kbd>.
- **Время выполнения и статистика**: Вывод точного времени выполнения процесса в миллисекундах (`⚡ 6.4ms`) и кода завершения в отдельном подвальном блоке консоли.
- **Поддержка вывода всех типов данных**: `console.log`, `console.warn`, `console.error`, `console.info`, `console.table`, `console.time`, `console.count` и `console.trace`.

### 💡 Варианты Решений и Сворачиваемые Подсказки (Solution Tab)
- **Переключатель вариантов решений**: Кнопки переключения подходов с выделением рекомендуемого решения.
- **Сворачиваемые подсказки для собеседований**: Интерактивные карточки-аккордеоны с нейтральным серым стилем и цветными акцентными полосками слева (Зелёная `#10b981` для рекомендуемого подхода, Оранжевая `#f59e0b` для особенностей).
